It appears that Synapse will, if no filter is specified on a `/sync` request, default to some sort of internal filter with a limit of 10 events per room timeline.

The spec, however, *implies* that `limited` will only be `true` if a filter is specified, through the following passage:

> True if the number of events returned was limited by the `limit` on the filter.

... but never explicitly says whether not specifying a `filter` should mean that there is no limit, or some sort of default limit.
