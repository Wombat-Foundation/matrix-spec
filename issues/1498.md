As described in vector-im/element-web#25179, the spec currently advises clients to malform tables:

|Input|Output|
|-|-|
| <table><thead><tr><th colspan="2">A</th><th>B</th></tr><tr><th>C</th><th>D</th><th>E</th></tr></thead><tbody><tr><td>F</td><td rowspan="2">G</td><td>H</td></tr><tr><td>I</td><td>J</td></tr></tbody></table> | <table><thead><tr><th>A</th><th>B</th></tr><tr><th>C</th><th>D</th><th>E</th></tr></thead><tbody><tr><td>F</td><td>G</td><td>H</td></tr><tr><td>I</td><td>J</td></tr></tbody></table> |

HTML attributes such as `colspan` and `rowspan` that convey structural information should be preserved to maintain message integrity.

While #1395 proposes adding [presentation](https://en.wikipedia.org/wiki/Separation_of_content_and_presentation) attributes to the spec, the intention of this correction is only to do the minimum required to not corrupt user data.
