**Link to problem area**: https://github.com/matrix-org/matrix-spec/blob/ca466b5a572a867de79ba9077e6445265b841c96/data/api/client-server/pusher.yaml#L237

**Issue**

The `format` parameter in `PusherData` is documented as

> Currently the only format available is 'event_id_only'.

This is confusing because while `event_id_only` is the only allowed value for `format`, the parameter is optional and omitting it sends a lot more than just the event ID which arguably could be called a "format" of its own.
