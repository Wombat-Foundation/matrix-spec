**Link to problem area**: https://spec.matrix.org/v1.15/client-server-api/#mroomcreate

**Issue**
The schema describes the `content`, but all the other fields like `event_id`, `room_id`, etc are missing definitions. 

We should either verbosely list all the fields all the time, or include a link to somewhere else in the spec that says "this is [an event]".
