**Link to problem area**: https://spec.matrix.org/v1.17/rooms/v9/#mroompower_levels-events-accept-values-as-strings

**Issue**
There is no defined behaviour as to what should be done with a e.g. `"9223372036854775807"` powerlevel in v6 to v9 rooms. It seems Synapse accepts a powerlevel like this, so it should be stated that this is allowed so as to not break existing rooms.
