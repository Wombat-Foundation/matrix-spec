https://github.com/matrix-org/matrix-doc/blob/master/data/api/client-server/definitions/event.yaml

Some descriptions start with `Optional.`, others don't. I would assume that the other fields are required. However, the `event_id` description contains `if applicable`, so it seems optional too.

This file has no `required` section to specify whether parameters are required or optional in a machine-readable way. No `required` section means all parameters are optional, but I don't think this is intentional, because [data/event-schemas/schema/core-event-schema/event.yaml](https://github.com/matrix-org/matrix-doc/blob/master/data/event-schemas/schema/core-event-schema/event.yaml) says all events must have `content` and `type`.
