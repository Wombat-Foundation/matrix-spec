Just like how we have home servers that run each person's account; we need to have phone servers for the purpose of giving a more traditional phone number.  Matrix is great for privacy but your still forced to use less private traditional companies for a phone number.   A phone server would setup an encrypted communication route to a given account that sets up with it.  Note that your Home server does not have to be your Phone Server.   A Phone Server would have the hardware needed to tie into traditional phone calls.   Think of this as setting up a Google Voice server.   The only difference would be that just like your home server can't read your communication when channels are set to encrypted; a phone server can't hear your communication/see your text because the channel is encrypted.   Here is an example of what would be encrypted and what would not be encrypted.

Matrix App -> Matrix App:  The first Matrix app dials a phone number not knowing whether that is a regular phone number or a phone number on a Matrix Phone Server.   The Matrix App checks phone servers and finds a match.  It does the entire communication through the Matrix network using encryption.  We could have an icon show whenever a call or text is not encrypted

Matrix App -> Home Phone:  The first Matrix app dials a phone number not knowing whether that is a regular phone number or a phone number on a Matrix Phone Server.  The Matrix App checks phone servers and finds no match.   It has encrypted communication from the Matrix app all the way up to the Matrix Phone server registered with your own Matrix account.   The phone server unencrypts it and then sends out the call over traditional phone infrastructure.   When the person talks back to the Matrix Phone Server, it encrypts the voice call before sending it to the Matrix Network and then the Matrix App where it is unencrypted.


Home Phone ->  Matrix App:   Someone dials a phone number and the Matrix Phone server receives the call.   It then encrypts communication before sending it to the Matrix Network and then the Matrix app.


This can work for third party communication apps like Signal as well.   Your Home server or Matrix App ( wherever it is implemented) could see the number is a Signal number and bridge to the other person's Signal app for both encypted voice calls and text messages.


Another way to think of this is a phone server is basically a bridge to traditional phone lines done in an encrypted way.   Any Matrix to Matrix phone calls would not need to go through traditional phone infrastructure.  Since Phone Servers actually have that phone number; regular phones can call a phone server.
