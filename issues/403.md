(noticed from https://github.com/matrix-org/synapse/issues/4249 )

We don't currently even mention unsubscribing from email pushers in the spec, in such a way that the CAN SPAM act and similar legislation requires. We should probably at least mention that a compliant Matrix server SHOULD provide such capability.

Speccing a particular way of unsubscribing is probably not useful, considering that a user will be interacting with it through a link in an email, and not through a Matrix client. However, it may be worth detailing an example API that meets common user requirements.
