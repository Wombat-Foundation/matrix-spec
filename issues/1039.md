**Link to problem area**: https://spec.matrix.org/v1.2/client-server-api/#post_matrixclientv3keysquery

**Issue**
`/keys/query` mentions a `token` parameter which has no known server implementations. Clients mostly do not implement it either. It was originally added in https://github.com/matrix-org/matrix-spec-proposals/pull/1104 which doesn't give much of a rationale for the addition.

**Expected behaviour**
