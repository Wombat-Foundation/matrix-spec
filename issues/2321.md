A "channel" type in discord that is pretty rare because Discord only allows it for communities.
Some more details can be found here: https://www.howtogeek.com/how-to-create-discord-forum-channel/

But to summarize it would basically be an alternative room to voice and text that allows for "posts", with the main view being an overview and clicking on a post gives a detailed view similar to threads (so that "help" issues or perhaps artistic content like images and video can be discussed in detail with a more intuitive and new user friendly interface compared to threads in a forum like manner). These posts can be assigned a tag so users can filter on tags that they are interested in (tags are set by admins/moderaters for that specific room, so users cannot just add their own).
