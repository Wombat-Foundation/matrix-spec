(See also https://github.com/matrix-org/matrix-doc/issues/2119).

There are some quite small changes we should make to the spec style to make it more readable and align it better with the [style guide](https://matrix-org.webflow.io/style-guide). This includes:

* `font-weight: 400` for body text
* `color: matrix-org/matrix-spec-proposals#333` for all text, including headings
* `background-color: #F4F4F4` for ToC, headings, admonition boxes, and table headings

Does this look like what we want? We could decide to keep more different background colors, although personally I like the more minimal look.

Are there any other changes we might want to make at the same time?

One issue is that some of these styles are coming from the overall site CSS (in particular /docs/css/main.css and /docs/guides/css/docs_overrides.css) and they don't live inside matrix-doc. I'm not sure whether it would be better to override them in matrix-doc's CSS, or to change the site CSS.
