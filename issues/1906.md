Currently [the spec](https://spec.matrix.org/v1.11/client-server-api/#server-behaviour-17) leaves pretty much everything as an implementation detail. Servers appear to all implement the same set of behaviours though, and there are proposals to make the spec more prescriptive: 

* https://github.com/matrix-org/matrix-spec-proposals/pull/4168
* https://github.com/matrix-org/matrix-spec-proposals/pull/4167

This leaves an open question: do we think the spec should be *more* prescriptive generally for room upgrades, or do we prefer to leave this as an implementation detail? This issue tracks that conversation as no specific MSC fits well imo.
