**Link to problem area**: https://spec.matrix.org/v1.16/client-server-api/#post_matrixclientv3register

**Issue**

The Application Service API [mentions](https://spec.matrix.org/v1.16/application-service-api/#server-admin-style-permissions) calling `/register` with a `type` parameter, which appears to disable user-interactive authentication.

However, the documentation of `/register` gives no hint of this parameter existing, nor that UIAA can be skipped in this way. This is somewhat confusing.
