**Link to problem area**:

https://spec.matrix.org/v1.18/appendices/#examples

**Issue**
The spec says:

> Given the following JSON object:
>
> ```json
> {
>     "a": -0,
>     "b": 1e10
> }
> ```
> 
> The following canonical JSON should be produced:
> 
> ```json
> {"a":0,"b":10000000000}
> ```

This implies that implementations must support the syntax `1e10` on incoming JSON. This was added in #1573, and I think it's incorrect. Synapse does *not* allow it (at least, for sensible room versions that forbid floats in events). I think it is legitimate for implementations to *either* canonicalise to 10000000000, *or* reject the JSON.
