**Suggestion**
The Matrix Spec does not strictly adhere to RESTful API best practices (for instance, some URIs contain verbs in their names). The API naming conventions and architecture should be more strongly aligned with RESTful principles as this would allow it to benefit from standardized semantics and make it easier for end users and developers to understand.
