**Link to problem area**: https://spec.matrix.org/v1.4/client-server-api/#mpush_rules

**Issue**

As you can see, there are various PushRule and PushCondition types (because you can set different fields in different places). It would be easier to read if those were called "OverridePushRule", "ContentPushRule", or similar. Same applies to conditions.

Similarly the actions are of type [], which makes you think it is an empty list instead of a list of object|string.
