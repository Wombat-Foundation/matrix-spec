Hello,

in https://github.com/matrix-org/matrix-spec-proposals/pull/4133 and https://github.com/element-hq/synapse/pull/17488 we saw that there will be the possibility to add custom fields to the user profile.

It would be great if there would also be the possibility to save such key:value pairs to rooms (via API) to add arbitrary information to the room. In our use case we need some further information to a room like the function group which created the room or an organisational unit the room belongs to and a few more data kind like this. This data could be saved directly to the room but we could also imagine an equivalent structure for rooms like the existing user profle for users. In short a place where to put all kinds of additional data for a room.

Before we start to write a MSC we would like to discuss this topic here.

What do you think about it? Are there already any considerations or plan to store such kind of data?
