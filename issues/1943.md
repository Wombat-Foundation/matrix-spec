**Issue**

Similar to https://github.com/matrix-org/matrix-spec/issues/1913, the spec currently restricts custom capabilities to object types. This rules out potentially viable other types such as booleans or arrays.

The original [MSC](https://github.com/matrix-org/matrix-spec-proposals/pull/1753/files#diff-64defa705e0c3cdc56f8b457ea856bce3d077cc750d2a39f389be8decb10b80dR33-R34) doesn't appear to specify any type restriction for individual capabilities. Therefore, I suspect this got added to the spec accidentally.
