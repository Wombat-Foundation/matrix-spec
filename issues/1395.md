**Current spec for m.room.message is defined here:**
https://spec.matrix.org/v1.5/client-server-api/#mroommessage-msgtypes

**Problem:**
We tried to use Matrix for delevery of rich microblogging-style messages to rooms using the m.text and formatted_body, but efforts were handicapped by insufficient HTML table layouts.

Regarding HTML table, only following elements are highlighted without specifying what attributes are supported:
table, thead, tbody, tr, th, td, caption, span, summary


**Proposal;**
Extend supported HTML table elements and attributes to support more complex and useful table layouts without compromising security.

HTML 4.0 table spec is used as a guideline:
https://www.w3.org/TR/html401/struct/tables.html

This proposal does not include CSS.


We want following to be included in to m.room.message spec:


1. ``<TABLE border>``: The "border" is allowed and defaults to 0. border = pixels. Eg. ``<TABLE border="1" >``

2. ``<TABLE width>``: The "width" is allowed and defaults to 100%. width = length. Eg. ``<TABLE width="100%" >``. The length is as per the above HTML 4.0 spec, a percentage or a pixel value. When the value is a percentage value, the value is relative to the available horizontal space.

3. ``<TABLE margin>``: The "margin", "margin-top", "margin-right", "margin-bottom" and "margin-left" are allowed and defaults to 0.
Eg. ``<TABLE margin-bottom="10">``

Values for "margin" as per the CSS standard.
Eg.
    auto - the browser calculates the margin.
    length - specifies a margin in px, em, etc.
    % - specifies a margin in % of the width of the containing element.
    inherit - specifies that the margin should be inherited from the parent element.

4. ``<TABLE padding>``: The "padding", "padding-top", "padding-right", "padding-bottom" and "padding-left" are allowed and defaults to 0.
Eg. ``<TABLE padding-bottom="10">``

Values for "padding" as per the CSS standard.
Eg.
    length - specifies a padding in px, em, etc.
    % - specifies a padding in % of the width of the containing element
    inherit - specifies that the padding should be inherited from the parent element

5. ``<TH rowspan>`` is accepted. Eg. ``<TH rowspan="N">``. N is number of rows to span.

6. ``<TH colspan>`` is accepted. Eg. ``<TH colspan="N">``. N is number of colmns to span.

7. ``<TH align>`` is accepted. Eg. ``<TH align="right">``.
This attribute specifies the alignment of data and the justification of text in a cell. Possible values:
    left: Left-flush data/Left-justify text.
    center: Center data/Center-justify text. This is the default value for table headers.
    right: Right-flush data/Right-justify text.
    justify: Double-justify text.

8. ``<TH valign>`` is accepted. Eg. ``<TH valign="top">``.
This attribute specifies the vertical position of data within a cell. Possible values:
    top: Cell data is flush with the top of the cell.
    middle: Cell data is centered vertically within the cell. This is the default value.
    bottom: Cell data is flush with the bottom of the cell.
    baseline: All cells in the same row as a cell whose valign attribute has this value should have their textual data positioned so that the first text line occurs on a baseline common to all cells in the row. This constraint does not apply to subsequent text lines in these cells.

9. ``<TH margin>``: The "margin", "margin-top", "margin-right", "margin-bottom" and "margin-left" are allowed and defaults to 0.
Values for "margin" as per the CSS standard.

10. ``<TH padding>``: The "padding", "padding-top", "padding-right", "padding-bottom" and "padding-left" are allowed and defaults to 0.
Values for "padding" as per the CSS standard.

11. ``<TH bgcolor>`` is accepted. Eg. ``<TH bgcolor="6-character hex color code">``. Eg. ``<TH bgcolor="#FF5733">``. A dark red.

12. ``<TD rowspan>`` is accepted. Eg. ``<TD rowspan="N">``. N is number of rows spanned by cell.

13. ``<TD colspan>`` is accepted. Eg. ``<TD colspan="N">``. N is number of cols spanned by cell.

14. ``<TD width>`` is accepted. Eg. ``<TD width="length">``. The length is as per the above HTML 4.0 spec, a percentage or a pixel value. When the value is a percentage value, the value is relative to the available horizontal space.

15. ``<TD align>`` is accepted. Eg. ``<TD align="right">``.
This attribute specifies the alignment of data and the justification of text in a cell. Possible values:
    left: Left-flush data/Left-justify text. This is the default value for table data.
    center: Center data/Center-justify text.
    right: Right-flush data/Right-justify text.
    justify: Double-justify text.

16. ``<TD valign>`` is accepted. Eg. ``<TD valign="top">``.
This attribute specifies the vertical position of data within a cell. Possible values:
    top: Cell data is flush with the top of the cell.
    middle: Cell data is centered vertically within the cell. This is the default value.
    bottom: Cell data is flush with the bottom of the cell.
    baseline: All cells in the same row as a cell whose valign attribute has this value should have their textual data positioned so that the first text line occurs on a baseline common to all cells in the row. This constraint does not apply to subsequent text lines in these cells.

17. ``<TD bgcolor>`` is accepted. Eg. ``<TD bgcolor="6-character hex color code">``. Eg. ``<TD bgcolor="#FF5733">``. A dark red.


18. ``<TD margin>``: The "margin", "margin-top", "margin-right", "margin-bottom" and "margin-left" are allowed and defaults to 0.
Values for "margin" as per the CSS standard.

19. ``<TD padding>``: The "padding", "padding-top", "padding-right", "padding-bottom" and "padding-left" are allowed and defaults to 0.
Values for "padding" as per the CSS standard.
