Some rooms might want to go from `m.federate: true` to `m.federate: false` or fix power levels which they cannot otherwise do (everyone is an admin, oops). Similar to `/createRoom`, there could be a parameter on the request body to override the state that's going to be set in thew new rooms.

The problem with this would be the large avenue for abuse: someone with enough permission could effectively lock out everyone else by simply upgrading the room.
