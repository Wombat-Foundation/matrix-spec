**Link to problem area**: https://spec.matrix.org/v1.1/client-server-api/#get_matrixclientversions

**Issue**
Currently, `unstable_features` is defined as "Experimental features the server supports. Features not listed here, or the lack of this property all together, indicate that a feature is not supported."

However, this gives no insight in the kind of mapping that this is, is this `string -> string`? `string -> bool`? `string -> any`?

The precedent seems to be that its `string -> bool`, but this has to be confirmed.
