Have some functionality in the protocol that allows for assigning one or more roles. I don't think this should be tied into the permission system and rather be solely used for grouping users together. Pinging all people with a certain role would be nice too. The permission system has been abused for that until now, but that feels too restrictive (e.g. you're not able to assign more than one "role" to a user).
