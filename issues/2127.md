**Link to problem area**:

Working out the scope of protocol use cases.

For example, what events are required to send a E2EE message between two parties. Similarly for receive.
Or a different one, what is the set of events required to securely CRUD a room with `N` participants, etc. As well as issue #2124.

**Issue**
> What is wrong? 

There is no succinct list/statement of what are the set of core-events in the protocol. But the idea exists with some prominence (["... Matrix specification defines a number of event types which are considered core to the protocol."](https://matrix-org.github.io/matrix-rust-sdk/matrix_sdk/ruma/events/index.html)). It would also be useful in some other contexts (#129, #2124).

> How can we improve?

Have a single page listing the set of core-events. Defining the core-event set is aided by a definition of scope. Say, for example, "Events required to pass a E2EE message between two parties.", or some variation on that .
