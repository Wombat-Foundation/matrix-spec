In [POST /_matrix/client/r0/account/3pid](https://matrix.org/docs/spec/client_server/unstable#post-matrix-client-r0-account-3pid), there is an example response:

```
{
  "submit_url": "https://example.org/path/to/submitToken"
}
```

that suggests the API could return a `submit_url`, but this seems like a spec bug, as it doesn't make sense to have a submit URL here.
