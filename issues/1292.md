**Link to problem area**: https://spec.matrix.org/v1.4/client-server-api/

**Issue**
Glyphs in the font "Inter" that contain overlapping shapes are even-odd filled, such as A and Q. This is exactly the problem/symptom described in the following issue (plenty of screenshots available there): https://github.com/google/fonts/issues/2602

OS: macOS Catalina 10.15.7 (19H2026)

Browsers I've tested, all of which are affected by this:
- Google Chrome 106.0.5249.119 (stable)
- Firefox 105.0.3
- Safari 15.6.1 (15613.3.9.1.16, 15613)

My understanding from the linked Google Fonts issue thread and `static/css/fonts/README.md` is that this is due to Google Fonts URLs changing their response depending on the User-Agent string, and you are fetching them using a different browser or OS from those above, and thus storing/using font files that don't work properly on my system.

For reference, when I visit <https://fonts.googleapis.com/css?family=Inter> on the affected system, here is the response in all browsers I tested, which I expect will differ from the response your build server receives:
