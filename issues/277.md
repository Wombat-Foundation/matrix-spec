Server-Server [Section 17](https://matrix.org/docs/spec/server_server/unstable.html#signing-events) does not list `redacts` as an essential key.

As a non-essential key it is not included in JSON-signing and verification. An unsigned key is subject to arbitrary modification. An attacker can then redirect the target of a redaction event to any other event with the same authority as the sender.
