Most DMs are nameless, so that for either party, the name of the other member shows.
Room aliases for DMs are quite useful - but not if they "grab" the room name, so that no longer the name of the other member shows.
For normal rooms this does not happen, so having the same (non-)behaviour for DMs should be a - very welcome - simplification of both the spec and of implementations.
