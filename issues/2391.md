I ran a Matrix server several years ago, but I still get requests for `/.well-known/matrix/server` every few minutes. Those requests respond with error 410, which, according to the HTTP spec, means the resource is permanently gone and should not be requested again. Despite this, servers, including Synapse, continue to request `/.well-known/matrix/server`. Matrix servers should respect 410 responses and stop requesting `/.well-known/matrix/server`.
