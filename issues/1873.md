**Link to problem area**:
https://github.com/matrix-org/matrix-spec/blob/7773716d189b16c1d5fa1dd2bfb8a1685bfb1108/data/api/client-server/content-repo.yaml#L226 and elsewhere in the same file.

**Issue**
API description files can be used by code generation tools, and our own [API viewer](https://playground.matrix.org) consumes them. See, for example [`GET /_matrix/media/v3/download/{serverName}/{mediaId}`](https://playground.matrix.org/#get-/_matrix/media/v3/download/-serverName-/-mediaId-). While it's still sort of readable through the handlebars, I'd rather stick to Markdown in API files.
