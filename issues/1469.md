This means we should specify a maximum limit on the number of `events` sent. Unstable MSCs for Appservices such as:

- https://github.com/matrix-org/matrix-spec-proposals/pull/3682
- https://github.com/matrix-org/matrix-spec-proposals/pull/3395
- https://github.com/matrix-org/matrix-spec-proposals/pull/2409
- https://github.com/matrix-org/matrix-spec-proposals/pull/3202

Will need to also specify their maximum sizes. This is needed because most HTTP listeners will specify a maximum body size for incoming requests, and in practice this is often exceeded when the AS receives a lot of traffic at once. For example, [Nginx defaults to 1MB](https://nginx.org/en/docs/http/ngx_http_core_module.html#client_max_body_size) and while we shouldn't arbitrarily restrict the spec to what nginx supports, it's clear that an unlimited number of events will cause great pain.
