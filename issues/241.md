In a `m.olm..` encrypted message, `ciphertext` is a JSON object containing the following:

    {
      <sender_key>: {
        "body": <body>,
        "type": <type>
      }
    }

In a `m.megolm..` encrypted message `ciphertext` contains a single string: 

    <body>

It might make sense for both to be specified by a singular format independent of algorithm?
