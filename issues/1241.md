**Link to problem area**: https://spec.matrix.org/v1.3/server-server-api/#typing-notifications and https://spec.matrix.org/v1.3/client-server-api/#typing-notifications

**Issue**

In the SSAPI we transmit the fact "User X is [not] typing in room R" `m.typing`.
In the CSAPI we transmit the fact "Users X, Y, Z are currently typing in room R" `m.typing`.

This is an opportunity for confusion. The expected structure for an event would ideally be determined by its type alone without any other context.
