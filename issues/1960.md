I would love to see tapback reactions, in which you can react to a reaction, just like or iMessage.

Reason:
Soooo many times, I find myself wanting to react to a reaction.
It would be a REALLY strong magnet towards Matrix, for non Matrix users.

It should be added to the protocol+ Element (X) first, then clients can add their own implementations.

Also, support for these should be added to Synapse as well, so that servers can incorporate the feature easily.

Perhaps, needing to make reactions end to end encrypted may become necessary.
