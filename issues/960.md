**Suggestion**

Messages that have a specific section in them that are meant to be copied (i.e. 2FA).

The most interesting use case for this is being able to have a button (at least on Android) which allows you to copy that part directly from the notification panel (this is an existing feature of many SMS apps, from Google or the ones from the manufacturers). An example of something similar can be found with G-Mail - being able to open a link without opening the E-Mail (for example GitHub issuemake use of this).
