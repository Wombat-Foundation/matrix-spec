**Link to problem area**: https://spec.matrix.org/v1.18/client-server-api/#room-summaries

**Issue**

The room summary API is missing a lot of the clarity given by [MSC3266](https://github.com/deepbluev7/matrix-doc/blob/room-summaries/proposals/3266-room-summary.md), for example what MAY be done for unauthenticated requests and guidance on 403 and 404 for rooms which require authentication or a user does not have access to.
