The OpenAPI specs for most of the APIs are available at `https://spec.matrix.org/{version}/{api}/api.json`. Examples:

 * https://spec.matrix.org/latest/client-server-api/api.json
 * https://spec.matrix.org/v1.7/application-service-api/api.json
 * https://spec.matrix.org/latest/push-gateway-api/api.json

However, the server-server api is not there. Previously, this was due to invalid data (https://github.com/matrix-org/matrix-spec/issues/14), but that is now fixed. We should update https://github.com/matrix-org/matrix-spec/blob/a147b977b3ab39d1ba44335edc0921558431de46/.github/workflows/main.yml#L95-L109 to publish the APIs.
