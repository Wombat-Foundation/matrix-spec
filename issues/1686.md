**Link to problem area**:
[Link](https://spec.matrix.org/v1.9/client-server-api/#put_matrixclientv3roomsroomidstateeventtypestatekey)

**Issue**
Specification says: 
"State events can be sent using this endpoint. These events will be overwritten if room id, event type and state key all match."

Under [Link]( https://spec.matrix.org/v1.9/client-server-api/#types-of-room-events) its stated, that 
"State events: These are events which update the metadata state of the room (e.g. room topic, room membership etc). State is keyed by a tuple of event type and a state_key. **State in the room** with the same key-tuple will be **overwritten**."



**Expected behaviour**
I assume that for the /_matrix/client/v3/rooms/{roomId}/state/{eventType}/{stateKey}  endpoint, also the change of the state and not overwriting of the event is supposed to be done. Otherwise the DAG (graph) of state events is destroyed.
