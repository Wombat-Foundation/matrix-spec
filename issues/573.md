Currently, when a room is upgraded the clients are not required to suggest join candidates in the join request to the homeserver. However, without such information the joining homeserver would not know which resident server to send the make_join and send_join requests. (The m.room.tombstone contains a room ID of the new room.)

The clients therefore should suggest the server from the author's user ID as a join candidate.

This detail seems to have gotten lost between MSC1501 proposal and the resulting spec PR.
