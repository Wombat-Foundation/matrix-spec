**Description:**

Please note, this is Matrix specification extend proposal.
Referring to: https://spec.matrix.org/v1.5/client-server-api/#mtext

The stats block (see the image below) currently appear only if someone add a reaction to a message.

![Screenshot from 2023-01-02 19-06-12](https://user-images.githubusercontent.com/94213268/210223513-33ba1606-5dbc-43ac-a43a-01c59e94e464.png)

Drawback of the current way is, users are not aware the message can be reacted.

I propose a message-level stats block control property, hypothetically named statBlock, where message sender control the initial rendering of a message.

The statBlock by default is false as now.

If statBlock is true for the message, then client should render the stats block even for zero reaction.
