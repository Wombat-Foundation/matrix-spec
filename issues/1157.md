**Issue**
The quoted bit of go template language seems to only look for an example defined under the key `application/json`. This means we can provide at most one example for a response in the text of the spec. Sometimes this is an obstacle, e.g. if the same HTTP status code is used to indicate two different error conditions and we wish to give an example of both.
