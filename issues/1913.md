**Link to problem area**:

https://spec.matrix.org/v1.11/client-server-api/#getwell-knownmatrixclient

https://github.com/matrix-org/matrix-spec/blob/d9c447e194180df5efa75ab25803d317d7df5f7f/data/api/client-server/definitions/wellknown/full.yaml#L25

**Issue**

The spec currently allows additional properties of type `object` in the response of `GET /.well-known/matrix/client`. It's unclear whether this actually intended to restrict values to JSON objects or not.

I cannot think of a reason why only objects should be allowed and FWIW [MSC4158](https://github.com/matrix-org/matrix-spec-proposals/pull/4158) attempts to introduce a property `m.rtc_foci`of type `array`.
