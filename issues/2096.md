Spec changes can be annotated with e.g. `x-addedInMatrixVersion` to indicate the version of the spec that something was added in. However, as an author not involved with the SCT, I don't know whether my contribution will actually be merged before the next spec release. Additionally, I don't know the specific number of that release either (though I can guess that it'll be 1.X+1).

It would be great if instead of having to guess, track and update the specific version in my PRs, I could just say something like `x-addedInMatrixVersion: vNext` and then we would script-replace `vNext`with the concrete version during release of the spec.
