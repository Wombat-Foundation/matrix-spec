**Link to problem area**:
- https://spec.matrix.org/v1.4/client-server-api/#put_matrixclientv3directorylistroomroomid
- https://spec.matrix.org/v1.4/application-service-api/#put_matrixclientv3directorylistappservicenetworkidroomid

**Issue** The former says 

> The new visibility setting for the room. Defaults to ‘public’. 
>
> One of: [private, public].

The latter says

> Required: Whether the room should be visible (public) in the directory or not (private).
>
> One of: [public, private].

Synapse
- matches the CS API as described above :heavy_check_mark:
- allows `visibility` to be optional in the Appservice API, [defaulting to `public`](https://github.com/matrix-org/synapse/blob/2019b60f3bb5a505fc730f38a4b1accbabe444bf/synapse/rest/client/directory.py#L170) :warning: 

Either
- the inconsistency is intended: Synapse is mistaken and not spec-compliant; or
- the inconsistency is unintentional and we ought to mandate it in the spec.

I've raised this issue assuming the latter is true, but if not we can move this issue to the Synapse repo.
