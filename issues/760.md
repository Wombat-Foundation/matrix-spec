From https://github.com/matrix-org/matrix-doc/pull/2959#issuecomment-762636762:

> Section numbers add a lot of visual clutter to the TOC sidebar ("12.14.1.3.2 Conditions"; the section number is longer than the section title). I would recommend to de-emphasize the numbers somehow, for example by using a lighter text color for them, to make the TOC easier to scan.
