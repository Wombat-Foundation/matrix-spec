The API is called [`/_matrix/client/v3/pushrules/`](https://spec.matrix.org/v1.6/client-server-api/#get_matrixclientv3pushrules)

However the push rules are returned in an account_data event of type [`m.push_rules`](https://spec.matrix.org/v1.6/client-server-api/#mpush_rules).
