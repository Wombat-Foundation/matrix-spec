**Link to problem area**: https://spec.matrix.org/v1.2/rooms/v9/#definitions

**Issue**

> Given an m.room.power_levels event P, the mainline of P is the list of events generated by starting with P and recursively taking the m.room.power_levels events from the auth_events, ordered such that P is last.

There are two ways to interpret `recursively taking the m.room.power_levels events from the auth_events`.

1. Start with P0. Retrieve P1, the power level event in P0's auth events. Retrieve P2, the power level event in P1's auth events. Continue to retrieve P_i until you reach an event with no power level auth event. The mainline of P is the list `[P_n, P_{n-1}, ..., P_2, P_1, P_0]` of all power events found.

2. Start with P0 and compute its auth chain C. The mainline of P is the set { power level events in A's auth events | A is in C }... ordered... somehow.

On first reading this, I thought definition (2) was intended (and Rich concurred, but then wasn't sure).  @erikjohnston confirms that (1) is intended.
