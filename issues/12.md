**Link to problem area**: https://spec.matrix.org/v1.2/#legacy-versioning

**Issue**
The above clarifies a support matrix for backwards definition linking as "v1.0 support", however, it does little to define how to actually detect such v1.0 support.

https://github.com/ruma/ruma/issues/852 raises some questions about this;
- Should v1.0 be determined to be supported if any of the above revisions appear in `/versions`?
  - Should it only be if *all* are detected?
  - Should it be only on `r0.6.1` or `r0.6.0`?
  - Should it be on *any* `r*` version?
- Should it (additionally) also be determined if a server sends a `v1.0` string in there?
