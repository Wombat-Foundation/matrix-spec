```json
{
    "action": "set_always_on_screen",
    "api": "fromWidget",
    "data": {
        "value": true
    },
    "requestId": "generated-id-1234",
    "widgetId": "20200827_WidgetExample"
}
```

`requestId` is lowerCamelCase whereas the `set_always_on_screen` action is snake_case.
