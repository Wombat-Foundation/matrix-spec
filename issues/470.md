Additionally to how filters currently work there should be a way to pre-filter stuff like

`/_matrix/client/r0/sync/account_data`

`/_matrix/client/r0/sync/rooms`

`/_matrix/client/r0/sync/next_batch`

or even further like


`/_matrix/client/r0/sync/presence/@user:matrix.org`

`/_matrix/client/r0/sync/rooms/!roomid:matrix.org`

`/_matrix/client/r0/sync/rooms/invite`

this is not only more consistent to how the rest of the API works but also much more convenient and easier than using filters which should in return only be used to fine tune your request if needed.

Furthermore these should only return the data within the parameter, e.g. not loading account_data when I only want presence states.
