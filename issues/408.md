It would be nice to have a way for users to provide hand-crafted small resolution images for icons for things like flair, room avatars, even user avatars - so that when these avatars are used as favicon-style thumbnails, we have a pixel perfect avatar rather than a bluntly scaled down version of a larger image.

It feels to me like this is something that the media repo API should support, so that a user can upload alternative images for a given URL to 'seed' the lower resolution variants.
