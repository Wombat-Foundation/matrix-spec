**Link to problem area**: https://arewep2pyet.com/

**Issue**
According to Are we p2p yet, it is intended for P2P Matrix to be bridged to the main protocol through
> A server which can bridge traffic between P2P and normal matrix e.g @ed25519-key:server-name.com or a bridge.

I wonder what’s the current thinking on implementing this bridging server. My concern is it could potentially create a point of failure like `matrix.org` which can get blocked in hostile nation-states (China, Iran, etc.), thus wiping out the very benefit of using P2P in those situations.
