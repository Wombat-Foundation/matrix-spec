A way to http `PATCH` to modify state events.

Similar to the following:

```http
PATCH /rooms/$ROOM_ID/state/m.room.power_levels HTTP/1.1

{
    "users": {
        "@foo:bar.baz": 100
    }
}
```

The request json would be merged with the current json and be used for the new state event.
