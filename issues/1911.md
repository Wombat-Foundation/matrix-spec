**Link to problem area**:

Search for the term "DNS name" on https://spec.matrix.org/v1.11/server-server-api.

**Issue**

The SS API uses the term "DNS name" in a number of places, for instance when describing the `{serverName}` path component in [`GET /_matrix/key/v2/query/{serverName}`](https://spec.matrix.org/v1.11/server-server-api/#get_matrixkeyv2queryservername).

![Screenshot 2024-07-18 at 09 45 46](https://github.com/user-attachments/assets/37292a27-21fe-4978-acae-bc553101ac2f)

The appendices in turn define a "DNS name" as one possible option for the `hostname` part of ["server names"](https://spec.matrix.org/v1.11/appendices/#server-name).

I suspect that the SS API merely uses the term "DNS name" as a transliteration of the "server name" term defined in the appendices. To avoid any confusion though, I think it might be better to just stick to "server name" and link out to its definition in the appendices.
