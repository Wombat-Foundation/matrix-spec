**Description:**

Please note, this is Matrix specification extend proposal.
Referring to: https://spec.matrix.org/v1.5/client-server-api/#mtext

Replies block (see the image below) currently appear only if someone reply a message.

![Screenshot from 2023-01-02 18-57-47](https://user-images.githubusercontent.com/94213268/210222501-553ae99f-a369-4724-8b21-7dbd0b8a85e8.png)

Drawback of the current way is, users are not aware the message can be replied in a thread without clutter.

I propose a message-level replies block control property, hypothetically named replyBlock, where message sender control the initial rendering of a message.

The replyBlock by default is false as now.

If replyBlock is true for the message, then client should render the reply block even for zero reply.
