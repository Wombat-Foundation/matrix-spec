When creating a room admins would be able to: 

- Set answerable questions for users who request to join
- Limit how many messages users can send in a row
- Limit how many stickers or media files users can send in a row or within defined period of time
- Ban sending of certain media files or all the media files
- Create customized right sets for people. Right sets could be saved in some kind of right set pack like sticker pack. There could be for example type 1 users: are able to do everything and have admin rights, type 2 users: can send everything but no admin rights, type 3 users: can only send text messages.
