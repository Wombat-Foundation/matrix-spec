I'd like to see a standardized way to store local user remarks (client-side display aliases) in Matrix, allowing users to assign custom names to contacts or rooms without modifying server-side  display_name  data. Similar features exist in other platforms:

 - XMPP
 - Telegram
 - Signal
 - Wechat

Secret storage can be utilised: https://spec.matrix.org/v1.14/client-server-api/#secrets
