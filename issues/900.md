**Link to problem area**: https://spec.matrix.org/unstable/appendices/#matrixto-navigation

**Issue**

This area contains the following text:

> The components of the matrix.to URI (`<identifier>` and `<extra parameter>`) are to be percent-encoded as per RFC 3986.
>
> Examples of matrix.to URIs are:
>
> * Room alias: `https://matrix.to/#/%23somewhere%3Aexample.org`
> * Room: `https://matrix.to/#/!somewhere%3Aexample.org`
> * Permalink by room: `https://matrix.to/#/!somewhere%3Aexample.org/%24event%3Aexample.org`
> * Permalink by room alias: `https://matrix.to/#/%23somewhere:example.org/%24event%3Aexample.org`
> * User: `https://matrix.to/#/%40alice%3Aexample.org`

In those examples, `!` is not percent-encoded despite being listed by as a reserved character (to be percent-encoded) by RFC 3986: https://datatracker.ietf.org/doc/html/rfc3986/#page-13

**Expected behaviour**

The `!`s should be percent-encoded, and ideally the characters to be percent-encoded would be listed directly in the spec because digging up the relevant section from the RFC was not easy.
