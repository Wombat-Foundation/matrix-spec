Can we implement the telegram's topic feature? It is an easy way to use matrix as a forum by changing basically nothing. Basically groups with topic option enabled are simple groups where topic are just pinned messages in the protocol, and every message that respond to the pinned message is an answer to the topic. Then it is the GUI of the app that manages everything to be seen as different topics. All messages that does not respond to anything go to a default topic called chatting or something, so it is also retrocompatible with older clients who does not support topics.

The difference with just create different channels/groups are that anyone can create a topic in a channel, so there will be a lot of topics, they are not like rooms. Have a look at https://t.me/durovschat to understand what I'm talking about.

I would like to have something like a forum on matrix, so federated.
