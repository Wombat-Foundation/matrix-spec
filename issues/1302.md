**Link to problem area**:
https://spec.matrix.org/v1.4/client-server-api/#get_matrixclientv3roomsroomidmembers

**Issue**
The spec states:
> The point in time (pagination token) to return members for in the room. This token can be obtained from a `prev_batch` token returned for each room by the sync API. Defaults to the current state of the room, as determined by the server.


Unclear if `at` should be `next_batch` (which Element Android and Element Web seem to use) or actually the `prev_batch` for the specific room.
Having implemented `at` in Dendrite and seeing that Element Web uses the `next_batch` here instead was a bit confusing. No idea if the spec is wrong or it's an issue with the client implementation?
