**Link to problem area**:
https://spec.matrix.org/v1.9/server-server-api/#get_matrixfederationv1hierarchyroomid

**Issue**
There are two different types with the name `PublicRoomsChunk`, with the only difference being that the latter has a `children_state` field which the other doesn't. In [ruma](https://ruma.io), it is assumed that the [former is for the `children` field](https://docs.rs/ruma/latest/ruma/api/federation/space/struct.SpaceHierarchyChildSummary.html), and the [latter is for the `room` field](https://docs.rs/ruma/latest/ruma/api/federation/space/struct.SpaceHierarchyParentSummary.html). However, in the example request in the spec, both the `children` and `room` fields use the `children_state` field, so it is unclear whether the example is correct and they should both have the `children_field`, ruma is correct and only the `room` field should have that, or even maybe the `children` field should have that and the `room` field shouldn't.
Either way, they really should either be merged (for the former solution), or have different names (for the others).
