**Issue**

- What happens if you try to GET or PUT account data for a different user? Synapse returns 403 with M_FORBIDDEN.
- What happens if you try to GET or PUT account data to a user_id that isn't a matrix id? 403 probably suffices, but 400 might also be appropriate.
- What happens if you try to GET a `type` of account data which isn't stored on the server? Synapse returns 404.
- Synapse also special-cases an attempt to PUT `m.fully_read`:,returning 405 (Method not allowed).
  - https://github.com/matrix-org/synapse/blob/e24ff8ebe3d4119d377355402245947f7de61c00/synapse/rest/client/account_data.py#L109-L114
  - Ahh, this is mandated by https://spec.matrix.org/v1.3/client-server-api/#server-behaviour-10
