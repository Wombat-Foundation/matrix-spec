[Section 5.3.6.1](https://matrix.org/docs/spec/client_server/latest#matrix-user-id) says:

> A client can identify a user using their Matrix ID. This can either be the fully qualified Matrix user ID, or just the localpart of the user ID.

It is not clear whether "just the localpart" includes the leading `@` or not.
