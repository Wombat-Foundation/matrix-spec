**Suggestion**
Add a feature to set reminders on specific messages mimicking the "Remind me about this" feature in slack


In slack you can (see https://slack.com/intl/en-gb/help/articles/208423427-Set-a-reminder):
- In any conversation, hover over a message or file.
- Click the three dots icon in the top-right corner of the message or file, then select Remind me about this.
- Choose a time from the list, or select Custom time to pick your own.

This is a great way to handle messages that are important but not urgent, so that they don't get lost.
