**Link to problem area**: https://spec.matrix.org/v1.2/client-server-api/#get_matrixclientv1roomsroomidhierarchy

**Issue**

The `PublicRoomsChunk` documentation in the response section to the `GET …/hierarchy` endpoint has this to say about the `join_rule` field:

> The room’s join rule. When not present, the room is assumed to be `public`.

However, it does not mention any fields that define the rules by which one is allowed to join the room. Is the idea there that seeing the room in the response at all means that the user who issued the request is allowed to join?

In practice, Synapse sends a `allowed_room_ids` which covers the only currently-specced type of allow condition, but represented in a different way than the same condition is represented in the room's `m.room.join_rules` (array of room IDs vs. array of objects).
