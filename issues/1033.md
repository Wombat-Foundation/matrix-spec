**Link to problem area**: https://spec.matrix.org/v1.2/rooms/v2/#event-format

**Issue**
The PDU format has the following in the example;
```json5
{
  // ...
  "prev_events": [
    "$af232176:example.org",
    {
      "sha256": "abase64encodedsha256hashshouldbe43byteslong"
    }
  ],
  // ...
}
```

I believe that this sha256 hash is meant to be formatted differently than inside a separate object.
