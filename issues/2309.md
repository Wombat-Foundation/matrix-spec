**Suggestion**

When a thread is created from a message it would be nice to be able to choose to "follow" the thread to receive notification from that thread (an option to opt in to notification from threads). This would probably alleviate notification spam, and yes the concept is from Mattermost.

P.S. This might be a bad implementation of a previous spec of the Elements desktop application, but when using the application at the company I work at there a lot of threads that send notifications to multiple people that are not participating in them.
