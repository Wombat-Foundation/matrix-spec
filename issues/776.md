Affects the redesign table rows and columns are pretty hard to distinguish imo, for several reasons:

### On my monitor, the row colors are barely distinguishable:

![grafik](https://user-images.githubusercontent.com/16312324/109962316-f16f7a00-7ce2-11eb-8560-5de46470ac2d.png)

On my monitor in daylight, I can't really distinguish those 2 rows well. This probably is also an accessibility issue for people with bad eyesight, that need high contrast.

### The table header is not visually part of the table:

![grafik](https://user-images.githubusercontent.com/16312324/109962571-44e1c800-7ce3-11eb-883a-ff0f4848949c.png)

Visually the table header is part of the headings, not part of the table, since it shares the bold font, background color and size.

### Tables are too "large"

The new spec wastes a lot of vertical space with padding on the left and right as well as horizontally, which makes most tables too big to fit on my screen. Which is why the comparison screenshot is cut off (in the table table section), I simply can't fit that on my screen anymore to compare it, which I think is pretty bad for a spec, that is 90% tables (not actually, but it feels like that sometimes, when you look for specific stuff). Not fitting full tables and maybe even multiple on the screen makes it much easier to miss stuff.

### Suggestions to improve legibility

- Give table headers a background color to make them part of the table
- Maybe add borders around the cells in the table and maybe even the table itself. That way the color is not the primary orientation method. The border should have a very distinguishable color.
- Maybe to align the table values? The you could have at least one visual line to orient yourself
- Reduce the row distance and font size in tables, as well as make them grow past the padding on the right. The latter is a separate issue though (#3042).
