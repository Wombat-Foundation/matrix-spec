**Link to problem area**: https://spec.matrix.org/v1.13/client-server-api/#get_matrixclientv3sync

**Issue**
The example events for the /sync response include the `room_id`.

**Expected behaviour**
They should not include the `room_id`, because the spec text above says so. This is a very scary trap for client devs!

For reference:

https://matrix.org/docs/spec/client_server/r0.4.0#get-matrix-client-r0-sync is correct and does not include them, but for 0.5.0 of the spec, this was refactored to include the example events from a common directory. Everywhere else events usually have a room_id, but not in /sync, but there is no way to strip that out afterwards just for the /sync spec. Specifically these lines cause the issue: https://github.com/matrix-org/matrix-doc/blob/client_server/r0.5.0/api/client-server/sync.yaml#L405

A possible solution is to just hardcode a /sync example or somehow figure out how to not include the `room_id` when using references.
