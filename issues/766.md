In a few places the spec links to `POST /_matrix/client/r0/account/3pid`:

https://github.com/matrix-org/matrix-doc/blob/315cf67f6b713e0bfeb99527767e2d65c4d8e11f/specification/client_server_api.rst#L710

https://github.com/matrix-org/matrix-doc/blob/315cf67f6b713e0bfeb99527767e2d65c4d8e11f/specification/client_server_api.rst#L989

https://github.com/matrix-org/matrix-doc/blob/315cf67f6b713e0bfeb99527767e2d65c4d8e11f/specification/client_server_api.rst#L1009

https://github.com/matrix-org/matrix-doc/blob/315cf67f6b713e0bfeb99527767e2d65c4d8e11f/specification/client_server_api.rst#L1047

These links don't work. I think this is because the API is now deprecated, so its ID is `deprecated-post-matrix-client-r0-account-3pid`, not `post-matrix-client-r0-account-3pid`.

I would have just fixed this in https://github.com/matrix-org/matrix-doc/pull/2988, but then thought: if it's deprecated, should we not update the spec content to stop suggesting that people use it?
