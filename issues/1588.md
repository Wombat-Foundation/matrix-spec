### Description

Enhancement request to support request-side hint for disabling url preview for Client-Server API's m.room.message (text or notice).

My use-case is the bot that periodically sends notifications to certain chat. While I want URL previews be generally available for this chat, I don't want these bot messages to show URL preview.

I see it as smth like this:
```json
{
  "msgtype": "m.text",
  "format": "org.matrix.custom.html",
  "formatted_body": "<a href='...'>text</a>",
  "body": "[md text](md link)",
  "hints": ["m.hint.no_preview"]
}

```
or this
```json
{
  "msgtype": "m.text",
  "format": "org.matrix.custom.html.no.preview",
  "formatted_body": "<a href='...'>text</a>",
  "body": "[md text](md link)",
}

```

If I need to create issue somewhere else, please advise.
Thanks in advance.
