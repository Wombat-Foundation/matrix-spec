**Suggestion**

I would like to specify reply format in one place (account data/state?) and have all clients use it.

Currently when I start typing a name and press tabulator, I get `name: ` with name being a pill. I would like to instead get a "name, " as I view that as more human thing to do (and as many disagree and believe ":" to be better or wish to have something entirely different from ",", I think this should be an option)

See also: https://github.com/matrix-org/matrix-appservice-irc/issues/1441 which inspired me to open this.
