**Link to problem area**: https://spec.matrix.org/v1.2/server-server-api/#resolving-server-names

**Issue**

It's not clear whether a .well-known response MUST use a `Content-Type` of `application/json` or whether it's acceptable to ignore that field and try to parse the response as JSON anyway. Synapse prefers to do the latter (as it does for most APIs?).

https://spec.matrix.org/v1.2/server-server-api/#api-standards mentions that "all API calls use a Content-Type of application/json" but it's not clear whether calls *not* using that should be rejected.
