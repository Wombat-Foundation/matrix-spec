**Suggestion**
matrix spec addition to add ability to request the first x seconds of video or a downscaled image, to be displayed while full contents/full resolution image downloads in background. This is what is done on most social media and it significantly improves loading times. I have had many people i told matrix about complain to me about slow media downloads due to a slow matrix homeserver, and this would really help to resolve that.
