**Is your feature request related to a problem? Please describe.**
Sometimes I want to search for specific stuff in a room when peeking, without having to join it. It is already possible via peeking to get the whole room's history, so searching in there would make it easier to only get specific information.

**Describe the solution you'd like**
Allow searching in public rooms that support peeking.

**Additional context**
Was originally brought up in this issue: https://github.com/matrix-org/matrix-static/issues/111
EDIT: wasn't sure whether to open the issue here, or in the `matrix-spec` repo.
