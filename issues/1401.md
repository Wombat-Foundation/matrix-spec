**Link to problem area**: https://spec.matrix.org/v1.5/client-server-api/#push-rules

**Issue**
What is wrong? This section, which is under "Client behaviour", seems to describe *Server* behavior (see #600), and fails to describe what clients are supposed to do with this information.

In addition, some of the push rules conditions talk about "unencrypted" events, I don't think this is accurate -- I think the homeserver runs those rules against the encrypted event, and clients are expected to decrypt the event first and then run the push rules. I'm not as confident about this, however.

**Expected behaviour**
How can the issue be fixed? Links to implementations/documents which prove the spec is wrong are appreciated.

The spec should describe how clients are expected to handle push rules.
