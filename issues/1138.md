Hi all!

**Is your feature request related to a problem? Please describe.**
1. I've thought for a while if the matrix network protocol had a way to temporarily delete messages for better user safety.
2. It would be interesting if the matrix had a way to configure a time when messages from users were deleted for better security and privacy of their data.

#### **Describe the solution you'd like** and/or **proof**
> *"Hi all! my last question... if you guys have the time and patience to answer. My question would be... if it would be possible to have temporary messages in the matrix protocol. This would be similar to what you find in things like Pastebin... where you share information that you delete after a time. Note: I would be happy for this new feedback"*
