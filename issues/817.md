https://matrix.org/docs/spec/server_server/r0.1.4#request-authentication

#### Issue
Came up in `#conduit:fachschaften.org`; It's not clear that the parameters after `X-Matrix` can use quotes or not, [RFC2184](https://tools.ietf.org/html/rfc2184) was mentioned with the following quote:

> Note that quotes around parameter values are part of the value
> syntax; they are NOT part of the value itself.  Furthermore, it is
> explicitly permitted to have a mixture of quoted and unquoted
> continuation fields.

Maybe this clarification can be added as an informational footnote.
