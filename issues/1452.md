### Use case

When you forget to "reply" to a specific message it would be useful to edit the message and attach the reply.

See https://github.com/vector-im/element-meta/issues/1047 for ideas/interest in this feature in Element.


### Proposal

Nothing needs to change spec-wise except for the language to allow it (as far as I know).

This already technically works in Synapse/Element after https://github.com/matrix-org/matrix-react-sdk/pull/6817

---

Related to retroactive threading


### Prior art

[MSC2676](https://github.com/matrix-org/matrix-spec-proposals/pull/2676) already explicitly calls out that this is not allowed:

 - https://github.com/matrix-org/matrix-spec-proposals/blob/main/proposals/2676-message-editing.md#applying-mnew_content
 - https://github.com/matrix-org/matrix-spec-proposals/blob/main/proposals/2676-message-editing.md#edits-of-replies
 
There was [some discussion on the MSC](https://github.com/matrix-org/matrix-spec-proposals/pull/2676#discussion_r696791776) to allow for this but it was punted to a future proposal
