**Link to problem area**:  https://spec.matrix.org/v1.6/server-server-api/#get_matrixkeyv2queryservername and https://spec.matrix.org/v1.6/server-server-api/#get_matrixkeyv2queryservername

**Issue**
The response is described as an object containing one field: 

Name | Type | Description
-- | -- | --
server_keys | **Server Keys** | The queried server’s keys, signed by the notary server.

This suggests that `server_keys` maps to a JSON object (which is defined further down).
However, the example (and `curl -X GET matrix.org/_matrix/key/v2/query/matrix.org | jq`) show that `server_keys` maps to a **list** of JSON objects.

**Expected behaviour**
This should says  `[Server Keys]` or similar.
