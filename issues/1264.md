**Suggestion**

Clients should let the user know (in their About page, for example) what version of the spec they support, so that users can confidently start using features that that particular spec version provides.

For example, v1.3 includes Threads. Once a client like Nheko is fully compliant with Matrix v1.3, the user could see that and start using the feature without fear of fragmented support or implementation.

I thought about homeservers also advertising support for a particular Matrix version, but I don't know how useful or actionable that would be. If it is possible for the _client_ to detect what version of the spec is supported by the homeserver the user's account resides on, maybe that could be exposed alongside the client's own supported version.
