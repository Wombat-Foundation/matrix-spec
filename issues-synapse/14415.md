**Description:**

After https://github.com/matrix-org/synapse/pull/13996 we now send the HS token in an `authentication` header in addition to the legacy query string. It would be good to make this configurable in the AS config, e.g. so that logs which include the query string no longer expose this security token or require manual redaction.
