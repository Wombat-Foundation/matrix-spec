### Description

Pillow dependency should be pinned or specified to latest version around 9.x.x in order to fix this problem, because 10.0.0 released not long ago made changes that [aren't backward compatible](https://pillow.readthedocs.io/en/stable/releasenotes/10.0.0.html#constants). Alternatively it is possible to make fix just by checking version of package and making constants have same names as before.
