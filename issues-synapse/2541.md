### Description

I use my own homeserver.

I binded a discord bridge to a specific room in riot. Users from discord side, successfully joined that room in riot side. My riot user and my discord user can join that room and talk together.

Everything is working fine except that if an another riot user has been invited to join that bridge room, he cannot join it if he clicks on accept invite and I have that error messages in logs.

Who can help me?

### Steps to reproduce

- setup a discord bridge
- have a specific room for that bridge on riot side
- join on riot side that room bridge with a user
- invite an another riot user to join that bridge
- the user invited will have a 500 error
