According to [the specification](https://matrix.org/speculator/spec/HEAD/client_server/unstable.html#post-matrix-client-unstable-rooms-roomid-join) (both r0.2.0 and unstable) the `rooms/{roomId}/join` endpoint should return the room_id for the room that was joined. This is not actually the case on matrix.org though – the response is just an empty object. I have not checked if this applies to `join/{roomIdOrAlias}` too, but I suspect that it does.
