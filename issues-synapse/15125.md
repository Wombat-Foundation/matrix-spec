**Description:**
Let's say that 
- A user (will be referred to as User A, is not registered on the main matrix.org homeserver) 
- Was testing the banning system on a relay(i am suggesting any forms of ban and then unban, but for now, i will go with this idea) from an external server  (may be any channel that is not in User A's homeserver, i.e. the matrix homeserver or any other server for that matter).
- "It Works!" he says after being banned
- He tried to unban himself from the relay (supported by the relay obviously), however he is still denied access
- He reaches out to a friend that is admin in the room, he says "but you aren't on the ban list!"
- After scouring the internet he found out that it was a bug in matrix-synapse and to workaround this bug he would be required to create a new account then rejoin that room to "refresh his homeserver of that server's banned members list" 
- He tries it, and it works, and he gets back in.
*real story btw*
## My question is:
###### Why should the homeserver handle the banned members list?
## My suggestion is:
##### Don't make the homeserver handle the ban list, just when a user joins, the homeserver should instead "ask the connecting server if this user is banned" then block/allow access, and if this is unfeasible by some technicality, then atleast make the homeserver refresh the status of their members every say 1 day or whatever the admin sets it up to
