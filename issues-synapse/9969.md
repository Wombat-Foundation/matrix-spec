### Description

<!-- Describe here the problem that you are experiencing -->

I’m running a medium sized matrix server (1650 users currently). For a few weeks now, the server is unstable. The reason is Synapse is eating all the RAM until the OOM triggers its death. Then, systemd restarts the process and it goes on and on like this. I’ve tried to clean my database, reindex it, compact it, nothing is working. It’s the same issue with or without workers.

The hardware is ok, as I have 32GB of ram and a quad core xeon. The database and synapse are running on an ssd raid.

Here is a screenshot of the RAM monitoring. That’s the last 6 hours. When the RAM usage drops, that’s when the main process is killed, so it’s quite often.

Any idea ? Someone else with the same issue ?
