Erik investigated further and ultimately submitted a patch to setuptools-rust: https://github.com/PyO3/setuptools-rust/pull/295. This was accepted, but has yet to be released. 

----

Once a newer setuptools-rust release is available, we should take advantage of this to ensure that we don't accidentally segfault running processes when we actually want to do a rolling restart.

At the moment, setuptools_rust is currently upper-bounded at the current release version:
https://github.com/matrix-org/synapse/blob/ae69d6952576fc77b4beca49181b807e7bd80a1d/pyproject.toml#L366-L371

which will presumably need bumping; confusingly we also have a lower bound here:

https://github.com/matrix-org/synapse/blob/ae69d6952576fc77b4beca49181b807e7bd80a1d/pyproject.toml#L212-L220
