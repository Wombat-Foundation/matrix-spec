### Description
It's very flaky, but sometimes joined public room is missing from /sync response, even if it is in /joined_rooms response.

<!-- Describe here the problem that you are experiencing -->

### Steps to reproduce
In my case:
- user 1 create public room
- user 1 joined room
- user 2 user joined room
- exchange messages
- user 2 leave room
- user 2 join room
- exchange messages
- users go offline for 5-7 days
- after that creator has this room in /sync response rooms.join.room_id
- user, that joined this room is missing it in /sync response
