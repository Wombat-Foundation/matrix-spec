Following the [unstable](https://matrix.org/docs/spec/server_server/unstable.html#rules)/[HEAD](https://matrix.org/speculator/spec/HEAD/server_server/unstable.html#rules) spec, the `m.room.create` event must have `depth` set to `0`.
Looking at events generated by synapse v0.24. when creating a room, `depth` is `1`.
Looking at old rooms, like Matrix HQ, `depth` is `0`.

If the spec was adapted to either value, rooms that are created with the other values would all be invalid.
Seems like the responsible changes where made in 2014 (thanks jzk for the links):
- https://github.com/matrix-org/synapse/commit/018443cb5914f8c4a5488397cc1c19689e949aff
- https://github.com/matrix-org/synapse/commit/e8323b9e344a557452b17f4e0dea9d95feff747f

Code has moved since then: https://github.com/matrix-org/synapse/commit/30057b1e154a0fdf1f778aa952c2f7c88656004e (thanks Magnap for the link)

Accepting both depth values for the create event is not possible either, as it would open attack and room hijacking possibilities potentially, assuming that's the reason it was specifically set to a certain value in the spec?
