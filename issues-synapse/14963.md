Description:
Upgrading matrixdotorg/synapse docker image from v.1.75 to v.1.76 results in the error: ModuleNotFoundError: No module named 'shared_secret_authenticator'. Possibly missing python module.

Steps to reproduce:
1. Install latest matrix image & mount shared_secret_authenticator.py volume
```
sudo docker run -d --name matrix --restart unless-stopped \
    -v /path/Matrix/:/data \
    -v /path/Matrix/shared_secret_authenticator.py:/usr/local/lib/python3.9/site-packages/shared_secret_authenticator.py \
    -p 8008:8008 \
    matrixdotorg/synapse:latest
```

Should return the error: ModuleNotFoundError: No module named 'shared_secret_authenticator'

2. Repeat the same by downgrading to v.1.75 & everything should work
```
sudo docker run -d --name matrix --restart unless-stopped \
    -v /path/Matrix/:/data \
    -v /path/Matrix/shared_secret_authenticator.py:/usr/local/lib/python3.9/site-packages/shared_secret_authenticator.py \
    -p 8008:8008 \
    matrixdotorg/synapse:v1.75.0
```
