Hello everyone. I’ve been asking this on #synapse for about one week now, unfortunately without any advice … so please allow me to open this questions and/or discussion here.

We would like to allow our users to add local addresses to their rooms. No public addresses, though.

In addition to that, we would like to specifically deny certain prefixes for local addresses (unless for one specific admin-account), or vice versa we could also allow only certain prefixes for all users.

For example, all users (unless admin-account) are allowed to create aliases for their rooms, but only aliases starting with e.g. underscore `_` … is this possible somehow via the `alias_creation_rules`?

```
alias_creation_rules:
  - user_id: "@admin-account:example.org"
    alias: "*"
    room_id: "*"
    action: allow
  - user_id: "*"
    alias: "_*:example.org"
    room_id: "*"
    action: allow
```
