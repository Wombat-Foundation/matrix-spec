At the moment this returns `Dict[str, Any]`. I'd rather this be `Dict[str, object]` so that we can't just assume the shape of the body is as we expect.

To make that kind of change we'd need to have some way to fetch, deserialise and validate a request body which returns a meaningful type. My vote for doing so is another function which takes a Pydantic model.
