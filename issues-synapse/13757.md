### Description

Hello everyone,

We've setup a Matrix server via the [matrix-docker-ansible-deploy](https://github.com/spantaleev/matrix-docker-ansible-deploy) playbook. We also have a Keycloak server running our Single Sign On software. 

We had created our accounts on Synapse by connecting to the SSO, and it worked great.

Recently, we've updated our Keycloak server ( which we had done before ), and when we login via Element, with the SSO, we are now prompted to create a new account. The weird part is that the existing sessions, with our existing accounts, still work. 

As such, we now have several matrix accounts linked to the same SSO account. But we can only access the last one created, and not the previous ones. 

We were wondering what kind of bug could that be ? 

### Steps to reproduce

- Install a Matrix server with Element via the matrix-docker-ansible-deploy playbook.
- Configure OpenID connect login as described in https://github.com/spantaleev/matrix-docker-ansible-deploy/blob/5c0c0d5af07c8daf502ed84059ccf6dbbaf634c5/docs/configuring-playbook-synapse.md#synapse--openid-connect-for-single-sign-on with a Keycloak server.
- Update your Keycloak server.
- Try to login with Keycloak.
