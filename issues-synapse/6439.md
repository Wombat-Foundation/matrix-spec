`GET /_synapse/admin/v1/whois/<user_id>` should contain:
- whether the account is **deactivated** (_deactivated_)
- whether it's a **guest account** (_is_guest_)
- whether it's an **admin account** (_admin_)

(Additionally it would be neat to have an admin api to get the list of all users, or filtered by simple criteria, like *is_guest*, *admin*, *deactivated*.)
