Context: with MSC3861 delegated auth enabled, there is a simple static admin token used by the matrix-authentication-service to perform various admin operations. It's a somewhat temporary workaround, but necessary for now.

It happens that we need to be able to call the C-S API as a specific user from MAS (in this particular case: the media upload API for avatar upload), so the quickest way to achieve this is to add a simple impersonation logic to this admin shared token shortcut.
I would do this by sticking a `user_id` query parameter, and parse it here: https://github.com/matrix-org/synapse/blob/54a51ff6c1a1d9c7174e239acdd2dee7bed744f7/synapse/api/auth/msc3861_delegated.py#L269
