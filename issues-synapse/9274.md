**Description:**

Live is live and some instance going down. A simple shutdown will generate a lot of non-transmission errors, but all messages in the rooms will be sent to a non-existent instance.
The idea is to propose an API / binary call that, like Mastodon (with the self-destruct https://docs.joinmastodon.org/admin/tootctl/#self-destruct ) will, at the very least, remove the users present in all the rooms and then unsubscribe from all the rooms to reduce the traffic to dead instances.


A question comes to my mind, if an instance dies, if someone recovers the domain and recreates an instance, is he going to recover the content of the old server via the federation or not?
