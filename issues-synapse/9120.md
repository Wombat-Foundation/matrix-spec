### Description

I'm trying to disable the e2e encryption in new rooms and private chats.

Changing the configuration doesn't seem to have any effect.

<!-- Describe here the problem that you are experiencing -->

### Steps to reproduce

- Add `encryption_enabled_by_default_for_room_type: off` to homeserver.yaml
- restart synapse
- invite a user to private chat
- note encryption is enabled and there is no way to create an unencrypted private chat
- alternatively, create a new room
- note that while there is UI to enable encryption, it's still selected by default

FWIW I tried both `off` and `"off"`.

Also, the phrasing in the comments of homeserver.yaml is a bit vague. Does `"off": this option will take no effect` mean encryption will be off by default or does it meant "this setting has no effect and hard-coded defaults will be used". If the latter, how does one disable encryption in private rooms?
