### Description

Hello
I want to use matrix as a private chat for friends so there's no need for identity servers, here. 
So in nginx I entered this to make my users not use an identity server per default:
```
location /.well-known/matrix/client {
      return 200 '{"m.homeserver": {"base_url": "https://matrix.homeserver.com"},"m.identity_server": {"base_url"""}}';
      add_header Content-Type application/json;
      add_header "Access-Control-Allow-Origin" *;
    }
```

But after logging in, I'm still seeing this:
![identity](https://user-images.githubusercontent.com/10515479/138077374-fa7143f9-6621-4401-8929-e2678014075d.PNG)

So this doesn't seem to work as intended.
