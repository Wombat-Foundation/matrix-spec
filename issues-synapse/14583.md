The `get_all_changed_entities` returns `None` in the case that the cache cannot provide information on the given stream ordering. Some of the callers treat `None` equivalent to `[]` (which corresponds to *no* changes).

Callers, checked do it correctly. Unchecked are either incorrect or maybe incorrect:

* [x] [`PresenceEventSource.get_new_events`](https://github.com/matrix-org/synapse/blob/618e4ab81b70e37bdb8e9224bd84fcfe4b15bdea/synapse/handlers/presence.py#L1695-L1725)
* [ ] [`PresenceEventSource._filter_all_presence_updates_for_user`](https://github.com/matrix-org/synapse/blob/618e4ab81b70e37bdb8e9224bd84fcfe4b15bdea/synapse/handlers/presence.py#L1769-L1778)
* [x] [`TypingWriterHandler.get_all_typing_updates`](https://github.com/matrix-org/synapse/blob/126a15794c95002560709283640ad412636b29b8/synapse/handlers/typing.py#L423-L435)
* `DeviceWorkerStore.get_cached_device_list_changes`:
	* [x] [`SyncHandler._generate_sync_entry_for_device_list`](https://github.com/matrix-org/synapse/blob/1183c372fa9da01b2667f1b83dab958dad432c68/synapse/handlers/sync.py#L1521-L1552)
* [ ] [`DeviceWorkerStore.get_users_whose_devices_changed`](https://github.com/matrix-org/synapse/blob/13aa29db1ddc925beb35f5f1da8fd1a1bcc91373/synapse/storage/databases/main/devices.py#L831-L846) (I'm fairly certain this is incorrect.)
* [x] [`StreamChangeCache.get_entities_changed`](https://github.com/matrix-org/synapse/blob/13aa29db1ddc925beb35f5f1da8fd1a1bcc91373/synapse/util/caches/stream_change_cache.py#L112-L128)
