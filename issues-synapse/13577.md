**Description:**
Synapse and Matrix endpoints provides us with the option to get the connected devices but they are not necessarily live sessions. which are still active. We want to limit the number of clients a user can use. But getting the devices list does not provide a robust way to get current live sessions of the user.

Last seen and last online does not necessarily tell us if the user is still logged in that device and active.

If I were to give an example, ejabberd has this connected user resources endpoint, which tells us about the live sessions of a particular user.
