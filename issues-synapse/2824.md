### Description

When someone who has a Matrix.org user account tries to sent me a video that's 28.38 MB in size, I'm unable to download it.  I get an `M_TOO_LARGE` error instead.

### Steps to reproduce

- Start a 1-to-1 chat between a matrix.org account and a home server account.
- On the matrix.org account, upload a video about 28 MB in size.
- On the home server account, try to download the video to watch.

The Riot app will fail silently when trying to download.

If you right-click and copy the download link, sign into your home server's web client, and paste and go to the link; you'll get the following JSON:

```json
{
  "errcode":"M_TOO_LARGE",
  "error":"Requested file is too large > 10485760 bytes"
}
```

- **Matrix.org-Version**: Synapse/0.26.0 (b=matrix-org-hotfixes,9249f11)
- **Homeserver-Version**:  Synapse/0.26.0
- **Install method**: NixOS option `services.matrix-synapse.enable = true;`
- **Platform**:  NixOS running on a virtual x86 server hosted by Scaleway.com
