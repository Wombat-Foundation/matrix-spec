Due to the conclusions of [matrix-doc matrix-org/matrix-spec#255](https://github.com/matrix-org/matrix-doc/issues/1013) the server should only transmit the exact string of bytes that it signed (canonical JSON). This probably reverts matrix-org/matrix-spec-proposals#878.

Please consider this high priority. The change is trivial and can be shipped immediately.
