### Description

The specification states the following when the "trusted_private_chat" preset is used during room creation: "All invitees are given the same power level as the room creator". Unfortunately, this doesn't happen in Synapse. Here is a direct link: https://matrix.org/docs/spec/client_server/latest#post-matrix-client-r0-createroom

### Steps to reproduce

- call the /_matrix/client/r0/createRoom endpoint and pass the "trusted_private_chat" preset and a list of invited users
- check the response of the /rooms/{roomId}/state API
- The m.room.power_levels event doesn't define any power levels for invited users. I. e. their power level remains 0.
