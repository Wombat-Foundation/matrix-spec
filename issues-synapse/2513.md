Synapse have useful [Purge Remote Media API](https://github.com/matrix-org/synapse/blob/master/docs/admin_api/purge_remote_media.rst) that clean ups `remote_content` and `remote_thumbnail` folders. 
But Synapse `media` storage have another folders that we can cleanup:
- url_cache
- url_cache_thumbnails
- local_thumbnails

Will be good to extend [Purge Remote Media API](https://github.com/matrix-org/synapse/blob/master/docs/admin_api/purge_remote_media.rst) or provide separate admin API for cleaning up those folders too.

Also will be good to have separate hard option for clearing too old `local_content` too.
