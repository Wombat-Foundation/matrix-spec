We should remove the unstable feature flags that were part of the r0.5.0 release cycle. These are:

* `m.require_identity_server` (https://github.com/matrix-org/synapse/pull/5972)
* `m.id_access_token` (https://github.com/matrix-org/synapse/pull/5974)
* `m.separate_add_and_bind` (https://github.com/matrix-org/synapse/pull/6044)

Clients that rely on these flags should check for Client Server API r0.6.0 support instead.

We should remove all the deprecated endpoints. These are:

* `/account/3pid` - replaced by `/account/3pid/add` and `/account/3pid/bind`
* Others...
