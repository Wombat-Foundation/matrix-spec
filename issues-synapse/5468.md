### Description

I sent an ACL to deny matrix.org, and this ended up banning all servers from participating. It seems to cause "allow: []" to get added to the event, which causes every server to be banned. 

### Steps to reproduce

In Riot, I sent the following state event from dev tools:

```
{
    "content": {
        "allow": [
            "*"
        ],
        "allow_ip_literals": false,
        "deny": [
            "matrix.org"
        ]
    },
    "type": "m.room.server_acl"
}
```

I then see the following in the chat in Riot: "<me> set server ACLs for this room: 🎉 All servers are banned from participating! This room can no longer be used."

If I look at the m.room.server_acl in dev tools, I see this:
```
{
  "type": "m.room.server_acl",
  "sender": "<my mxid>",
  "content": {
    "content": {
      "allow": [
        "*"
      ],
      "allow_ip_literals": false,
      "deny": [
        "matrix.org"
      ]
    },
    "type": "m.room.server_acl",
    "allow": []
  },
  "state_key": "",
  "origin_server_ts": 1560649579360,
  "unsigned": {
    "age": 80
  },
  "event_id": "<event_id>",
  "room_id": "<room_id>"
}
```
(note the ""allow": []" added into the acl.) 

### Version information

This is happening on a self-hosted synapse 1.0. I am able to reproduce this in a new room every time.
