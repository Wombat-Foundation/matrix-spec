### Steps to reproduce

1. Install `matrix-synapse-py3`.
2. Configure the replication listeners with `bind_address: "::1"`
2. Configure a worker with `worker_main_http_uri: "http://[::1]:8008"`
3. Start synapse.

The above error will be encountered.
