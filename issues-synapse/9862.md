### Description

SSO CAS configuration don't work as expected.

### Steps to reproduce

First i configured a cas service in homeserver.yaml:

```
server_name: "domain.io"
public_baseurl:"im.domain.io"

cas_config:
  enabled: True
  server_url: "https://im.domain.io/_matrix/cas_server.php"

```
when reaching the server i'm getting redirected in loop to :
https://im.domain.io/_matrix/client/r0/login/sso/redirect?redirectUrl=https%3A%2F%2Felement.domain.io%2F%23%2F

If i reach:
https://im.domain.io/_matrix/cas_server.php/login?service=https%3A%2F%2Fim.domain.io%2F_matrix%2Fclient%2Fr0%2Flogin%2Fcas%2Fticket%3FredirectUrl%3Dhttps%253A%252F%252Felement.domain.io%252F%2523%252F
i'm getting loggued and redirected properly

It seems that synapse doesn't redirect the user to the cas server url and i don't understand why.
The location header in the previous version was good and in 1.31.0 we get stuck in a redirect loop.

I'm running synapse server v1.31.0.
I don't get this problem in v1.28

- **Version**: v1.31.0
- **Install method**: from sources (yunohost)
- **Platform**: VM / Debian buster
