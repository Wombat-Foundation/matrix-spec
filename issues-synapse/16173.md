### Description

I've created a bot for my chat room, and because bots may post frequently, I've added it to the override_ratelimit, and sending a GET request to (https://pockets.chat/_synapse/admin/v1/users/@bot:pockets.chat/override_ratelimit) shows the following:

```
{
    "messages_per_second": 0,
    "burst_count": 0
}
```

Yet, apprise will still get rate limiting responses:

```
DEBUG - Matrix Response: b'{"errcode":"M_LIMIT_EXCEEDED","error":"Too Many Requests","retry_after_ms":278142}'
WARNING - Matrix server requested we throttle back 278.142ms; retries left 1.
DEBUG - Response Details:
b'{"errcode":"M_LIMIT_EXCEEDED","error":"Too Many Requests","retry_after_ms":278142}'
```

I've restarted synapse since making the change, but it doesn't seem to take.

This is the command i'm using in apprise
```
apprise -vvvv -b "test" matrix_dev=matrixs://botusername:password@pockets.chat/\!ROOMID:pockets.chat?format=markdown
```

### Steps to reproduce

- Create a new user for bot related tasks
- Add user using the override_ratelimit API
- Post using the API (in my case via Apprise)
- Keep posting until you see the "Too Many Requests" error
