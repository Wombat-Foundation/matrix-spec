### Description

The doc says that [disabling user clears the cross-signing keys](https://matrix-org.github.io/synapse/latest/admin_api/user_admin_api.html#deactivate-account).

But from my tests, the same cross-signing keys remain accross disabling+re-enabling process.

I even tested to trigger a `regenerate_directory` event and wait for it to complete before re-enabling it but it does change nothing.

Waiting for a fix, is there any workaround to manually clear (not replace, clear) cross-signing keys for a given user ?

Thanks by advance <3

### Steps to reproduce

- disable user via admin API
- enable user via admin APIh
- check for cross-signing keys (for ex in session initialization logs, but I guess it can be checked in DB too)
