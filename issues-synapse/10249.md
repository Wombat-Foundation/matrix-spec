### Description

As the title implies having the ";" character (in quotes as well) in the notif_from key causes the email to fallback to the machine hostname, thus preventing emails with a strict sender check


```
  notif_from: "ToS;DR %(app)s <matrix@tosdr.org>"
```
![image](https://user-images.githubusercontent.com/40178814/123369829-cf924f80-d57e-11eb-92f7-324aa67cc0d1.png)

Removing the semicolon fixes the issue.
![image](https://user-images.githubusercontent.com/40178814/123369871-e8026a00-d57e-11eb-9cf7-63cf540dc673.png)


### Steps to reproduce

- Use a semicolon in the notif_from key
- Send a test email

It should include the Semicolon as well.
