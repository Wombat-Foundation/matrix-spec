### Description

Other users on other homeservers can send messages to my account.
My account however cannot send messages to those users.
However, those users see typing notifications from my account, just not the actual message.

The log does not show any warning or error messages apart from the following messages which I suppose are unrelated to this problem:

```
2018-08-23 20:02:52,600 - synapse.storage._base - 317 - WARNING - - Starting db txn 'update_presence' from sentinel context
2018-08-23 20:02:52,600 - synapse.storage._base - 353 - WARNING - - Starting db connection from sentinel context: metrics will be lost
```

The info log _suggests_ (not sure if I read it correctly) that the remote homeservers accept the message event.

### Steps to reproduce

The problem just occurred on synapse 0.27.X after months of not touching it (just worked).
I thought maybe some backwards-incompatible change happend with the federation protocol, so I updated to 0.33.2.
However, this did not help.
Again: the upgrade did not correlate with the bug I describe above.
