Noticed in [this sentry error](https://sentry.tools.element.io/organizations/element/issues/198/?project=2&query=is%3Aunresolved&sort=freq&statsPeriod=14d).

We try to call `urlparse` here

https://github.com/matrix-org/synapse/blob/303b40b988bc372a81fc1a3cf62d3f5d074970ff/synapse/rest/media/v1/preview_url_resource.py#L631-L653

where image_url is a dictionary

```json
{"href": "https://example.com/cats.jpg"}
```

I don't know how the OG metadata is represented in json, but looking at https://ogp.me/#structured it seems that `og:image` is either a URL string or a struct which may contain a `url` key. Synapse doesn't account for the latter case.

Curiously, the example in the sentry error uses a `href` key which seems bogus, but maybe this is common in the wild.
