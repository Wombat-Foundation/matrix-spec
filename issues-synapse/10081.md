### Description

When state events are filtered out from `timeline` (in `/sync` response), `state` field still includes old events or does not include events at all. This is confusing as long as user does not get latest state of room (or does not get it at all).

### Steps to reproduce

Have [this script](https://github.com/globekeeper/dendrite/blob/playground/piotr-kozimor/playground/synapse_issue.py). Edit HS variable to that it points to fresh `synapse` (local would be the best, it creates room and puts state events to it). Run the script:

```bash
python3 -m pytest synapse_issue.py
```
The test case shall fail.

This test case **passes on `dendrite`**.

### Version information

- **Homeserver**: self-hosted

- **Version**:  1.34

- **Install method**: official docker image

- **Platform**: k8s, container
