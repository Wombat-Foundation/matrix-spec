My first experience with a large setup is that the push gateway is overloaded with requests coming from synapse. I believe the gateway is called for every pusher available. So if I have a chat group with say 10K users, all with active pushers and no push rules set, the gateway will receive 10K requests. This leads to performance issues on both sides.

A simple solution for this example would be to bundle the push into 1 request, listing the devices with the push keys in the payload.
