### Description

We run a matrix server which is connected to the companies AD server. An employee has left the company so we disabled his AD
Account. We would expect that he would now be unable to access the companies matrix server, but that's not the case. He is still online and we don't see a way to make sure people don't have access anymore after leaving the company.

### Steps to reproduce

- Configure synapse to allow AD access
- Create AD user
- Login with AD user Account
- Disable AD User on AD Server
- Login with AD user Account
