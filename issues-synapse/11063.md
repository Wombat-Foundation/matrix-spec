Some popular websites don't conform to the letter of the oEmbed spec.

* speakerdeck.com provides the version as a number instead of a string
    * https://speakerdeck.com/oembed.json?url=https%3A%2F%2Fspeakerdeck.com%2Fholman%2Fscaling-github
    * https://sentry.matrix.org/sentry/synapse-matrixorg/issues/232174/events/4549739/

* giphy.com doesn't bother with a version at all
    * https://giphy.com/services/oembed?url=https://media1.giphy.com/media/BzyTuYCmvSORqs1ABM/giphy.gif?cid=790b76113fb855164b090d82ecf6715f60f758bf165182e8&rid=giphy.gif&ct=g
    * https://sentry.matrix.org/sentry/synapse-matrixorg/issues/232170/events/06f26f6a8cb34e6db84d756f04bc65f8/
