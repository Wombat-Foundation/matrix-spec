### Description

We use Shibboleth to authenticate our users at synapse. The IDP attributes `uid`, `email` and `displayName` are passed cleanly to synapse. However the `displayName`attribute does not appear in the user profile settings of any client. The email attribute is set in the user profile. Also the correct `displayName` is shown in the upper left corner (see screenshot below), but not in the profile settings.

### Steps to reproduce

- initial login (account creation) via SAML to synapse
- displayName is not shown in profile settings

 expected:
 - displayName should be shown in profile settings

### Version information

matrix-synapse-py3 1.20.1+bionic1 on Ubuntu 18.04 LTS (package from packages.matrix.org/debian/ )
