### Description

No thumbnails generated on upload.

Spawning from https://github.com/matrix-org/synapse/issues/13016

### Steps to reproduce

 1. Setup synapse with this [`homeserver.yaml`](https://github.com/matrix-org/matrix-public-archive/blob/0f493a241ebde5741f503fb568e02a378e185f67/test/dockerfiles/synapse/homeserver.yaml) (based on the Complement one)
    - `dynamic_thumbnails: false`
 1. Upload an image (`/upload`)
    - [test image](https://github.com/matrix-org/matrix-public-archive/blob/cead1796b88e6555d4792b63db7288cd721ccf03/test/fixtures/friction_between_surfaces.jpg).
 1. Try to request a full version of the image (`/download`) -> 200 ✔
 1. Try to request a thumbnail of that image (`/thumbnail`) -> 404 ❌

Reproducible in [this end-to-end (e2e) test](https://github.com/matrix-org/matrix-public-archive/blob/952a3acd4a5e25edc72714b7cb68d54e6418cf7a/test/e2e-tests.js#L206-L233) with this [test image](https://github.com/matrix-org/matrix-public-archive/blob/cead1796b88e6555d4792b63db7288cd721ccf03/test/fixtures/friction_between_surfaces.jpg).
