**Description:**

The intention of the feature is that if you provision a user via the admin API, synapse can automatically email them a login URL to get started. While this might seem a bit out of scope for a homeserver, there are a few reasons why I'd like to have this feature considered:

- Ease of configuration: Synapse already knows the web client URL, the SMTP settings, and details about the user.
- Templating: Synapse already has support for templating emails so it would be nice to re-use that functionality to send another email type.

Our current use case for this is that we have a external service that automatically provisions users for a organisation and we'd like to email those users their details so they can log in and get started. These users are SSO enabled, so it can just be a login URL with some light branding. This might also be useful for standard deployments where after registering with an email, you'd like a "Welcome to Element!" email in your inbox for audit purposes or just reminding you what you signed up for (Slack do this one).

In terms of implementation, I'd expect:

- A configuration option on whether to automatically send emails on registration.
- An parameter added to the `PUT .../users/$userId` admin API which allows you to configure whether to send a welcome email on creation.
- A template file similar to the other email templates.
