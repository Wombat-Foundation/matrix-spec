The total number of unread notifications for a room (see `notification_count` in `/_matrix/client/r0/sync` API) must be updated when a push rule is defined or removed at room level.

When a push rule is defined at room level to disable the regular notifications (see mentions only mode), this notification count must only take into account the notifications related to the override rules.

Presently, the room notification count is unchanged, its value is then inconsistent.
