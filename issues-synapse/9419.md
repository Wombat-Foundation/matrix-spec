### Description

**Symptom**:
When attempting to federate with matrix.org by trying to browse it's list of rooms in Element, I get a `401 Unauthorized` in the synapse logs, and `Failed to find any key to satisfy VerifyJsonRequest` in the Element UI. After troubleshooting with @anoadragon453 we determined the issue is firewall related.

**Cause**:
The current matrix URLs don't resolve to the correct federation server IPs. In my firewall, whitelisting the IPs of **`matrix.org`** and **`matrix-federation.matrix.org`** (currently resolving to `104.20.20.236` and `104.20.21.236`) still prevents matrix from federating with my homeserver. It turns out that **these are the reverse proxy IPs** and are not the same as those of the federation servers.

**Solution**:
Attach a public DNS name to `matrix.org`'s federation servers so that those with a strictly firewalled synapse server can properly whitelist them and successfully federate.

Or, route the matrix federation servers outbound traffic through the existing IPs tied to the DNS of `matrix.org` and `matrix-federation.matrix.org` so that whitelisting these will allow proper federation.
