### Description

<!-- Describe here the problem that you are experiencing -->
Since version 1.37, apparently using https://github.com/matrix-org/matrix-synapse-ldap3/pull/89, self-signed certificate LDAP backend do not work even if CA is placed in the system trust store.

### Steps to reproduce

- upgrade to matrix 1.37
- import self-signed certificate : put it in `/usr/local/share/ca-certificates/ldap.crt` and run `update-ca-certificates`
- certificate gets written in `/etc/ssl/certs`
- restart matrix-synapse
- try to authenticate
- observe in the logs : `ldap_auth_provider - 499 - WARNING - sentinel - Error during LDAP authentication: ("('socket ssl wrapping error: [SSL: CERTIFICATE_VERIFY_FAILED] certificate verify failed: unable to get local issuer certificate (_ssl.c:1056)',)",)`
- replacing `_ldap_tls = ldap3.Tls(validate=ssl.CERT_REQUIRED)` to `_ldap_tls = ldap3.Tls()` solve the issue but reduces security
- ldapsearch works with same server and credentials
