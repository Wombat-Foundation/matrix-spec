**Description:**

```
{"io.element.relation_types":["io.element.thread"]}
```
, like we'll do for `/messages` api as recommended in [MSC3440](https://github.com/matrix-org/matrix-doc/blob/gsouquet/threading-via-relations/proposals/3440-threading-via-relations.md#fetch-all-threads-in-a-room)
