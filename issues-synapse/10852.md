Consider:

 * our server is active in a given room, let's say Room X
 * a user attempts to back-paginate in that room. We attempt to backfill from remote server HS1.
 * meanwhile, remote server HS2 sends us an event in Room X, which lists some auth events that we do not have. We therefore request those events from HS2 and start persisting them as outliers.
 * Meanwhile, the results from the backfill come back and we start processing them.

If the missing auth events happen to be in the results of the backfill, then they could be first persisted as regular events, and then persisted *again* as outliers.

I'm not actually sure whether this would produce any bad effects, other than leaving us in the unusual situation of having an outlier for which we also have the room state - but it sounds like it might violate assumptions somewhere.
