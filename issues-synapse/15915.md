### Description

The 10.0.0 release [Py-Pyllow](https://pillow.readthedocs.io/en/stable/releasenotes/10.0.0.html)  removed some constants like `Image.ANTIALIAS`. 

This leads to failure when users request image uploading:
```
 File "/usr/local/lib/python3.9/site-packages/synapse/media/thumbnailer.py", line 134, in _resize
    return self.image.resize((width, height), Image.ANTIALIAS)
AttributeError: module 'PIL.Image' has no attribute 'ANTIALIAS'
```

Any clue to solve this ?



### Steps to reproduce

Upgrade py-pyllow to  `10.0.0`
