### Description

After upgrading from 0.34.0 to 0.34.1.1, attempting to start the server results in the following error:

```
$ sudo -u synapse python3.6 -m synapse.app.homeserver --config-path=/etc/synapse/homeserver.yaml --report-stats=no
ERROR:root:Needed msgpack-python>=0.4.2 but it was not installed
Missing Requirements: "msgpack-python>=0.4.2"
To install run:
    pip install --upgrade --force "msgpack-python>=0.4.2"
```

However msgpack-python is installed:

```
$ equery list dev-python/msgpack
 * Searching for msgpack in dev-python ...
[IP-] [  ] dev-python/msgpack-0.5.6:0
```

```
$ python3.6 -c "from msgpack._version import version ; print(version)"
(0, 5, 6)
```
