eledev-synapse_1  | 2021-07-13 01:12:03,142 - twisted - 258 - INFO - sentinel - SMTP Client retrying server. Retry: 3

The SMTP server in this setup was emitting Connection Refused back at Synapse. The `Retry` is backwards, and there's only a single millisecond between attempts.
