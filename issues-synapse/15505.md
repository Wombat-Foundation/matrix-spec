### Description

When using an OIDC provider as a secondary login method, Synapse will crash if the provider is unavailable at startup.

This is rather unfortunate if you are running an IdP alongside Synapse, let's say in a composefile. It required me to build keycloak with a `curl` binary inside the container and implement health checks.

### Steps to reproduce

- configure OIDC IdP
- make sure it's unavailable
- start synapse
