**Description:**

Synapse already allows configuring auto join to a list of rooms after signup.

It would be neat for communities to have the possibility of adding auto-join rooms for a community. So when an invite to a community is accepted by a user, the user would automatically be joined (or invited?) to a selected list of rooms.
