I would like to be able to use android without google services. Currently notifications must use FCM unless each app developer hosts a notification gateway which drains battery. I suggest using [UnifiedPush](https://unifiedpush.org/), the community successor to [OpenPush](https://bubu1.eu/openpush/). Although UnifiedPush is (really) brand new, I'm not aware of any other app-independent implementation.

The only currently available UnifiedPush app is FluffyChat, but there is a request for [Element](https://github.com/vector-im/element-android/issues/2743) support and it would be neat if the user didn't have to host yet another personal server. I believe the technical approach would be for synapse to act as a Push Provider, since it's already an always-online service and then a "distributor" app could use the homeserver url as a backend.
