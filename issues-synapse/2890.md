### Description

There's no preview at all for any urls from keytown.me, for example, neither title nor image. The issue title might be misleading, that's only an assumption.

### Steps to reproduce

- post an url like https://keytown.me/
- no preview appears as if it's not even an url

Log reads:

```
2018-02-20 09:48:09,012 - synapse.http.server - 124 - INFO - GET-6- <SynapseRequest at 0x7faf78407518 method=GET uri=/_matrix/media/r0/preview_url?url=https%3A%2F%2Fkeytown.me%2F&ts=1519109288279&access_token=<redacted> clientproto=HTTP/1.0 site=8008> SynapseError: 500 - Failed to download content: [<twisted.python.failure.Failure OpenSSL.SSL.Error: [('SSL routines', 'ssl3_read_bytes', 'sslv3 alert handshake failure')]>]
```
From what I found this happens if the site disabled SSLv3 on their end or if cipher suites don't match (see #2350). Some advice downgrading python-cryptography but it didn't help in my case.
