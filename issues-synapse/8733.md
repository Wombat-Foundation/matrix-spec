### Description

After I set up synapse I recognized that synapse holds open files on a filesystem, that's off limits for synapse (it's a remote fuse FS). After modifiing permissions synapse crashes with `MemoryError`.
Kernel log shows something like:
```
Denied untrusted mmap of /var/tmp/
Denied untrusted mmap of /var/lib/synapse/
...
```
My guess: Synapse wants to execute files which it has written before. And on it's way to achieve this, it's trying all filesystems it can find. Even remote fuse file systems.

Please run those files with the interpreter, not through exec. Exec for non-privileged users in not root owned dirs isn't allowed on (at least) my systems and apparently the BSD's (see #1148).
