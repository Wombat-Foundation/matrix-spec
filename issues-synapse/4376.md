### Description

The URL Previews feature provides the following `User-Agent` header when fetching a web page:

```
User-Agent: Synapse/0.34.1.1
```

It's a small detail, but sending such accurate version information is a security risk as it informs the corresponding web server of potential security vulnerabilities the homeserver server has.

You should remove the version information or at the very least trim it to the major version only.

For example, look how discrete Firefox is:

```
User-Agent: Mozilla/5.0 (X11; Linux x86_64; rv:64.0) Gecko/20100101 Firefox/64.0
```
