CPython [3.11.0rc2](https://www.python.org/downloads/release/python-3110rc2/) was released yesterday. A final release is scheduled for 2022-10-24.

We support all upstream-supported versions of CPython, so at some point we'll want to include 3.11 in CI. It would be good to do this ahead of a release if possible.

- [x] Run trial tests against 3.11 in CI
  - #13812 
- [ ] Run sytest against 3.11 in CI
- AFAIK Sytest is only testing against the Python versions that happen to come with the Debian/ubuntu distros we test against. Currently there is no distro shipping 3.11 ([debian](https://packages.debian.org/search?keywords=python3&searchon=names&exact=1&suite=all&section=all), [ubuntu](https://packages.ubuntu.com/search?keywords=python3))
- See also Sytest's own CI, https://github.com/matrix-org/sytest/blob/bebf431edf7311d5147139f44dab97131a784d29/.github/workflows/pipeline.yml#L23-L51
- [ ] Run complement against 3.11 in CI
  - Tests against whatever's in the docker image---[currently 3.9](https://github.com/matrix-org/synapse/blob/2a3cd59dd06411a79fb7500970db1b98f0d87695/docker/Dockerfile#L29).
