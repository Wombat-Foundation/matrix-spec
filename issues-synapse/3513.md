Setting up a TURN server, somehow I set the config in homeserver.yaml to read:

```turn-shared-secret: 81ahb1ahBl4481ahb1ahBl4481ahb1ahBl4481ahb1ahBl44```

When _of course_ it should have read:

```turn_shared_secret: 81ahb1ahBl4481ahb1ahBl4481ahb1ahBl4481ahb1ahBl44```

Synapse uncritically accepted a `turn_shared_secret` of (presumably) empty string and generated (invalid) passwords using that. Coupled with coturn's super limp logging and frustrating debug/test tools, this silent failure frustrated my efforts to set up a functioning TURN server for just over one and a half years :sob:
