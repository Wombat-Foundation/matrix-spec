Synapse seems to expect that colons be escaped in the path part of URL and throws 500 Internal Server Error upon encounter with an unescaped colon. To reproduce, try, e.g., `https://matrix.org/_matrix/client/r0/join/%23matrix-clients:lain.haus` (note that the hash is properly escaped)

Background: Qt encodes the path passed to `QUrl::setPath()` in this manner (which seems to be compliant with RFC 3986, FWIW). I can workaround it in libqmatrixclient but 500 is not a good answer anyway; so probably better fix on the server side.
