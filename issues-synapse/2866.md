When installed via pip/git as the Readme states at the beginning, is there any update mechanism included? I.e. can Synapse update itself?

Because there are also no update instructions listed, so huh… you should know that for security reasons it is the most important thing to have up-to-date software.
Additionally, generally, for federated stuff things can break easily when you have multiple old servers and need to support these/provide backward-compatibility for "too old" servers and so on.

So either add instructions or some kind of auto-update mechanism. The current situation is reckless, when a vulnerability will be found in the future and all these installations just will not update…
