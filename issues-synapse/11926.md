**Description:**

When we load a context around an in-thread event, we want to paginate backwards and forwards from there and load older and newer messages in a thread, respectively. We have a `dir` parameters in `/messages` [api](https://spec.matrix.org/v1.2/client-server-api/#get_matrixclientv3roomsroomidmessages) to paginate in both directions in a room timeline. We need something similar for `/relations api` to achieve the same thing on a thread timeline.
