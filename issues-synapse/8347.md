**Description:**

Python 3.5 has [reached End-Of-Life](https://endoflife.date/python) on the 13th of September, deprecating this could open up synapse to (for example):
- f-string literals (#8332)
- Variable typing annotations (#8351)
- Async generators
- Async list literals (or "comprehensions")

([3.6 release notes](https://docs.python.org/3/whatsnew/3.6.html))
