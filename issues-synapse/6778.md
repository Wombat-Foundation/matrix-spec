Since Synapse v1.9.0 the below exception is thrown ...
`AttributeError: 'ModuleApi' object has no attribute 'hs'`

for the following line of code ...
`store = yield self.account_handler.hs.get_profile_handler().store`

... which is part of a password provider. The result is that it is no longer possible to login through the password provider. 

Any idea of a quick fix?
