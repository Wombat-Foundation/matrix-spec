### Description

There is an issue when we try to enable push notifications for  element iOS , by setting up our custom matrix/synapse homeserver and sygnal push gateway as a separate component. The sygnal API for push notifications (_matrix/push/v1/notify) works fine when triggered manually through a REST client , but synapse fails to send the same request with the same push key to sygnal's API.

It was working in 1.40.0(synapse) and 0.10.1(sygnal), and occurred when we migrated to 1.49.0(synapse).


### Steps to reproduce


- setup synapse and sygnal
- connect to that as a custom home server from element iOS
- log in as a user
- generate a push notification event for the same user by room mentions/messages or direct messages

### Homeserver

custom synapse home server 

### Synapse Version

1.49.0

### Installation Method

Other (please mention below)

### Platform

Synapse and sygnal are setup from source and are running as docker containers on instances managed in a private cloud platform.
