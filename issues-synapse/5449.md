### Description

I am trying to figure out how to upgrade my server to 1.0 by adding a TLS cert on 8448. I'm following this flow of documentation and it seems nowhere does it tell me how to actually do the operation I'm supposed to do.

https://github.com/matrix-org/synapse/blob/master/UPGRADE.rst -> https://github.com/matrix-org/synapse/blob/master/docs/MSC1711_certificates_FAQ.md#configuring-certificates-for-compatibility-with-synapse-100 -> https://github.com/matrix-org/synapse/blob/master/docs/ACME.md

The most the docs say is "Enable acme support in homeserver.yaml." This text is in both of the latter documents, but it doesn't say what the name of the setting is, what possible values it can be set to, etc.

Can the docs be updated to be more explicit about what that step entails, or link to a document describing the setting and the expected value and semantics? My homeserver.yaml does not have any mention about ACME in the template (probably because the template is old, but I imagine most people who are upgrading have a similar situation.)
