# Backend
python - REST api based on [klein](https://github.com/twisted/klein) which produces the configs
by templating the sample config generated by synapse.

# Frontend
React-Redux, es6 and a bunch of other goodies

# It's a setup util
This util is just a very simple initial setup thing. It will walk users through picking a username and setting up ports. It will handhold users looking to use a reverse proxy and delegation. Once it's at this point I would be very happy with the project. There's still plenty of scope for it to become the defacto config util for synapse but that may be for later.

# Federation tester:
It will include some simple utils to test the setup.

# Config editor
We've decided not to allow editing of the yaml files inside the installer.
