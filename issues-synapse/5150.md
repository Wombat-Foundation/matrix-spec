I have installed matrix synapse on one of my school's hosted VMs following these instructions with the prebuilt debian/ubuntu package: https://github.com/matrix-org/synapse/blob/master/INSTALL.md
The VM is running Ubuntu 18.04.2. After finally getting my homeserver.yaml file configured properly (I had to remove all of the special characters from the file since .yaml files apparently don't support them), I tried running the command `register_new_matrix_user -c homeserver.yaml http://localhost:8008` as shown in the guide, but I keep hitting an error. The error states: "ERROR! Received 400 Bad Request Shared secret registration is not enabled". Now I know have shared secret registration enabled in the homeserver.yaml file, and even generated a secret string to place for the value, but as far as I can tell, I am not even using the shared secret to register the user? I have also tried using the `-k 'my secret code'` option instead of the `-c homeserver.yaml` option, but to no avail. I have also edited the homeserver.yaml file and commented out the registration_shared_secret field altogether, but then the server gives me the error: "No 'registration_shared_secret' defined in config." Before you ask, yes the field `enable_registration` is set to true as well. Has anyone else experienced this issue? I will paste the registration of my homeserver.yaml file code below to see if there are any issues. Apologies for formatting; the # for the commented out lines seems to bold everything. Thanks.

**Edit: Just wanted to add that I've even gone into the register.py file in 
/opt/venvs/matrix-synapse/lib/python3.6/site-packages/synapse/rest/client/v2_alpha/
and taken out the lines of code that spit out this error. I then restarted matrix-synapse, tried to register again, and it still gave me the same error. How is this possible? Is there another instance of code somewhere I'm unaware of that can raise this synapse error?
