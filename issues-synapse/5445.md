A device list update received from matrix.org is taking a reliable 72 seconds to persist on the main process. The replication timeout is 60s, so it times out every time, failing the transaction. The transaction is then retried by matrix.org a minute or so later, which then causes the device list update to go the main process, which then takes 72s, which then times out, and the transaction fails. Repeat forever.
