### Description

After upgrading my Docker-hosted Synapse server to matrixdotorg/synapse:latest, V0.33.8, port 8448 of my server hangs for a minute or so and returns an empty response. 

The issue also happens if I `docker exec` into the container, install curl, and hit the server locally. If I run the container locally, the response returns immediately, and is also empty.

### Steps to reproduce

1. Install Docker, or run from a Docker-capable system.
2. `docker run -it --rm -p 8448:8448 -e SYNAPSE_SERVER_NAME=thewordnerd.info -e SYNAPSE_REPORT_STATS=1 docker.io/matrixdotorg/synapse:latest`
3. `curl -kv localhost:8448`
