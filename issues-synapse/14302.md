### Description

Contrary to what the [docs](https://matrix-org.github.io/synapse/latest/admin_api/user_admin_api.html#list-accounts) say, the "List Accounts" Admin API endpoint will always return `next_token`.

Affected code seems to be

https://github.com/matrix-org/synapse/blob/86b7d9b8862775353951322d604624e37d428a55/synapse/rest/admin/users.py#L143-L146

### Steps to reproduce

- Have more than 100 users
- Fetch users with query `next_token=100`
- Watch the result contain `next_token: 100`

local dev
