### Description
I was purging a few thousand users an appbridge left behind, all with `{ "erase": true }`, but got `{"errcode":"M_UNKNOWN","error":"No row found (profiles)"}` for a few dozen of them.
Without `erase: true`, I could successfully deactivate them.

### Steps to reproduce
- Try to delete users with erase: true
- Observe failure
- Try to delete same users without erase: true
- Observe success
