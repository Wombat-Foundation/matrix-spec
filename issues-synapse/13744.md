We are making two related changes related to packaging and from-source installations in 1.68:

- Rust: #12595 et al
- Sqlite: #12983

These should be transparent to anyone using our docker images or our debian packages. However, packagers and those installing from source need to be aware of the upcoming need for a Rust compiler and for a slightly more modern SQLite version.

We expect these changes to be uncontroversial, and have sounded out community packagers directly. Nevertheless, when we announce this (in Matrix channels, in a blog post, and maybe in a tweet?) we should call out these changes so that people are given fair warning.
