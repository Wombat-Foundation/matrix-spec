Using gmail, you can do 'user.name+test1@gmail.com' to create instant aliases of emails
Emails go to the same inbox, but Matrix does not know that.
However the + is filtered from the new account form so that it tries to register 'user.name test1@gmail.com' which is not a valid email address.
