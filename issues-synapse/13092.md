### Description

I'm using Azure AD(Microsofts IDP) as a identity provider for Synapse. During the login I'm passing a UID SAML attribute however during the login process this attribute is not registered and I recieved a login error stating that UID was not found during the login process.
The current config I'm using for saml is super basic
```
saml2_config:
  sp_config:
    metadata:
      remote:
        - url: https://login.microsoftonline.com/[my tenant ID/federationmetadata/2007-06/federationmetadata.xml?appid=[ service provider ID]
    service:
      sp:
        allow_unsolicited: true
enable_registration: true
enable_registration_without_verification: true
password_config:
   enabled: false
```

### Steps to reproduce

- Attempted to login to https://riot.im/app with my server
- Clicked "Login with SAML"
- Get redirected to a page stating the uid was not found in the saml response.
