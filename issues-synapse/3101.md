### Description

I am writing a game that I use Matrix as my chat protocol. As each user logs in I want the game to be able to attach some data from the user to the room, and for that data to be accessible by every other user.
I do this so that when a user hosts a game, it attached some json about the game that the other players can then join.

I almost got there with the .../state/{custom_event_type}/{state_key} (where the state key is the user id) API, but that only works for the user who created the room. Other uses get a forbidden response.

I suppose the quick solution would be to allow any user to have permission to write a state key based on their user id or some room permission to set certain events as publicly read/writable.
