### Description

The account_data and ephemeral events are not returned then when specifying a the "rooms" property of a RoomFilter while calling the /sync api endpoint

### Steps to reproduce

- GET https://b/_matrix/client/r0/sync?filter=###see below###
```
{
  "room": {

  },
  "presence": {
    "types": []
  },
  "account_data": {
    "types": []
  }
}
```
