for some reason, we build the docker image against libressl rather openssl, and libressl don't yet support tls1.3: https://github.com/libressl-portable/portable/issues/228.

That means that any docker-based synapse is going to fail to talk to a server which requires tls1.3 - which is becoming increasingly common.
