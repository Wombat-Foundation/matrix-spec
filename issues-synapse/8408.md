### Description

<!-- Describe here the problem that you are experiencing -->
If I try to verify a user with whom I share a room with already, it creates a new room where the other person has to join, and afterwards I can only verify if both users have "only encrypt to verified devices" deactivated, which seems really counter-intuitive.

This might also be a bug of the clients, but as it happens with Element Web and with Element Android I am guessing this is not the case.


### Steps to reproduce
- Join a room where other people are in.
- Try to verify a user of this room.

Edit:// Not restricted to homeserver, I just reproduced it with two accounts on matrix.org.
