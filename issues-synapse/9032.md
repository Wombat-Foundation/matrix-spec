With roots in [this suggestion](https://github.com/matrix-org/synapse/pull/7613#discussion_r438859896) by @richvdh, the current Delete Room API uses `POST /_synapse/admin/v1/rooms/<room_id>/delete` instead of `DELETE /_synapse/admin/v1/rooms/<room_id>`, on the logic that DELETE should not have a request body.

This logic is incorrect, as better detailed by [this stackoverflow answer](https://stackoverflow.com/a/299696), but in short, the spec supports it, and the matrix APIs already have other instances of `DELETE` being used with a request body.
https://matrix.org/docs/spec/client_server/latest#delete-matrix-client-r0-devices-deviceid
