Hi,

after an initial installation via the debian repository, synapse cannot start. The error is: 

> Missing mandatory `server_name` config option.

I have installed synapse via ansible, there is no way for an interactive install process like the installation documents recommend, so there was no way to add a value for `server_name` during installation.
I fixed it with manually adding this key and a value to homeserver.yaml, but maybe you could add a default value, wich then will be overwritten by the interactive installation process or via dpkg-reconfigure.
