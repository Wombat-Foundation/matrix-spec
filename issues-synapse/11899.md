### Description

Title says it all. Similar to #11840, all WEBPs are thumbnailed as JPEGs by synapse, leaving them with missing properties, in this case animation. Expected behavior is to be thumbnailed as a GIF, or even as another animated WEBP for file size reasons.

### Steps to reproduce

- Send an animated WEBP
- Be met with a still image thumbnail
