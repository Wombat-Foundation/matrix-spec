The group server should be a completely independent server from the homeserver or any other component in a matrix system. Having this separation allows for third party group servers and enhanced functionality, above and beyond what synapse may provide. 

The current situation is that group information comes down /sync, which effectively prevents the group server from being ripped away from synapse. The third party server could do some mitm handling of /sync, however that feels silly.

Further, the group server should get it's own series of endpoints (like the media repo). Instead of being under the client namespace, it should be under the `groups` namespace or similar (`/_matrix/groups/r0/whatever`).

I've filed this issue here for visibility, and the lack of spec. It would be greatly appreciated if the group server can be handled outside of synapse.
