### Description

Since an upgrade of Synapse to 1.30.0 (and a server restart), I encounter significant problems in a specific room (which before worked without any problem). Here are the symptoms:
- If I try to send a message in the room using Element, I get the message `User @XXX:YYY not in room  FhnTYZhdgIipdYUdar:otherserver.org (None)`, where `@XXX:YYY` is my userid.
- If I try to leave the room, I get the message `Not a known room`
- I can still read the history, and if someone sends a message to the room, I can see it as well.
