When requesting thumbnails for remote media, Synapse can get into a state where it believes the media does not exist. The requests 404 with a `M_NOT_FOUND`. To the best of my knowledge, Synapse does not attempt to fetch the media from the remote server. Synapse does have a local copy of the full file, which can be fetched via /download.

For example the media file https://matrix-client.matrix.org/_matrix/media/r0/download/gitter.im/415eae37d822051e667e63c35fb5e83e17414cf6 seems to load fine, but https://matrix-client.matrix.org/_matrix/media/r0/thumbnail/gitter.im/415eae37d822051e667e63c35fb5e83e17414cf6?width=32&height=32&method=crop will result in a 404.

The database for `matrix.org` contains no references to the thumbnail, suggesting we should be trying to fetch a fresh thumbnail fro m the remote server:
```
## matrix=> select * from remote_media_cache_thumbnails where media_origin = 'gitter.im' and media_id = '415eae37d822051e667e63c35fb5e83e17414cf6';

(0 rows)
```

The only logging we could find for the failing requests is:
```
2020-12-08 03:39:30,227 - synapse.rest.media.v1.thumbnail_resource - 273 - INFO - GET-1683972 - Failed to find any generated thumbnails
2020-12-08 03:39:30,232 - synapse.access.http.8085 - 331 - INFO - GET-1683972 - 115.99.189.246 - 8085 - {None} Processed request: 0.012sec/-0.000sec (0.004sec, 0.000sec) (0.001sec/0.002sec/2) 105B 404 "GET /_matrix/media/r0/thumbnail/gitter.im/415eae37d822051e667e63c35fb5e83e17414cf6?width=32&height=32&method=crop HTTP/1.1" "Mozilla/5.0 (X11; Linux x86_64; rv:83.0) Gecko/201001...
```

The gitter.im server is using the matrix-media-repo. Servers such as half-shot.uk are able to render a thumbnail, while servers using the Synapse media implementation are not able to.
