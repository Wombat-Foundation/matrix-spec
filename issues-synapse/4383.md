The user has a validated email address in `user_threepids`, and very likely left the identity server setting at `vector.im` when logging in to riot. The `trusted_third_party_id_servers` setting in homeserver.yaml lists `matrix.org`, `riot.im`, and `vector.im`. The `users_pending_deactivation` table is empty. The user says their account left all rooms, but they can still log in.

This is synapse 0.34.0.1-0matrix1 debian package running on a debian stable, on matrix.stratum0.org.
