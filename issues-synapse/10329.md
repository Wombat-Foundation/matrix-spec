### Description

We use Cloudflare Family Filter and get error REFUSED for a domain: dig srv _matrix._tcp.chat.mountainview.theworkpc.com @1.1.1.3 (it's probably categorised wrongly by Cloudflare, but that's not the issue here.)

The problem is that synapse get totally confused with this response (probably can't handle it) and starts to query the same domain again and again with no end it seems.

_Note: the domain in question is just an example to clarify the issue at hand._
