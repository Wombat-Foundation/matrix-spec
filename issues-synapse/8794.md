### Description

I've tried setting up a Synapse instance, using Docker and Caddy, following the official documentation, but the instance is not accessible outside of localhost. 

<!-- Describe here the problem that you are experiencing -->

### Steps to reproduce
So I tried to set up Synapse on an entirely fresh ubuntu vm using docker and Caddy. It seems like things are working, no errors in the log `docker logs synapse`. The content of the log is available for a month at https://paste.ubuntu.com/p/PKfrP5J5GW/

To check if things were working I used wget on localhost:8008 to see if there was a populated index.html. There was: "Your Synapse server is listening on this port and is ready for messages". So far so good.

However, when I use Element to connect to https://matrix.thewrt.com or https://matrix.thewrt.com:8448
I get: "Cannot reach homeserver". Furthermore, https://thewrt.com/_matrix/static returns an empty page, which I believe it shouldn't?

The steps I've taken are the following, are there any mistakes?

- install docker, docker-compose, set caddy up with docker-compose. Caddy's docker-compose file:
```
version: "3.7"
services:
  caddy:
    image: caddy
    container_name: caddy
    hostname: caddy
    restart: unless-stopped
    ports:
      - "80:80"
      - "443:443"
      - "8448:8448"
    volumes:
      - ./Caddyfile:/etc/caddy/Caddyfile:ro
      - ./data:/data
      - ./config:/config
networks:
  default:
    external:
      name: $DOCKER_MY_NETWORK
```
Note that $DOCKER_MY_NETWORK is defined in an .env file as being `caddy_net` 

- get Caddyfile from synapse documentation (https://github.com/matrix-org/synapse/blob/develop/docs/reverse_proxy.md#caddy-2):
```
matrix.thewrt.com {
  reverse_proxy /_matrix/* http://localhost:8008
  reverse_proxy /_synapse/client/* http://localhost:8008
}
thewrt.com:8448 {
  reverse_proxy http://localhost:8008
}
```
- create docker by running the following (as specified at https://hub.docker.com/r/matrixdotorg/synapse):
```
docker run -it --rm \
--mount type=volume,src=synapse-data,dst=/data \
-e SYNAPSE_SERVER_NAME=thewrt.com \
-e SYNAPSE_REPORT_STATS=yes  \
matrixdotorg/synapse:latest generate
```
- enable user registration in homeserver.yml
- run docker (as specified at https://hub.docker.com/r/matrixdotorg/synapse):
```
docker run -d --name synapse \
    --mount type=volume,src=synapse-data,dst=/data \
    --network=caddy_net \
    -p 8008:8008 \
    matrixdotorg/synapse:latest
```
- Docker network inspect caddy_nets lists synapse and caddy in the same container
- Checking ports 80, 443, 8448 from outside the local network shows they are open
