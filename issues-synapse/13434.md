### Description

So, in Element it is possible to enable custom themes, after importing some ones into the client it still has them when using an entirely different client. That makes me think that those themes are saved server side on the account you saved them in. For example, I have an account user0@example.org, I log into element.example.org, enable custom themes in Labs, import some ones into it. Then log off and log in as user1@example.org, those themes aren't there. Then I log in to Element desktop as user0@example.org and those themes are there. The problem is that I can't remove them, so if I import something bad, I can't get rid of it. I'm not sure whether that's intended or no, but I'll consider that as a bug.

### Steps to reproduce

Log into your account with Element and enable "Support adding custom themes" in Labs. Then import some themes and try logging into an another Element instance, you'll see those themes there.
