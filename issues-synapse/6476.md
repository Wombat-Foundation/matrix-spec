Currently [full schema SQL files](https://github.com/matrix-org/synapse/tree/master/synapse/storage/data_stores/main/schema/full_schemas) are made manually from creating Synapse SQLite and Postgres DBs from scratch, and then dumping them into SQL files. This is problematic as it only saves the final schema, but does not keep any of the data that is inserted into the DB.

Some of the delta files insert data in the DB which Synapse then assumes is there, causing bugs like https://github.com/matrix-org/synapse/issues/6311.

We should make sure that the schema *and* the data of a freshly migrated DB are saved in the delta file.
