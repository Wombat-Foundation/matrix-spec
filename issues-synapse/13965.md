Local room joins are known to be slow, currently taking anywhere from 266ms-1.7s or more when joining #synapse-dev (as an example room). Ideally this would take less than 300ms on average. More profiling work is needed to determine if there are any obvious changes to the code that will facilitate this. In addition, work on speeding up event persistence (including calculating push rules) would definitely help resolve this issue, although may be out of the immediate scope.
