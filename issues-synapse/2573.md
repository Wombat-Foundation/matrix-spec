After 'su postgres' i can run 'createdb' with my sudo accounts name but it complains there is no role for that user:

Update: I was able to view all roles with '\du' inside the psql shell.
`# \du`
`                                   List of roles`
` Role name |                         Attributes                         | Member of `
`-----------+------------------------------------------------------------+-----------`
`postgres  | Superuser, Create role, Create DB, Replication, Bypass RLS | {}`
