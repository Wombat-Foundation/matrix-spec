### Description

Hello,
When I was work about 1-2 months ago and testing synapse homeserver version 1.63, I created directory `/sync` in nginx. I am using homeserver with nginx reverse proxy on localhost port `8008`. The Synapse domain is `https://chat.xxx.com` also in that time was working with https://github.com/Awesome-Technologies/synapse-admin and add / deactive users.
I have set `/sync` in nginx chat config file to load data from `/var/www/html/chat/sync/` . When I have touched it in browser, https://chat.xxx.com/sync, all database flushed!

Database was using SQLite.

I think if `/sync` directory is sensitive, you should note it on config documents.
