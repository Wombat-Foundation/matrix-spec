Using Matrix for communication is really fantastic!
We use it for our organisation and completly migrated from other messaging-services to Matrix.
We often assign tasks to a group of people, which then create a room for the conversation.
If you want to pass a information to all of them, by now you have to write individual messages to everyone - not very convenient.
I would love to see an option which allows you to turn on direct messages to a room.
An answer to the message (by using the answer button) should then be directed to the original writer.

Thanks a lot!
