Following discussion in #10479 (and especially https://github.com/matrix-org/synapse/issues/10479#issuecomment-887001086), I've checked the sync response when Synapse does not have OTK (one time key) anymore. So when the number of OTK is changing from N to 0.

Instead of receiving 

```json
"device_one_time_keys_count":{"signed_curve25519":0}
```

The client receives

```json
"device_one_time_keys_count":{}
```

and so the client cannot distinguish "no change" and "no OTK left", and do not upload new OTK, which at the end breaks decryption of some messages.

Server version: 1.38.0 commit 12c92eec1
