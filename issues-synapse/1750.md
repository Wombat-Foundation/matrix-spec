When I forward a image or video it creates another file occupying storage and increasing costs. This should be reduced by having them as links instead of storing again.

We should also track the creator and he/she alone has the option of deleting it. If deleted by the creator/first uploader, the links should stop working. Video properties should contain the Matrix User ID of the original creator/first uploader.
