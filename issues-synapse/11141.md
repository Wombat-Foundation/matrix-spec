### Description

```
sudo -u synapse python
Python 3.9.7 (default, Oct 10 2021, 15:13:22)
[GCC 11.1.0] on linux
Type "help", "copyright", "credits" or "license" for more information.
>>> open('/etc/synapse/homeserver.log')
<_io.TextIOWrapper name='/etc/synapse/homeserver.log' mode='r' encoding='UTF-8'>
```

I downgraded to 1.41.1 (latest working version in pacman cache) and everything is working again.
