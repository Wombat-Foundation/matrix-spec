### Description

<!-- Describe here the problem that you are experiencing -->
When sending a text message containing "\^@" the message isn't send and an "internal server error" is reported.

### Steps to reproduce

Raw example text which caused this issue:
```
{
  "type": "m.room.message",
  "content": {
    "msgtype": "m.text",
    "body": "sending this text doesn't work: https://termbin.com/25z6\^@"
  },
  "event_id": "~!OGEhHVWSdvArJzumhm:matrix.org:m1618126067831.34",
  "user_id": "@Celmor:matrix.org",
  "sender": "@Celmor:matrix.org",
  "room_id": "!OGEhHVWSdvArJzumhm:matrix.org",
  "origin_server_ts": 1618126067831
}
```

on linux:
- run `nc termbin.com 9999 <<< "some text" | xclip -i -sel primary`
- paste and send in a matrix room
- get "internal server error"
