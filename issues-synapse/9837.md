**Description:**

I've played around with Matterbridge on my Nexcloud in January to have a Nextcloud Talk room connected to my Matrix account on my homeserver.

What I did not know: Matterbridge was opening a new session every few minutes. So from January to now I've ended with thousands of open sessions in my Synapse list, rendering my account pretty unusable.

There is no chance to check all these sessions in Element-Web and delete them here as even checking a single item in the list takes seconds. I guess this would take a day or more.

What is really missing is a "log out all sessions" button which deletes all active sessions. Such a thing is present in most projects for securlty reasons, we should have this in Synapse / Element as well.

Meanwhile, if someone could help with a database command to delete all the sessions it'll be helpful as a workaround.
