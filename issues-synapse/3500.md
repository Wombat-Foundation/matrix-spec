We've already discussed previously how difficult it is to keep displayname and avatar_url keys across profile updates due to UX issues. But for custom keys in the ``content``, it feels like we could easily keep them across membership updates. 

Use case is where in the discord bridge we set some custom keys so aware clients can show pretty role colours in their memberlists under ``uk.half-shot.discord.member``.
