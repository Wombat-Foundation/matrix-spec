### Description

After upgrading to 1.24.0+buster1 users can no longer login using LDAP against AD for authentication. Already authenticated users/devices (with tokens) do not seem to be affected, just new login attempts.

Issues seems to be a case-sensetivity issue

- Login as `Firstname.LastName' - Fails
- When `name` in `users` table is changed to match what is in LDAP, authentication works
- When username is entered `Lower Case` (`firstname.lastname`) in element `login screen` , authentication works

### Steps to reproduce
- Configure LDAP authentication
- Make sure `name` in `users` database is all lowercase but LDAP is Mixed Case ie: `User.Name` vs `user.name`
- Try to login
- **LDAP  Snippet**
```
password_providers:
     - module: "ldap_auth_provider.LdapAuthProvider"
       config:
         enabled: true
         uri: "ldap://ipaddress:389"
         start_tls: false
         base: "dc=domainr,dc=com"
         attributes:
            uid: "sAMAccountName"
            mail: "email"
            name: "givenName"
```

User logs in
