We've seen it happen a few times in EMS where a host will perform badly, bringing down the `synapse_http_request_apdex`, but when the host recovers the apdex does not until the host is restarted.

![image](https://user-images.githubusercontent.com/2072976/126779593-b6d60454-564f-4cf5-9922-57e66ab8ab57.png)

Above is a screenshot of two hosts, one being vector.modular.im and the other being openastronomy.modular.im. This is a graph of `synapse_http_request_apdex:6h`. A bridge is restarted around the time that the bad host starts to dip, which presumably drives down the metric. Over time however the host recovers, and currently the host is using virtually no resources but the metric has not improved.
