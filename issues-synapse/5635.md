I have the following setup:

-- 1x client server (https://www.mydomain.com) which has a local (192.168.x.x) and a public IP address.
-- 1x Matrix Synapse v1.1.0 server (https://matrix.mydomain.com) which has a local (192.168.x.x) and a public IP address.
-- Internal network communication/routing is done on the basis of the local IP addresses (shown in the homeserver.log).
-- Reverse Apache proxy according to this https://github.com/matrix-org/synapse/blob/master/docs/reverse_proxy.rst
-- `bind_addresses: ['127.0.0.1']` and `x_forwarded: true` for port 8008 are set in homeserver.yaml.

Issue: 
-- Every cURL request from the client server to the Matrix Synapse server results in a cURL timeout.
-- Every cURL (e.g. /login) requests are processed correctly by Synapse which is shown in the log.
-- However, no value is returned.
-- Requests made by a Riot Web (v1.2.2, with a public IP) work fine.

Question:
-- Does Synapse have an issue with handling local IPs in a local network?
