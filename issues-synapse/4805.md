### Description

register_new_matrix user only tries to connect on port 8448 by default. If you set `no_tls: True` in your homeserver.yaml, that won't work and crash fatally.

### Steps to reproduce
-`no_tls: True` in homeserver.yaml
- fill in new user data in `register_new_matrix_user`
- crash without registering
```
requests.exceptions.ConnectionError: HTTPSConnectionPool(host='localhost', port=8448): Max retries exceeded with url: /_matrix/client/r0/admin/register (Caused by NewConnectionError('<urllib3.connection.VerifiedHTTPSConnection object at 0x7f8ba14210b8>: Failed to establish a new connection: [Errno 111] Connection refused'))
```
Instead, it would be nice to pick up the config setting and try over http port 8008
