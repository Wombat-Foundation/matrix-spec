**Description:**

From looking at the docs and source code, it seems like there is no way to provide the postgres password as an environment variable. You can provide it when generating the config file, but not afterwards. This makes it difficult to version-control the config file.

I found a related issue https://github.com/matrix-org/synapse/issues/11489 that explores being able to dynamically configure any variable. I just wanted to bring this issue up separately because I think it is common enough that it warrants more urgency, so we should provide some solution in the interim in case #11489 requires more time. With the popularity of docker compose and infrastructure-as-code, I'd expect a fair number of users would want to be able to just version control their config file and be able to just add some environment variables and spin up their entire deployment. But having hard-coded passwords in the config file makes this much harder.
