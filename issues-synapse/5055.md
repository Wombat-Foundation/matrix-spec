### Description

Not sure if this is a bug or not.
I switched to a reverse proxy setup for the federation port and thus deactivated TLS completely in homeserver.yaml (`no_tls: True`).
On Startup of 0.99.3 I get the following warning:
```
twisted - 242 - WARNING -  - /home/matrix/synapse/env3/lib/python3.5/site-packages/synapse/config/tls.py:305: builtins.UserWarning: Self-signed TLS certificates will not be accepted by Synapse 1.0. Please either provide a valid certificate, or use Synapse's ACME support to provision one.
```

### Steps to reproduce

- Deactivate TLS in homeserver.yaml (`no_tls: True`)
- Startup synapse
- Check logs

### Expected
If no certs are being used, no warning about self-signed certs should be printed, I think.
