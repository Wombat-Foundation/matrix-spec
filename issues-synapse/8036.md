See https://github.com/matrix-org/sytest/issues/918#issuecomment-669613247. Basically, if you leave and rejoin a room too quickly, then the remote server might send you a make_join response whose prev_events predate your leave event, which seems to make synapse explode horribly.

Initially it returns a `404 - Unknown room` (which is bogus in itself), but subsequent attempts to join (even with a prev_events) result in an ISE:
