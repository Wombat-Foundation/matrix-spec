I'm Michael from the Antergos Linux project and we just integrated Matrix into our IRC channel via Freenode. We have noticed an issue that is not really a big deal but would be cool if it could be addressed.

We integrated #antergos on freenode with #antergos:matrix.org and overall it works fantastically, I especially like the support of IRC commands inside of Matrix. However, we found an issue with the IRC bot sending duplicate messages.

In IRC the bot sees links and then reshares the link with title and description automatically. This is a really useful feature in IRC but is completely unneeded in Matrix since Matrix does that by default. The result is Matrix has the link and all of the extra details fetched twice for the same link.

Overall this is not that big of a deal and we can tolerate it fine but it would be nice to identify the types of messages the bots send.

For example, in some cases our Bot sends regular messages but in the case of links, the Bot will send a channel "Notice". If it were possible to mute channel Notices from a particular IRC user rather than muting the user entirely then that would solve the duplication issue while keeping the rest of the features the bot provides in regular messages.

Would this be of interest to Matrix to address?
