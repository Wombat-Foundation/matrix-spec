**Issue description:**

A user on homeserver "domain2.de" invites a user on homeserver "domain1.de" to a chat.
The user on domain1 gets the invite, but as soon as he wants to accept the invite, he'll get "internal server error" after a few seconds.
There seems to be no way to accept the invite via Riot Web or Riot IOS.

**Homeserver:** 
Synapse/0.99.3 on Ubuntu 16.04 installed via Repos (Python 3 venv) (VM @ESXi 6.5)
