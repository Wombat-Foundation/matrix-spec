### Description

Debian package never finishes upgrading.

Upon further inspection, it appears that the `/var/lib/dpkg/info/matrix-synapse-py3.postinst` script invoked by `/usr/bin/perl -w /usr/sbin/dpkg-reconfigure matrix-synapse-py3 -u` is the culprit, as it never finishes, and hangs on a `read(8,`

I've had this problem for a few versions now. I thought my Synapse was still actually upgrading but in fact it was not. The Debian package manager thinks that a recent version is installed, but Synapse itself reports a different version:
`dpkg -l | grep matrix-synapse`:
```
ii  matrix-synapse-py3               0.99.2+stretch1                amd64        Open federated Instant Messaging and VoIP server
```
but:
`curl https://matrix.jaccu.se/_matrix/federation/v1/version`:
```
{
    "server": {
        "name": "Synapse",
        "version": "0.22.1"
    }
}
```

### Steps to reproduce

- `sudo apt upgrade`
- `/var/lib/dpkg/info/matrix-synapse-py3.postinst` gets invoked
- the upgrade stays there, not going further
