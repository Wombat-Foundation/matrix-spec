So I have this very specific use case where my homeserver was once up only occasionaly (because of virtu issues, apparently), then totally down, then up and running well, and I'm on a room on a homeserver which hasn't been able to reach mine because of routing problems on the provider's side.

So now that my own server is up and running and routing issues has been (almost) resolved, some events from the second homeserver never got synced with mine, including join events from an user (which is the account on matrix.org I was using during the said downtime). My homeserver isn't syncing these events, meaning that now I have an unlisted user speaking on the room and Riot doesn't seem happy with it as the profile picture and name apparently aren't provided (I believe it's Synapse who provide these info, correct me if I'm wrong).
