Myself and another homeserver's user are encountering an issue where synapse is repeatedly trying to fetch community flair for a community whose homeserver has gone AWOL, showing what appears to be bad backoff behavior:

```
2019-03-20 13:36:30,084 - synapse.util.retryutils - 193 - INFO - GET-3262 - Connection to tapenet.org was unsuccessful (<class 'synapse.api.errors.RequestSendFailed'>(Failed to send request: TimeoutError: User timeout caused connection failure.)); backoff now 86400000
2019-03-20 13:37:21,960 - synapse.util.retryutils - 193 - INFO - GET-3571 - Connection to tapenet.org was unsuccessful (<class 'synapse.api.errors.RequestSendFailed'>(Failed to send request: TimeoutError: User timeout caused connection failure.)); backoff now 0
2019-03-20 13:37:22,248 - synapse.util.retryutils - 193 - INFO - GET-3569 - Connection to tapenet.org was unsuccessful (<class 'synapse.api.errors.RequestSendFailed'>(Failed to send request: TimeoutError: User timeout caused connection failure.)); backoff now 0
```

Riot Desktop/Web and Android seem unaffected by this, but Riot iOS sees *crazy* message sending/scrollback loading lag whenever the flair for this down'd community would normally be fetched/shown, which seems to be a separate but related issue (synchronous waiting on those fetches to resolve perhaps?)
