Ask syweb where the web client is, rather than just presuming it's under `.__file__`. That way,  the debian package can declare that actually it lives in a different place, because debian packaging requires that the javascript lives in `/usr/share/javascript/...`.

(This does first depend on a later release of matrix-angular-sdk; see [SYWEB-381](https://matrix.org/jira/browse/SYWEB-381))
