Announced at https://mail.python.org/archives/list/twisted@python.org/message/LJU54CY4S5GIOE46B7XCBVXONRV4BHBX/

> This is mainly a bugfix release.
>
> The main bug is:
> - twisted.web.client.RedirectAgent and twisted.web.client.BrowserLikeRedirectAgent now properly remove sensitive headers when redirecting to a different origin. (`#10294`)

This refers to https://twistedmatrix.com/trac/ticket/10294, which refers to https://twistedmatrix.com/trac/ticket/10295. In turn, that refers to https://github.com/twisted/twisted/pull/1683, which removes deprecated functions and notes GHSA-92x2-jw7w-xvvx. At the time of writing, that security advisory has not been published.

However, the [commit corresponding to the advisory](https://github.com/twisted/twisted/commit/af8fe78542a6f2bf2235ccee8158d9c88d31e8e2) is available, and it notes a list of [five sensitive headers](https://github.com/twisted/twisted/commit/af8fe78542a6f2bf2235ccee8158d9c88d31e8e2#diff-e4b69c8a7d3ea27ae42bd8b9ce6000b391e3901c61294ccf2d238ec102d458e9R2117-R2121).

**Speculation:** my (DMR) guess is that the deprecated functions and RedirectAgents were both forwarding sensitive headers. The former has been removed, and the latter has been fixed.
