In the rare case of a database crash or an accidental deletion of entries in the table `event_forward_extremities` (the forward ends of the event graph, for each room) you are not able to use the room any more unless an external user sais something inside that room (which repairs the history through the federated data)

In this case there should be automatically added a new entry in the tabel event_forward_extremities for that room, so the room is usable again.
