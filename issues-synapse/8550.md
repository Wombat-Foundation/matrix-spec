The Room Details Admin API is [currently marked as "Draft"](https://github.com/matrix-org/synapse/blob/8075504a600b47ac93faf9b605ade691ae0fbcd3/docs/admin_api/rooms.md#draft-room-details-api), and is the only Admin API that is marked as so. This status was originally added by https://github.com/matrix-org/synapse/pull/7317 back in Synapse v1.14.0.

I believe the motivation for this change was to signal to implementers that this API is unstable and may change at any time. As this admin API has not had any backwards-incompatible changes since v1.14.0, I feel this status may no longer necessary. Additionally, it may actually be harmful as implementers may be avoiding using it until it is considered stable.

@awesome-manuel you originally advocated for the "draft" status. How do you feel about potentially removing it at this point?
