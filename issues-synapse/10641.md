Currently `check_event_for_spam` only gets called for local events in `create_and_send_nonmember_event`, meaning it doesn't get called for new `m.room.member` events, which looks like a thinko. Maybe it should instead be called in `create_new_client_event` which is where we also call `check_event_allowed`, or in `handle_new_client_event`.
