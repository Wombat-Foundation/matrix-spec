Synapse: 1.24.0 docker image on Ubuntu 20.04 all updated running on virtual server (amd64)
Postgres: 10.13 docker image on Ubuntu 20.04 all updated running on virtual server (amd64)

Around christmas, my homeserver domain (`matrix.schildbach,de`) had an expired DNSSEC signature for a few days, which caused it to become unknown for some DNS servers. I fixed the problem around the 27th of December and all my other services have recovered gracefully shortly after.

However, for my Matrix homeserver it seems to have triggered the "Unable to decrypt" problem for some (not all) of my encrypted rooms. One room affected in particular is `Internal room ID: !oxSBzcyFXyZyPcEOJL:matrix.org`. I cannot read any of these messages that were posted since my DNS problem.

Re-requesting keys (via the button) doesn't help, and by the way has never done anything for me.

In contrast to a [previous instance](https://github.com/matrix-org/synapse/issues/8889) of this problem I cannot find any error messages indicating an inconsistent database. The only database error I see about once per day is
