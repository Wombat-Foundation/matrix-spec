It would be very helpful to have a way to leave maintenance notes in a static way, e.g. by placing a static json file under `/_matrix/sync` or whatever endpoint riot typically looks at.

There are two use cases for this:
1) leaving a note to decommission a homeserver more gracefully than connection error / timeout
2) informing users during a maintenance window where an actual synapse server isn't available

My concrete use case is that my homeserver has a downtime due to server problems, and I would be able to divert traffic to inform users of the reasons but I can't actually get synapse up. As is, people get an unhelpful "Connection error" on riot-web or worse, "Riot is using battery" on riot-android.

I reckon this should be simple to spec and implement, and goes a long way towards smoothing over common error modes.
