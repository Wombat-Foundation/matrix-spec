### Description

When polling new events using the /sync endpoint, new events are not there instantly but with a delay of about 1.5 Minutes.
However the messages can be seen instantly when using a Matrix Client like element.
Furthermore the problem seems to be kinda solved when using long polling. Then only the first few requests will delay, but every following requests will get the new events instantly.

The problem is not there when using the /rooms/roomId/messages endpoint

### Steps to reproduce

- Write a message to a user using matrix
- Poll the message using /sync
- You will see a delay of about 30 seconds to 1.5 minutes
