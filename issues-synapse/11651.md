### Description

<!-- Describe here the problem that you are experiencing -->

Password changes using `/_synapse/admin/v2/users/<user_id>` do not work.

### Steps to reproduce

As described [here](https://matrix-org.github.io/synapse/latest/admin_api/user_admin_api.html#create-or-modify-account)

- `PUT /_synapse/admin/v2/users/@example_user:example.com` with a body of `{"password": "a_very_secure_string"}`
- Observe the `200 OK` response
- Find that `@example_user` is now both ejected from all sessions and unable to login with `a_very_secure_string`
