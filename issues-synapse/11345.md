The response generated for `/send_join` (and parsing of it on the federation client side) still uses an unstable prefix from [MSC3083](https://github.com/matrix-org/matrix-doc/pull/3083): `org.matrix.msc3083.v2.event`.

This should be updated to be just `event`, the stable field name. We probably need to send / handle both for a period of time unfortunately.

See https://github.com/matrix-org/synapse/blob/98c8fc6ce82d9d6b1bd21bf70df6a0e1ce91c1dc/synapse/federation/federation_server.py#L617
