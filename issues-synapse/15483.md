**Description:**

There seems to be no way to query the current admin of the room.
This is not available via https://matrix-org.github.io/synapse/v1.38/admin_api/rooms.html#room-details-api.

https://matrix-org.github.io/synapse/v1.38/admin_api/rooms.html#room-state-api seems to have this, but it's not clear (not well documented) how to parse the `m.room.power_levels` which I assume are what I am searching for.

User case:
On user deactivation (handled outside synapse), assign a new admin for all rooms the deactivated user is the admin of.
