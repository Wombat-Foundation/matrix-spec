[MSC2140](https://github.com/matrix-org/matrix-doc/pull/2140/files#diff-c03a26de5ac40fb532de19cb7fc2aaf7R274) adds a new API to the HS:

[`POST /_matrix/client/r0/account/3pid/unbind`](https://github.com/matrix-org/matrix-doc/blob/dbkr/tos_2/proposals/2140-terms-of-service-2.md#post-_matrixclientr0account3pidunbind)

Clients would use this to unbind 3PIDs on the IS (proxied via the HS).
