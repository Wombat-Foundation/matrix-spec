Currently there is no way to tell whether a given room is a space or not through Synapse's [Admin API](https://matrix-org.github.io/synapse/latest/usage/administration/admin_api/index.html).

Ideally, this would be exposed in both the [List Room](https://matrix-org.github.io/synapse/latest/admin_api/rooms.html#list-room-api) and [Room Details](https://matrix-org.github.io/synapse/latest/admin_api/rooms.html#room-details-api) APIs.

I suggest to expose a `type` property which returns the room type. The type would mirror the room's `m.room.create` event's `content.type` property. For a space, as specified by [MSC1772](https://github.com/matrix-org/matrix-doc/pull/1772) as `m.space`.
