### Description

When I try yo join a room (just any) I get a error 500.
The logs say there is an assertion error:
`assert room_id not in self._federation_event_handler.room_queues`

The comments from the source:
```
        # This shouldn't happen, because the RoomMemberHandler has a
        # linearizer lock which only allows one operation per user per room
        # at a time - so this is just paranoia.
        assert room_id not in self._federation_event_handler.room_queues
```

I do not know for how long this is broken, because I don't join rooms often. What I did recently was setup a bunch of workers, I can imagine this could be a source of the problem.
