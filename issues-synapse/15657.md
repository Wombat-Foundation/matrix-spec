[*As mentioned by @DMRobertson,*](https://matrix.to/#/!SGNQGPGUwtcPBUotTL:matrix.org/$Em8UxrFvoDCOrvws0YyM14itO_DwWHJvvN9S0MkzzGw?via=jki.re&via=matrix.org&via=element.io)

We should report the currently running version as a metric.

### Problem

It's hard to tell what the `matrix.org` deployment was running over time in order to correlate regressions.

The best we have seems to be to go log-diving in the internal ops Matrix room with a bunch of alerts and hope someone posted the commit hash at the time of the deploy.

### Dev notes

We have `SYNAPSE_VERSION` which looks like `1.84.0rc1 (b=matrix-org-hotfixes,184a688c64)` and includes a lot of useful information which looks perfect to report.
