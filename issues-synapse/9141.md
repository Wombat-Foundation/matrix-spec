### Description

Installation of `matrix-synapse` as outlined [here](https://github.com/matrix-org/synapse/blob/master/docs/workers.md#setting-up-workers) using `pip install matrix-synapse[all]` or `pip install matrix-synapse[redis]` does not work. Pip claims `pip: No match.`

### Steps to reproduce

Install `matrix-synapse` from source and execute `pip install matrix-synapse[all]` or `pip install matrix-synapse[redis]`.

### Solution

Install dependencies manually (in this case redis dependencies):

```
pip install txredisapi hiredis
```

### Version information

| Software | Version |
| :------------: | ----------: |
| matrix-synapse | 1.25.0 |
| python | 3.9.1 |
| redis | 6.0.10 |

### Platform

**OS** in use is **FreeBSD 12.2-RELEASE-p1 GENERIC amd64**
