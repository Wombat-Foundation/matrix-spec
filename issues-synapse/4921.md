The `preview_url` API seems to return an encoded response instead of JSON. For example, when trying: `https://matrix.org/_matrix/media/r0/preview_url?url=https%3A%2F%2Fgithub.com%2Fvector-im%2Friot-web%2Fissues%2F7153&ts=1553271576812`:

```
$ curl 'https://matrix.org/_matrix/media/r0/preview_url?url=https%3A%2F%2Fgithub.com%2Fvector-im%2Friot-web%2Fissues%2F7153&ts=1553271576812' \
-H 'Accept: application/json' \
-H 'Authorization: Bearer <access_token>'
\x7b226f673a696d61676...
```
