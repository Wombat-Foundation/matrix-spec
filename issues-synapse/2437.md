### Description

Upgraded Synapse from 0.19.1 to 0.22.1 using `apt-get upgrade`. I'm using `https://matrix.org/packages/debian/`. Now synapse won't start anymore

### Steps to reproduce

- `apt-get update && apt-get upgrade`
- `service matrix-synapse restart`

I expected synapse to restart. However I'm getting this now:

```
2017-09-02 23:11:14,974 - synapse.app.homeserver - 304 - INFO - - Server hostname: [redacted]

2017-09-02 23:11:14,976 - synapse.app.homeserver - 323 - INFO - - Preparing database: sqlite3...
2017-09-02 23:11:14,978 - synapse.storage.prepare_database - 212 - INFO - - Upgrading schema to v43
```

### Version information

- **Homeserver**: I'm running my own homeserver. DB is sqlite
- **Version**:   0.22.1 
- **Install method**: debian package     
- **Platform**:  Ubuntu 16.04.3 LTS on a VM

**Edit 1**: might be related to #2287

**Edit 2**: I did some more digging and I found the following: The hostname of my homeserver is `matrix.domain.com`, however the usernames in sqlite are `user@domain.com`. I.e. the subdomain is missing on the `users` table, which makes the startup test fail. I do have a `SRV` record on the main domain to point towards the matrix subdomain. This didn't cause any problems so far.
