### Description

"Recent" Element desktop and Element web clients cannot connect to synapse. It worked with older clients from ~ 2 months ago.
Desktop and Web client, if they were logged in before, the old view is shown and a bottom banner says that the connection is lost.
New login just gets stuck at loading, with the spinning loading icon in the middle of the screen. 

Element Android after upgrading from 1.5.11 to 1.5.18 stopped being able to connect. It started a new "sync" after upgrade and it got stuck on it.

The servers throws an error seen on the log and the clients are stuck connecting / loading.

### Steps to reproduce

- Start server
- Open Element client
- Client gets stuck loading
