As of now the server notices feature seems[ to only apply to one specific user](https://github.com/matrix-org/synapse/blob/master/docs/server_notices.md#sending-notices) through the manhole.

Due the nature of a server notice, as to be used for announcing maintenance for example, i think it would only make sense to at least give the option to send such a thing to all users located on the homeserver.
