The groups/communities feature in Synapse is unspecced (defined in [MSC1513](https://github.com/matrix-org/matrix-doc/issues/1513), kind of, but is abandoned) -- spaces ([MSC1772](https://github.com/matrix-org/matrix-doc/pull/1772) and friends).

There are still some useful features driven by Groups (namely flair) so it is unclear when this will happen. Note that Element Web has the capability to convert a Group -> Space.

A rough plan of how we might want to do this is:

* [x] Add an experimental config flag for groups that guards the unstable endpoints for groups.
* [x] Add a deprecation notice to our release and upgrade notes. (Should probably be done at the same time as 1.)
* [x] Default the above flag to `false` to disable those endpoints at the end of the deprecation period. The configuration flag should emit a warning if it is enabled.
* [x] (After some time...) Remove the groups code.
	* Endpoints
	* Handlers
	* Update the worker documentation
	* `RelatedGroups` constant
* [x] (After some time...) Bump the schema and remove the database tables for groups.

Related to #8334.
