This feature request is related to [MSC3394](https://github.com/matrix-org/matrix-doc/pull/3394), and necessary for a new generation of social-media focused matrix clients like [Minestrix](https://matrix.to/#/#minestrix:carnot.cc) and [Matrix Art](https://matrix.to/#/#matrix-art:nordgedanken.dev).

These social-media-focused clients use rooms to store posts, and threads to store comments. But because of current limitations in the current permissions system, they have to choose between these two options:

1. Either regular members *can* send messages to the room, and therefore everyone can write posts on your wall...
2. Or they *can't*, and therefore only you can write posts on your wall, but no one can comment them.

A third option is necessary, where only you can write posts on your wall, but regular members of the room can comment those posts. For that we need to have a new permission that lets someone write a message only if it's inside a thread; that is, if that message is in relation to another message.

Apparently this change needs to be implemented by a client before the MSC can be approved, and it needs to be included in Synapse before any clients can implement it. So there's a real need for Synapse to include it.
