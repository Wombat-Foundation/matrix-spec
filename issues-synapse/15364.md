### Description

T.: We tried registering a Matrix user on our server. Usually, this useda work by just using the `register_new_matrix_user` script. Yet, regardlessa whether we supplied the registration secret via the config file or directly, n regardlessa whether we supplied the URL ourselves or let't be autodiscovered, 't always hung at `Sending registration request`. So, we tried setting `enable_registration` n `registration_requires_token` to `true`, generated a registration token, n tried registering thru Element (https://element.artemislena.eu) (we dunno whether Element actually supports registration tokens even, n'f not, whether *any* client does, we just tried't out). Well, after entering username n password on the registration window, that hung forever, too. Checked the browser console, apparently we were getting 429 (i.e. rate limit?) on the endpoint for checking whether the username was available (said endpoint simply returned `{"true"}` when we tried opening't manually in the browser, btw). At that point, I asked in the Synapse Admins room, where, after excluding several config issues, I was told trying registering w `synadm`. That timed out too (see logs below) n I was told we should open a GitHub issue, so there we go.
