I had some trouble because my server updates automatically. since version .29 synapse introduced a new configuration requirement on apache2 (x-forward-proto) which lead to some errors which i was not aware of.
when in this moment one tried to contact another person on my server (e.g. from @matrix.org to @mysmallhomeserver.com) the key exchange seemed to fail. thats not a big deal because i noticed that error in the logs and followed the migration guide (adding that x proto forward header).
but it was impossible since then to communicate with the person. he was able to read my messages and he has seen that i have seen his messages, but i was unable to read them. 
i had to manually verify him with the emojis - after that it worked. i guess that "broken" key (or no key at all) has been exchanged and was not updated automatically.
i am a technical person and was able to fix that but i guess most people have no idea what to do in that case.

would it be possible to somehow popup a messagebox "the key does not match or is not existent, would you like to verify the other person manually?" and when pressed "yes", popup the emojis for manual verification.

if i should create this in the client instead of synapse, please let me know.
