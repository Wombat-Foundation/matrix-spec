Hi, 

I'm trying to use a filter to get only messages in my room timeline, my filter looks like this:

```json
{
    "room": {
        "timeline": {
            "limit": 1,
            "types": [
                "m.room.message",
                "m.room.encrypted",
            ]
        }
    }
}
```
The problem is that when I'm using this filter I only get old state events even though I haven't specified a filter on them, for example when I update the ```m.room.power_levels```, the change takes effect but I don't get the updated state when I'm using that filter so I tried explicitly specifying the state filter and got the same result, then I thought it might be the limit and tried that too but it was the same.

My filter ended up looking like this:
```
{
    "room": {
        "state": {
            "limit": 9007199254740991, (Yes, I know it's absurd)
            "types": [
                "*",
                "m.room.create",
                "m.room.power_levels",
                "m.room.name",
                "m.room.member",
            ]
        },
        "timeline": {
            "limit": 1,
            "types": [
                "m.room.message",
                "m.room.encrypted"
            ]
        }
    }
}
```

I'm using a Synapse Homeserver, Installed using pip version 1.25.0
