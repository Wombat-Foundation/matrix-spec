To speedup sending a message in an encrypted rooms, we are considering the possibility to pre-share megolm outbound keys when opening a room. So when typing/sending a message (in most cases) outbound keys are already shared and setup.
Note: element-web does it already when you start typing.

This change may entail some side effects (like network congestion when a high number of members will open the room), so we consider we should be able to notify the clients about the best mode of pre-sharing to apply. So we suggest introducing a new `_matrix/client/versions` flag: `io.element.e2ee_outbound_keys_pre_sharing`

We would consider 3 values:
- disabled
- on_typing
- on_room_opening
