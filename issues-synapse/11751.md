### Description

originally reported as https://github.com/vector-im/element-web/issues/20543
<!-- Describe here the problem that you are experiencing -->

> it seems to me that there also is an issue either with synapse or with synapse-admin that addresses added by admins (i.e. without regular verification flow) are not marked as "verified", and the server tells the client that when resetting. could you open issues with the respective projects or point me to the relevant one?

> The server is free to request anything it wishes via UIA flows so this sounds like a backend issue rather than an Element one. Element can't assume/filter the requested UIA flows based on the exact path the user is taking as the spec allows any UIA flow to be used on any UIA-enabled API.

### Steps to reproduce

  1. add 3PID email address to an account via synapse-admin, i.e. it is added without confirming it
  2. do a pw reset using element
  3. after entering new pw, it asks whether you have verified your email address unnecessarily
  4. you can ignore and continue, but it sounds weird
