I’d like if the admin account_data API was extended to allow setting account data. It currently only supports viewing the account data. 

The only way to set account data is currently by using `PUT /_matrix/client/v3/user/{userId}/account_data/{type}` as defined here: [Matrix API](https://matrix.org/docs/api/#put-/_matrix/client/v3/user/-userId-/account_data/-type-) 

I don’t know how many practical uses this would have but I’d need it to add [Stickerpicker](https://github.com/maunium/stickerpicker)  stickers for other users.

As a workaround I’ve simply modified this line on [account_data.py](https://github.com/matrix-org/synapse/blob/4ec40b16ac2436387d5d947308e5dc37857acbf6/synapse/rest/client/account_data.py#L241) 

```python
if user_id != requester.user.to_string():
```
```python
if user_id != requester.user.to_string() and requester.user.to_string() != “@adminaccount:myserver.tld”:
```
