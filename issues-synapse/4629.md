Hi,

i tried to build a cleanup script for me. It should remove remote_media and also local messages in different rooms on my homeserver. (mostly rss feed rooms, which can be deleted after 3 days.). but for some reason it says 

{
    "deleted": 0
}

and 3 time different purge ids, but records  still are there. 

{
    "purge_id": "fWxhWFUmZKonpArr"
}
Log entry only shows:
2019-02-12 14:10:57,195 - synapse.handlers.pagination - 106 - INFO - POST-7347- [purge] starting purge_id fWxhWFUmZKonpArr

same for others with different id.

I enclose the script, maybe i have overseen something:

<pre>
#!/bin/sh

# token is in the settings page of your riot client (desktop at least)

TOKEN="yourtoken"
MATRIXSV="https://YOURSERVER/_matrix/client/r0/admin"
CURL=/usr/local/bin/curl
TIMESTAMP0=`date +%s`
# we want to keep 3 days
TIMESTAMP3=`date -v-3d +%s`
TIMESTAMP3C=`date -v-3d`

echo "--------------------------------------------"
echo "`hostname` Cleanup Start! `date`"
echo "--------------------------------------------"

echo "--------------------------------------------"
echo "cleanout remote media store till ${TIMESTAMP3C} (${TIMESTAMP3})"
echo "--------------------------------------------"

# https://github.com/matrix-org/synapse/blob/master/docs/admin_api/purge_remote_media.rst

${CURL} -XPOST -d "{ \"before_ts\":${TIMESTAMP3} }" "${MATRIXSV}/purge_media_cache?before_ts=${TIMESTAMP3}&access_token=${TOKEN}"

echo "--------------------------------------------"
echo "cleanout special rooms till ${TIMESTAMP3C} (${TIMESTAMP3})"
echo "--------------------------------------------"

# https://github.com/matrix-org/synapse/blob/master/docs/admin_api/purge_history_api.rst

echo "--------------------------------------------"
echo "ROOM ONE should clean local too"
echo "--------------------------------------------"
# !roomid:server
# Cleanout local too

${CURL} -XPOST \
        --header "Content-Type: application/json" \
        --data "{ \"purge_up_to_ts\" : ${TIMESTAMP3} , \"delete_local_events\" : true }" \
        "${MATRIXSV}/purge_history/!roomid:server?access_token=${TOKEN}"

echo "--------------------------------------------"
echo "ROOM TWO should clean local too"
echo "--------------------------------------------"
# !roomid:server
# Cleanout local too

${CURL} -XPOST \
        --header "Content-Type: application/json" \
        --data "{ \"purge_up_to_ts\" : ${TIMESTAMP3} , \"delete_local_events\" : true }" \
        "${MATRIXSV}/purge_history/!roomid:server?access_token=${TOKEN}"

echo "--------------------------------------------"
echo "`hostname` Cleanup End! `date`"
echo "--------------------------------------------"

df -h

echo "--------------------------------------------"

du -h /usr/local/pgsql | tail -5

echo "--------------------------------------------"

du -h /var/db/matrix-synapse | tail -10

</pre>
