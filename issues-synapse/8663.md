The [delete room admin API](https://github.com/matrix-org/synapse/blob/develop/docs/admin_api/rooms.md#delete-room-api) covers all of the functionality of the [shutdown room admin API](https://github.com/matrix-org/synapse/blob/develop/docs/admin_api/shutdown_room.md) and more.

Instead of having two endpoints that do roughly the same thing, we should deprecate the less useful one.

A deprecation warning will need to go out in the changelog, to allow people to update their third-party code before we eventually remove the API altogether.
