[MSC3316](https://github.com/matrix-org/matrix-doc/pull/3316) recommends that `PUT /_matrix/client/r0/rooms/{roomId}/state/{eventType}/{stateKey}` should support a `ts` key for appservices to override the `origin_server_ts` value of an event. This is already supported in Synapse for normal events, as the feature has been in Synapse for a long time (albeit [excluded from the spec](https://matrix.org/docs/spec/application_service/r0.1.2#timestamp-massaging); MSC3316 aims to revive it).
