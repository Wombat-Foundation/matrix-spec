### Description

Doing normal `apt upgrade` on Debian 11 (bullseye) using matrixorg repository from 1.77.0 -> 1.78.0, the installation fails with:

```
dpkg-deb: error: archive '/tmp/apt-dpkg-install-58Z80T/5-matrix-org-archive-keyring_1.1_all.deb' uses unknown compression for member 'control
.tar.zst', giving up
dpkg: error processing archive /tmp/apt-dpkg-install-58Z80T/5-matrix-org-archive-keyring_1.1_all.deb (--unpack):
 dpkg-deb --control subprocess returned error exit status 2
Errors were encountered while processing:
 /tmp/apt-dpkg-install-58Z80T/5-matrix-org-archive-keyring_1.1_all.deb
E: Sub-process /usr/bin/dpkg returned an error code (1)
```

Initial searching suggest that Debian 11 dpkg doesn't support zstd compression, support came in for Debian 12, which is still very much alpha.

### Steps to reproduce

- Have Debian 11 / Bullseye as OS
- Use matrixorg provided repository installed Synapse
- Do normal `apt update+upgrade` procedure
