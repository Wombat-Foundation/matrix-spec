### Description

I want to migrate my (a few years old) sqlite3 homeserver.db with around ~7GB to a PostgreSQL database. Unfortunately the migration always fails at the same point with `invalid input syntax for type bigint`.

I tried to VACUUM the database after the import failed for the first time using `sqlite3 /opt/synapse-data/homeserver.db.snapshot "VACUUM;"` and I also checked the integrity with `sqlite3 /opt/synapse-data/homeserver.db.snapshot "pragma integrity_check;"`.  The latter command responded with "ok".

### Steps to reproduce

- Follow the steps in the [official manual](https://github.com/matrix-org/synapse/blob/master/docs/postgres.md#porting-from-sqlite)
- I removed the folder `/data/schema` so a completely new PSQL database gets created during container startup
- I started both docker containers with `docker-compose up -d`, config is like in [this template](https://github.com/matrix-org/synapse/tree/develop/contrib/docker) and only the port, volume directories and passwords were changed
- I got into the container for synapse with `docker exec -it synapse-synapse-1 /bin/bash`
- And executed `synapse_port_db --sqlite-database /data/homeserver.db.snapshot --postgres-config /data/homeserver-postgres.yaml --curses`
- After a short period of time the error appears
