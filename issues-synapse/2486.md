When monitoring system, IoT device is used with matrix, there is some possibility, that the access token gets stolen.

Now imagine a monitoring system of BigCorp. Someone getting access to the access_token, could join other rooms and try to impersonate an employee of BigCorp.

If user accounts / access_tokens could be locked down, so that they are not able to get access to other rooms / accept invitations, this would be much harder.
