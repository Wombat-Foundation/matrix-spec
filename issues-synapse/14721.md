### Description

if depoly with workers and nginx
login with synapse-admin, api `/_synapse/admin/v1/users/@hello:xxx.xxx/media?dir=b&from=0&limit=50&order_by=created_ts` will response 400

Because the request does not have the correct forwarded media service
in the [https://github.com/matrix-org/synapse/blob/develop/docker/configure_workers_and_start.py#LL83C13-L83C51](https://github.com/matrix-org/synapse/blob/develop/docker/configure_workers_and_start.py#LL83C13-L83C51) file
The regular expression of media_repository has only one `"^/_synapse/admin/v1/user/.*/media.*$"`

he failed to handle `users` correctly

should be changed to
`"^/_synapse/admin/v1/(user|users)/.*/media.*$"`
