### Description

With Synaps 0.99.5.2, running `hash_password` yields an `AttributeError` when accessing the `pepper` key of the `password_config` section, when it is empty.

### Steps to reproduce

- Install Synapse 0.99.5.2
- Create a sample configuration file with `python -m synapse.app.homeserver --server-name example.com --config-path config.yaml --generate-config --report-stats=yes`
- Run `hash_password -c /path/to/config.yaml`

```
$ hash_password -c /path/to/config.yaml 
Traceback (most recent call last):
  File "[…]/bin/hash_password", line 56, in <module>
    password_pepper = password_config.get("pepper", password_pepper)
AttributeError: 'NoneType' object has no attribute 'get'
```

`config.yaml` contains the default `password_config` stanza, i.e.:

```yaml
password_config:
   # Uncomment to disable password login
   #
   #enabled: false

   # Uncomment and change to a secret random string for extra security.
   # DO NOT CHANGE THIS AFTER INITIAL SETUP!
   #
   #pepper: "EVEN_MORE_SECRET"
```

Patching the line causing the error to this seems to avoid the issue:

```python
        password_config = config.get("password_config", None) or {}
```

### Version information

- **Homeserver**: (own, can use fresh example setup)
- **Version**: 0.99.5.2
- **Install method**: PIP
- **Platform**: Debian GNU/Linux stable
