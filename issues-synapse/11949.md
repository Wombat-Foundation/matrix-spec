https://spec.matrix.org/v1.2/client-server-api/#token-authenticated-registration is now part of the spec, so the unstable token proposed in https://github.com/matrix-org/matrix-doc/pull/3231 can be deprecated.

The endpoint `/_matrix/client/unstable/org.matrix.msc3231/register/org.matrix.msc3231.login.registration_token/validity` and needs to be replaced with https://spec.matrix.org/v1.2/client-server-api/#token-authenticated-registration
