I fixed it by adding the following lines to the `synapse_port_db`:
```
BOOLEAN_COLUMNS = {
    ..
    ..
    "redactions": ["have_censored"],
    "room_stats_state": ["is_federatable"],
}
```
The script runs without problems and it looks like there are no issues with the clients. Everything looks fine.

Is there more that I could have done?
