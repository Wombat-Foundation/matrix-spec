### Description

I'm trying to add Rooms to Spaces via the /state/m.space.child/ API, but they are not listed with the /hierarchy Endpoint.
When a Room is added to a Space via the Element Desktop App or the Element web App, which runs the exact same API request, the Room is listed like expected.

is there needed an additional step to get the room added to a space get listed in the hierarchy?
I can't see anything different watching the network tab in the browser console.

I'm calling the API serverside via PHP CURL, but I think, that shouldn't matter

### Steps to reproduce

- run a PUT request like https://matrix.org/_matrix/client/r0/rooms/%21#####%3Amatrix.org/state/m.space.child/%21#####%3Amatrix.org?access_token=##### with params {via: ["matrix.org"], suggested: false}
- try to get the hierarchy with https://matrix.org/_matrix/client/v1/rooms/%#####%3Amatrix.org/hierarchy?access_token=#####&suggested_only=false&limit=20
- the Room is not listed in the hierarchy, only rooms which are added via the Element web or Desktop App
- the Room is listed in the roomlist of the space in the web or Desktop App, but not in the Space overview or in the Space on the Android App
- I can remove the room via the same API request and empty params, no problem. 
- viewing the Space - messages of my API request and the request by the APP, they are exatly the same and looking like that in both cases (stripped):
