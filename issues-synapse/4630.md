### Description

When in register-process you will get "Phone numbers are not authorized to register on this server", when defining it in "homeserver.yaml" as required.

### Steps to reproduce

1. Edit your "homeserver.yaml"
2. Uncomment/add "msisdn" in Registration-Section:
`	# Enable registration for new users.
		enable_registration: True
	registrations_require_3pid:
  		- email
  		- msisdn
`

3. Register a new User [Here I used Riot to register a new Account] 
3.1 define e-mail, valid phoneNumber, userName and password
3.2 hit register

When processing, you will see in the log-file:
` 14:30:33,187 - synapse.access.http.8008 - 233 - INFO - POST-44- <IP> - 8008 - Received request: POST /_matrix/client/r0/register/msisdn/requestToken

2019-02-12 14:30:33,188 - synapse.http.server - 85 - INFO - POST-44- <XForwardedForRequest at 0x7f83ae35c160 method='POST' uri='/_matrix/client/r0/register/msisdn/requestToken' clientproto='HTTP/1.0' site=8008> SynapseError: **403 - Phone numbers are not authorized to register on this server**"`

I also tried to set "disable_msisdn_registration: False" and 

`allowed_local_3pids:
   - medium: msisdn
     pattern: '\+491907777777'`



### Version information
- **Homeserver**: 
matrix-synapse

- **Version**: 
0.99.0

- **Install method**: 
I installed it via the official package 

- **Platform**: 
Debian 9.7
