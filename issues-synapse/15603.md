*Spawning from https://github.com/matrix-org/synapse/pull/15602,* where we should be running `mypy` with our minimum supported Python version since later versions can include overloads, etc which aren't backwards compatible.

Before we can actually [merge the PR which updates the CI to use Python 3.8](https://github.com/matrix-org/synapse/pull/15602), we have to resolve the lints that pop up first so we don't just have a broken CI after merging https://github.com/matrix-org/synapse/pull/15602

### Dev notes

Find/replace from the `mypy` output to generate that list:

Find:
```
^(.*):(\d+): (.*)$
```

Replace:
```
 - [ ] [`$1:$2`](https://github.com/matrix-org/synapse/blob/ba572647b291e593e70a30e45c234c9766472ff3/$1#L$2): `$3`
```
