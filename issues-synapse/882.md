running 

```
python -m synapse.app.homeserver \
    --server-name machine.my.domain.name \
    --config-path homeserver.yaml \
    --generate-config \
    --report-stats=[yes|no]
```

sets, unlike the deb package:
- registration_shared_secret
- macaroon_shared_secret
- server_name

the deb package sets  idp_redirect_url to an unsable value "http://test/idp", also web_client bool is set differenty. I suggest syncing the resulting configuration so that only paths differ, not actual server defaults.
