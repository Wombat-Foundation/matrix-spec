Installed using pip on ubuntu, running 0.99rc4. `synctl stop` says it is stopping the homeserver, however the logs indicate that the server is still processing new requests with no indication of stopping. `synctl restart` has a similar problem in that it blocks for a long while until the server is manually stopped.

Appears to not matter if workers are being used or not: the master process will always hang. Process requires `kill -9`. 

Using python 3.
