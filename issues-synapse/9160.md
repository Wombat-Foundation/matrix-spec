Hi,

I've set up a self hosted configuration with a Synapse and an Element-web instances on the same domain. The Synapse instance is locked to accounts registered on our domain, and the Element-web instance defaults to our own Synapse home server.

Authentication uses our SSO (OIDC via LemonLDAP::ng). everything works like a charm, but there is this annoying SSO configuration step keeping asking us:
> The application at element.example.com is requesting full access to your example.com Matrix account.
> If you don't recognise this address, you should ignore this and close this tab.

Since we manage both instances, a white list option to allow bypassing this confirmation step would be appreciated.

Thanks in advance for considering.
