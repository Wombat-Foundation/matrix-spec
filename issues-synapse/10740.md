### Description

I made a typo in a complement test as follows:

```go
	privateRoom := bob.CreateRoom(t, map[string]interface{}{
		"visibility": "private",
		"invite":     []string{bob.UserID},
	})
```

That'll end up sending a call to `/createRoom` with Bob's access token which tries to also invite Bob.

This is a silly thing to do, but I expected a 400 Bad Request rather than a 403 Forbidden.
