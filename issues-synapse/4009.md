When we fetch state from data store we split the query in two: one for members and one for non-members:

https://github.com/matrix-org/synapse/blob/92faeb2a3fc73bd9307b3192aeacec4afb1aad1a/synapse/storage/state.py#L765-L772

This was introduced to support lazy loading (in particular to make the caches better), however these queries are expensive for the database. Ideally, we should always make at most one query to the database, even if the caches remain separate.
