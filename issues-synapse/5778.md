**Description**

I am trying to implement my own password provider. To begin with I started with the simplest possible provider:

~~~~
from twisted.internet import defer

class SimpleAuthProvider(object):

    def __init__(self, config, account_handler):
        pass

    @defer.inlineCallbacks
    def check_password(self, user_id, password):
        defer.returnValue(True)

    @staticmethod
    def parse_config(config):
        return None
~~~~

I adjusted my homeserver.yaml accordingly:

~~~~
password_providers:
  - module: "simple_auth_provider.SimpleAuthProvider
  - config:
~~~~

Then I tried to login with riot web, using different (existing and non-existing) accounts and (correct and incorrect) passwords.

**Expected Behavior:**

I would expect to be able to login with any password.

**Actual Behavior:**

Riot reports at the login page: "Error: Problem communicating with the given homeserver. (M_UNKNOWN)".
