As per https://github.com/vector-im/vector-web/issues/321 we'd like invite metadata to include both m.room.aliases as well as m.room.canonical_alias, as if a room has no canonical alias or name set (e.g. #test:matrix.org), we otherwise have no way to refer to it in the UI.
