### Description

The matrix-synapse server didn't successfully start after upgrading to the newest version (0.26.0-1).

### Steps to reproduce

- Install version 0.25.1 of matrix-synapse.
- Upgrade matrix-synapse to version 0.26.0.
- Do `systemctl restart matrix-synapse`.
- Synapse will try to start, but stops after getting several errors (shown below).

![screenshot from 2018-01-07 10-53-17](https://user-images.githubusercontent.com/20875906/34648572-c747fdac-f39b-11e7-9ee9-9103355e318c.png)

Describe how what happens differs from what you expected.

Normally running `apt upgrade` and `systemctl restart matrix-synapse` upgrades and restarts matrix-synapse.
This time however, matrix-synapse stopped while starting up.
