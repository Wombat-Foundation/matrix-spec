### Description
The events sometimes take place with a long delay or only when they are repeated. Symptoms/examples:
- file upload (response: "The file 'image.png' failed to upload.")
- unable to view incoming attachments (response: {"errcode":"M_UNKNOWN","error":"Failed to fetch remote media"}. With nginx timeout first.)
- login using the Element web client (our instance at https://riot.vesp.cz)
  - the first attempt (response: Invalid homeserver discovery response) - this always happens 🥴
  - the second and further attempts (response: Error: Problem communicating with the given homeserver.)
  - no messages are leaving the home server matrix.vesp.cz ([configuration](https://github.com/otevrenamesta/otevrenamesta-cz-configuration/blob/master/machines/matrix.nix)). At the same time, incoming messages are delivered immediately
    - internal users (home server matrix.vesp.cz) can communicate (without attachments)
    - SmsMatrix bot sends/receives messages..🙈

Without any external intervention, everything will start working correctly within x-tens of minutes or units of hours. (Unsent messages are delivered, second sign-in attempts are successful. In the wrong order of course.)

### Steps to reproduce
The [configuration](https://github.com/otevrenamesta/otevrenamesta-cz-configuration/blob/master/machines/matrix.nix) is [fully reproducible](https://nixos.org/) 🙊 (I know, too laborious.)

### Version information
- **Homeserver**: matrix.vesp.cz
- **Version**: 1.23.0
- **Install method**: Hydra - https://github.com/otevrenamesta/otevrenamesta-cz-configuration/blob/master/machines/matrix.nix
- **Platform**:
  - hosted at [vpsFree.cz](https://vpsfree.org/)
  - running in a container behind central [reverse proxy](https://github.com/otevrenamesta/otevrenamesta-cz-configuration/blob/master/machines/proxy.nix) (nginx)
  - NixOS
