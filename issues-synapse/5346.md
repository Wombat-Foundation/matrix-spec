### Description

in `homeserver.yaml`, when `public_baseurl:` is configured to `http://<homeserver>` and there are only `tls: true` listeners, many clients throw misleading errors:

    NETWORK_ERROR
    net::ERR_EMPTY_RESPONSE

And synapse does not report any errors. 

### Steps to reproduce

- set `public_baseurl: "http://<homeserver>:8448"` in homeserver.yaml
- set `listeners: [{port: 8448, bind_address: "", type: http, tls: true, x_forwarded: false, resour
ces: [{names: ["client","webclient","federation"], compress: false}]}] ` in homeserver.yaml

- start the homeserver
- log in with riot-desktop or riot-android.
