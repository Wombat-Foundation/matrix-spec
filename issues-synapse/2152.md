I use the following query to sync with matrix.org

```json
sync?full_state=true&set_presence=online&filter={"presence":{"limit":0},"room":{"ephemeral":{"limit":0},"timeline":{"limit":70}}}
```
but I receive an empty `state` array on the rooms which I am the creator. 

If I remove the timeline filter like so

```json
sync?full_state=true&set_presence=online&filter={"presence":{"limit":0},"room":{"ephemeral":{"limit":0}}}
```
I receive all the `state` arrays as expected. 

Is this the expected behavior? The spec states that if `full_state: true` all the state events will be returned. Also it seems really unintuitive that a timeline filter will affected the state.
