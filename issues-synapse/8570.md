## Describe the problem

Currently, [`EventBase`](https://github.com/matrix-org/synapse/blob/898196f1cca419c0d2b60529c86ddff3cea83072/synapse/events/__init__.py#L205) and subtypes have `DictProperty` attributes, but these attributes aren't checked when filled with the values of the internal `_dict`.

This is required to uphold invariance (#8376) throughout wherever these objects are used.

## Solution

Either explicitly mention that these fields (by design) can't verify/alter/reject their values (because the event is already persisted or federated before its ever touched), or verify those values upon creating the object, upholding the annotated types.
