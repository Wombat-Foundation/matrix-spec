### Steps to reproduce

- Set up a synapse homeserver using sqlite as the database
- Enable `account_validity` (I used the example config in the `homeserver.yaml` file, and only changed the `period` configuration option from `6w` to `12w`)
- Create a new user
- Start the server, log in, poke about.
- Follow the [postgres documentation steps to use the porst script](https://github.com/matrix-org/synapse/blob/master/docs/postgres.rst#using-the-port-script), so shut down, create snapshot copy of the database, start server again, run the port script.

- **Homeserver**:  `zopatista.com` (public URL `https://matrix.zopatista.com`)

If not matrix.org:

- **Version**:  0.99.5.2

- **Install method**:  apt, from https://packages.matrix.org/debian/

- **Platform**:  Linux (Debian Buster)
