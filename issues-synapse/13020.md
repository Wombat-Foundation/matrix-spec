I'd expect to see community worker endpoints that are going to be nuked in Synapse 1.61 ( https://github.com/matrix-org/synapse/pull/12936/files#diff-4eef4606c1f655c8f2b04944a322717d2dfe2a32f6df6df8403dad7ebdd00052 ) to be listed in Synapse upgrade notes at release time.

Reasoning: It is easy to check current state of _existing_ endpoints from workers.md, but opposite is not true, surprisingly hard to determine does one have an endpoint in their config that is _not_ listed on workers.md anymore. So at least upgrade notes should reveal "these endpoints are removed, go check your worker config".
