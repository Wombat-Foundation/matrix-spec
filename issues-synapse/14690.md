### Description

Hello,

I've observed this weird bug for a while.

I join a room and after a while I can no longer send messages.

Log says this:

```
2022-12-17 19:25:07,773 - synapse.access.http.8008 - 415 - DEBUG - OPTIONS-650 - [long IPv6]- 8008 - Received request: OPTIONS /_matrix/client/r0/sync?filter=10&timeout=30000&since=s1985937_10724101_0_338903_77820_147_29332_808319_0
```

Then I leave a room and create a new conversation and things work for a while.

415 means Unsupported Media Type. I cannot see a reason why suddenly regular text would be unsupported.

(Now, this happens both with SchildiChat and Element, so not a bug limited to SchildiChat.)

### Steps to reproduce

- join room
- use it for a while
- messages can no longer be sent
