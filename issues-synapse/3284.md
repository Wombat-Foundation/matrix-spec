Since synapse 0.30, server notices are available, and require to add a few lines into the configuration file as explained here : https://github.com/matrix-org/synapse/blob/master/docs/server_notices.md

However, the configuration file automatically generated in the Docker image does not yet contain such new lines, as can be seen in the current template: https://github.com/matrix-org/synapse/blob/master/contrib/docker/conf/homeserver.yaml

I would suggest to have a default working `server_notices` section in the template, that could maybe be configured through environment variables, similarly to other options.
