A bunch of mau-related code was introduced in 0.33.3 ish (#3708, #3662, and many others) which runs a bunch of database code during startup without `yield`ing or otherwise managing logcontexts, and hence ends up leaking logcontexts into the reactor and emitting scary-looking warnings in the logs:

```
2018-09-07 11:18:43,101 - synapse.util.logcontext - 431 - WARNING - - Unexpected logging context: main@7fd0fb976c08 is not sentinel
```
