Coming from https://github.com/vector-im/element-web/issues/16931, Synapse effectively pulls a leave event out of thin air when unable to get the federation server to cooperate with leaving the room.

`RoomMemberMasterHandler._generate_local_out_of_band_leave` (in `synapse.handlers.room_member`) is responsible for generating that event, and I think it's code smell. Not just in general for the codebase, but also for implementing the spec; its generating an event locally that's supposed to come from remote.

However, in above element issue, it seems that including an empty object in the `leave` map is enough to make clients believe that it has left the server. The spec says nothing about any key being mandatory, and so this would be valid according to the spec.
