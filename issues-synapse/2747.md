Currently registering a new appservice user gets you an access token for that user, however that's the last time you'll see that token. If the appservice uses that token and it gets lost, the only way to recover it is to do some database queries. The appservice cannot re-register the user (as the user ID is already taken) and it cannot login (currently).

An extension to the login would potentially be to allow appservices to log in with a request very similar to that of registering:

**Registration (current)**:
```
POST /_matrix/client/r0/register?access_token=your_as_token
{
  "username": "_namespaced_user",
  "type": "m.login.application_service"
}
```

**Proposed login request**:
```
POST /_matrix/client/r0/login?access_token=your_as_token
{
  "username": "_namespaced_user",
  "type": "m.login.application_service"
}
```
