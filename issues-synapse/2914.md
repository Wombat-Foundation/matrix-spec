### Description

On a custom Matrix instance deployed to another domain than its Riot, we are receiving CORS errors when trying to add new members via their email address to the channel:

- https://github.com/allmende/docker-matrix/issues/10

### Steps to reproduce

- Open an empty room with riot.allmende.io
- Invite some email address
- receive the error in the browser as
```
Failed to load https://riot.im/_matrix/identity/api/v1/lookup?medium=email&address=almereyda%2Briottest%40allmende.io: No 'Access-Control-Allow-Origin' header is present on the requested resource. Origin 'https://riot.allmende.io' is therefore not allowed access. The response had HTTP status code 504.
```

### Expected response

The home server invites users
