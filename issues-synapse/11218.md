### Description
I am still trying to figure out why FluffyChat cant register users on Matrix.org and now I think the captcha web fallback is broken. Unfortunately there is no working captcha plugin yet in flutter so I rely on the web fallback. At first it seems to work but after the whole registration workflow is done, the server responses with: "500 - Internal server error".

I now have found the difference. The response after solving the captcha in the web fallback and then send
```json
// ...
"auth": {"session": "abcd"}
```

was:

```json
      "stages": [
        "m.login.recaptcha",
        "m.login.terms",
        "m.login.email.identity"
      ]
    }
  ],
  "params": {
    "m.login.recaptcha": {
      "public_key": "6LcgI54UAAAAABGdGmruw6DdOocFpYVdjYBRe4zb"
    },
    "m.login.terms": {
      "policies": {
        "privacy_policy": {
          "version": "1.0",
          "en": {
            "name": "Terms and Conditions",
            "url": "https://matrix-client.matrix.org/_matrix/consent?v=1.0"
          }
        }
      }
    }
  },
  "completed": [
    "m.login.recaptcha"
  ],
  "error": "Captcha response is required",
  "errcode": "M_CAPTCHA_NEEDED"
}
```

So while m.login.recaptcha is in the list of completed stages, I see an error "Captcha response is required". That's why I think there seems to be something broken with the captcha web fallback.
