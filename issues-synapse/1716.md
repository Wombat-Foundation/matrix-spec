If file is uploaded to the chat it becomes available with such url:
https://<domain>/_matrix/media/v1/download/<domain>/<hash>
And it can be downloaded by anybody. Even by unauthorised users. And of course it is not verified that user have access to the chat.
I think it should be considered an error.
