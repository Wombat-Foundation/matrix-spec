**Description:**

In my use case I'm creating a matrix room and store the returned room id into a database. In case something goes wrong while storing the room id into the database – or somewhere else – I'm left with a dangling matrix room.

If synapse would support database-like transactions I could create the room, store the room id and only after successfully storing it, commit the room creation transaction.
