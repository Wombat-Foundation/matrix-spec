There is a whole conversation about how you do this, but as it stands if a host goes over it's MAU limit then the client is sent an alert. However if the host is reconfigured with a higher limit, the clients are not informed and will continue to show a MAU limit banner. I think it would be wise to check the state of an alert in the server notice room on startup, and if MAU < limit, rescind it.
