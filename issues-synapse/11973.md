If the latest event in a thread is edited, the edit is not taken into account when calculating the thread summary.

This would happen if you have:

1. A root event (`A`).
2. A threaded event (`B`).
3. An edit to `B` (`C`).

The summary shows `B` as the latest event instead of `C`.
