### Description

I discovered this bug while implementing a room join feature for this Matrix admin CLI: https://github.com/JOJ0/synadm/pull/32.
While room id works for joining a user into a room, room alias fails. Probably because `#` is a special character.

### Steps to reproduce

- curl -d '{"user_id": "@user:domain"}'  -H 'Content-Type: application/json' -X POST 'https://matrix.domain/_synapse/admin/v1/join/#testing:domain?access_token=token'
- Got `{"errcode":"M_MISSING_TOKEN","error":"Missing access token"}`
