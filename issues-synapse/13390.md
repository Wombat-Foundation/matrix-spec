### Description

By only mistyping “confirm password” once, a user ID is taken despite an error return “Password do not match”.

After restarting a server it returned an error “Error during initialisation: database is locked”
Second start, “started synapse.app.homeserver”
The user ID with the mismatched password returns,
“Sending registration request...
ERROR! Received 400 Bad Request
User ID already taken.”

Is there a way to delete such a user-ID to reuse it again?

register_new_matrix_user -c homeserver.yaml

Password "Right"
Confirm Password "Wrong"

synctl restart

Error during initialisation:
database is locked
