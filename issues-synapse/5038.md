When we try and open a bunch of TLS connections we spend a lot of time in [`twisted.internet._sslverify.py:selectCiphers:1799`](https://github.com/twisted/twisted/blob/twisted-18.9.0/src/twisted/internet/_sslverify.py#L1800), which can really kill performance if we need to start talking to a lot of servers at once (e.g. for presence). My instinct is that this shouldn't be half as expensive as it is.
