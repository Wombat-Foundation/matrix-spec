### Description

```
500: {"errcode":"M_UNKNOWN","error":"Internal server error"}
Couldn't find room.
```

This was the response returned when I tried to run `GetUserProfile.py` from `Matrix Client-server SDK for Python 2 and 3`

Then I checked the server logs in that, I found that my home server was not correctly set up, it throwing `DNS Lookup failed`. But, also, in the `synapse/handlers/profile.py` file, in function `get_avatar_url()`, the result was throwing the error:

```
File "synapse/handlers/profile.py", line 178, in get_avatar_url
    defer.returnValue(result["avatar_url"])
exceptions.UnboundLocalError: local variable 'result' referenced before assignment
```
And that is expected too. As the query failed, the control passed over to `except` leaving the value of `result` uninitialized.
