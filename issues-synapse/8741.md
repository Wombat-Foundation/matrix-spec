## Description

Hello I am trying to setup a local development environment with matrix synapse and keycloak as OIDC through Docker. The OIDC setup is giving me some trouble. 

> Error sending request to  GET https://keycloak:8443/auth/realms/awesome/.well-known/openid-configuration: RequestTimedOutError 504: Timeout waiting for response from remote server

Any idea what might be causing the timeout?

All 3 services (**reverse proxy**, **keycloak** and **synapse**) are running in isolation and i use an external network to make them communicate . Both keylcoak and synapse are also running through https with self signed certs. Executing curl `https://keycloak.local/auth/realms/awesome/.well-known/openid-configuration` from the host or the synapse container with OIDC disabled returns the configuration as expected.

Initially I was also getting an SSL issue which I am assuming has been fixed by recent changes to the synapse docker image?

I have tried using [mkcert](https://github.com/FiloSottile/mkcert) to generate the certificates on my own as well as out of the box custom DNS servers like [traefik.me](https://traefik.me/) to avoid messing up with /etc/hosts.

The problem arises the moment I enable OIDC support in the synapse homeserver.yaml file but I am not sure if it is a synapse issue or a docker networking setup issue that is causing the errors.
