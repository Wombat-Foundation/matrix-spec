### Description
This issue prevents iOS devices from receiving push notifications.

<!-- Describe here the problem that you are experiencing -->

### Steps to reproduce
1. Add an environment variable "HTTP_PROXY" to the Synapse container, and fill in the proxy address;
![{A6BEC8A6-4B0D-637C-131C-43F49FD93106}](https://user-images.githubusercontent.com/48104960/154784607-bf32e4e3-fc74-4358-b18c-614d937befcd.png)

2. Restart the Synapse container;
3. Execute the command using the container's shell: `curl https://matrix.org/_matrix/federation/v1/version`
4. Since matrix.org is blocked in my region, curl will output an error at this point;
![{9D0B216B-D6EE-1019-9E60-991DF76E6BFD}](https://user-images.githubusercontent.com/48104960/154784615-e430ee3b-8f19-45da-96c3-13585e250baf.png)

5. To confirm that it is not a proxy server problem, execute the command again using the container's shell, but this time with additional parameters to use the proxy server: `curl --proxy http://127.0.0.1:8081 https://matrix.org/_matrix/federation/v1/version`;
6. At this point curl will output a JSON, indicating that the connection is successful.
![{DF349407-E7CD-FA8C-79F7-235973219477}](https://user-images.githubusercontent.com/48104960/154784623-7f0e9ece-371d-4337-ad42-a2e9d3718db6.png)
