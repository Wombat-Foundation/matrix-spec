I'm not sure if this was already considered, but maybe it would help to speed up things in synapse by implementing performance intensive parts in [Cython](https://cython.org/) code, which integrates seamlessly in the overall Python codebase.

(Something that may also be worth considering if not already done is to use [asyncpg](https://github.com/MagicStack/asyncpg), which basically is a Cython wrapper for the Postgres C API).
