```
⟩ curl -XDELETE "https://matrix.raim.ist/_matrix/client/r0/directory/room/#test5555:raim.ist?access_token=wrong_token"
{
    "errcode": "M_MISSING_TOKEN",
    "error": "Missing access token."
}
```

Should be:
```
{
    "errcode": "M_UNKNOWN_TOKEN",
    "error": "Invalid macaroon passed."
}
```

----------

```
curl -XDELETE "https://matrix.raim.ist/_matrix/client/r0/directory/room/#test5555:raim.ist?access_token=correct_token
```

gives you the error

```
{
    "errcode": "M_MISSING_TOKEN",
    "error": "Missing access token."
}
```
when it is actually complaining about `#` not being `%23`.
