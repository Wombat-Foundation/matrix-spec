When registering with an existing Gitlab/Github/Facebook/Google/Apple account, it seems like it is not possible to do any of the following:

- Log in normally with email or username
- Reset password

This makes sense, because both of these things are done via the existing Gitlab/Github/Facebook/Google/Apple account.  But it should then be possible to kind of "switch" to logging in "normally" with email or username and a password, and disassociate/unlink the Gitlab/Github/Facebook/Google/Apple account.

Or is there already a way to do this via the API?

It is true that there is the possibility to register a new account "normally", and do an account transfer, but this way, one doesn't keep ones username.
