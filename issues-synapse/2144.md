It would be nice to be able to delete all media after X instead of just before X. An extension to this would be all media between X and Y. Currently the documentation claims to only accept before X.

Extending this same request to the history purge API would be appreciated, although slightly less useful.

An example case where this would be useful is when a remote server has intentionally removed some media due to whatever circumstances, and as an administrator you'd like to remove that media from your server as well. You may not know all of the affected MXC URLs, but may have an estimated timespan for which you can selectively delete media from all sources.
