A default installation of synapse (in my case my RPI), the twisted version is disclosed in the header. In a proper enterprise environment, this would be flagged as a security incident due information disclosure. Though everyone should be on the latest version, some will not do it, or will not be able to patch. When a zero day comes by, this is of the upmost importance that automated scanners will not be able to determine the version on the header.

See [this](https://stackoverflow.com/questions/20304287/remove-rewrite-http-header-server-twistedweb) on how it possibly could be solved
