Hello,
in homeserver.yaml you can change the setting for user_directory to search all users on the server.

When activating this you will see **all the users** who have any "connection" to this server.
One can activate the setting to prefer local users.

But it would be nice to activate the search for local users only.

On an private server the users would find each other but not all the others with whom someone communicates too.
Thank you very much.
