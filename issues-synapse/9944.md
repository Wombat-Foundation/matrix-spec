In the process of splitting the Account Validity feature into its [own module](https://github.com/matrix-org/synapse-email-account-validity/) we've run up against a roadblock: we don't have a well-defined path for people to add extension modules to our Docker images.

We need to survey prior art, pick a solution, and then implement and document it.
