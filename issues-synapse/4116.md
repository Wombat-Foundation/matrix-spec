Currently we use `executemany` to insert multiple rows to the DB, but `psycopg2` simply calls `execute` in a loop. This is annoying as when trying to insert hundreds or thousands of rows the RTT to the database can really slow things down.

We should consider manually batching up inserts, as a single insert statement can insert multiple rows.
