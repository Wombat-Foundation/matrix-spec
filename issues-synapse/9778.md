Synapse currently only supports the ACMEv1 protocol, which has been deprecated by Let's Encrypt (the usual place one gets certs via ACME) [since 2020](https://community.letsencrypt.org/t/acme-v2-scheduled-deprecation-of-unauthenticated-resource-gets/74380). ACMEv2 is now required to request new certs and renew existing ones.

The library we use for ACME support, [txacme](https://github.com/twisted/txacme/issues/151), had implemented some promising work to support v2, but it is currently unfinished.

Advertising ACME support in Synapse currently is confusing to users. We should remove it for now (and potentially re-add it again in the future if a suitable ACMEv2 library surfaces).
