Use case: I have a conference bot that wants to create literally thousands of rooms as fast as possible. Currently the `rc_message` limit can be overridden, which is great, but the lack of rate limit is not given to the function which creates the membership event, thus rate limiting `/createRoom`.

It would be great to have an option in the rate limit override table to exclude users from *all* rate limits, including `rc_message` and `rc_joins` in particular.
