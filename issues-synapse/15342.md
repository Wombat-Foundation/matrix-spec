### Description

Upgrade Synapse to v 1.80 using PIP leads to a broken installation. 

### Steps to reproduce

Have a previous version of Synapse installed like 1.79 using virtualenv and pip. Try and upgrade using normal PIP. 

Try running Synapse after upgrade and see following error. 

```
./bin/synctl --no-daemonize start" (uid: 5084 gid: 5084)
```

Several different personal homeservers. The upgrade fails consistently. 

### Synapse Version

1.79 upgraded to 1.80

### Installation Method

pip (from PyPI)

OS: Freebsd 13.1

Initial installation
python3.11 -m venv /home/synapse
source /home/synapse/bin/activate
pip install "matrix-synapse[postgres]"

Typical upgrade
/home/synapse/bin/pip install --upgrade "matrix-synapse[postgres]"
