### Description

<!-- Describe here the problem that you are experiencing -->
Unable to send larger files when connecting through the system proxy in Windows. 

When using Element on Windows, and connecting through the system proxy, the status bar for uploading a file does not work, and the file fails to send.

If connecting without a proxy the progress bar works, and the file sends.

### Steps to reproduce

- Element on Windows
- Connect to a homeserver using the system proxy
- In a room upload a file less than the max file size
