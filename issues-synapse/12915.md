Hello, I was asked to move to ask here, since seem to be related to the server, not the UI. Originally opened at https://github.com/vector-im/element-web/issues/22388.

### Steps to reproduce

1. Be administrator in a room with IRC bridge (room v6)
2. An OP from IRC set the room as 'voice only'
3. See no membership changes in the log on both desktop and mobile (but membership changes appear for a matrix user on another server), but permissions actually changed.

### Outcome

#### What did you expect?

Membership changes for all users in the room visible in the room log

#### What happened instead?

Nothing. No messages at all about membership changes. Note that manual membership changes for single users appear in the log as expected.

### Homeserver

synapse 1.59.1
