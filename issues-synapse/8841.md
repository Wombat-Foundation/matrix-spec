@t3chguy was experiencing abnormally high load on his Synapse and postgres instances today. Lots of queries similar to:

```sql
WITH RECURSIVE state(state_group)
AS ( VALUES(658151::bigint)
  UNION ALL
  SELECT prev_state_group FROM state_group_edges e, state s
  WHERE s.state_group = e.state_group
) SELECT DISTINCT ON (type, state_key) type, state_key, event_id FROM state_groups_state WHERE state_group IN (
  SELECT state_group FROM state
) AND (
  (type = 'm.room.history_visibility' AND state_key = '') OR (type = 'm.room.member' AND state_key = '@x:riot.ovh')
) ORDER BY type, state_key, state_group DESC;
```

From what I can see, this is called by the `state_group_state_deduplication` background job - but also by just regular state resolution. Which makes tracking down the root of this issue quite tricky.
