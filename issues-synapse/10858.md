I was unable to find the proper way of requesting the last message from a particular room. I have tried using a filtered sync request. This approach kind of works but cannot return the last message event after several join room->sync request->leave room steps. It seems that the last message event goes out of the scope of the sync search request.  
I was looking at this from an IoT standpoint in which a specific variable would be associated with a room. From there, any number of clients could join and request or subscribe to the particular variable.
Is there another way of achieving this outcome? because it seems that something like this would be a nice feature to have.
