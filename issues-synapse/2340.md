There is currently no link between an uploaded file and the room where it has been uploaded.

So in theory, everybody have access to all uploaded files (if they are able to guess the random path) and it may be a privacy issue.

And if we want to be able to safely delete uploaded files belonging to abandoned room, a link between the uploaded file and the room has to exist somewhere.

Relevant issues: https://github.com/matrix-org/synapse/issues/2339
