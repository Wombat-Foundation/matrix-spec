We built an app service that manages rooms for our users.
This service sets the power level of the members of chat groups.

We have a room with over 2000 persons in it and want to set the power level of each of these persons, so that only a few of them can write and most can only read. In our application the user can configure if a user can read or write.

To achieve that we use the botIntent like this: `botIntent.sendStateEvent(roomId, 'm.room.power_levels', '', eventContent);`
The eventContent contains all users and their power levels.

In this big group we get the following error: `M_TOO_LARGE: event too large`.

[https://github.com/matrix-org/mjolnir/issues/129](Here) i read that there is an limit as of how big an event can be.
So is there no way to set power levels for so many persons in a chat room?
