**Context**
As a hosting provider, I prefer to use the well-known delegation and ask of my customers only a proxy of `<server_name>/.well-known/matrix/*` to `<delegate_name>/.well-known/matrix/*`.

**Description:**
Synapse derives the `m.server` of `.well-known/matrix/server` from server_name which is bad when using delegation.
Wouldn't be better to use public_baseurl instead ?
When not delegating, it uses the server_name anyway :
https://github.com/matrix-org/synapse/blob/c3516e9decc355b75a297d72a13b98a43d312e66/synapse/config/server.py#L280-L288
But maybe there are other scenarios I don't know about.

I'm willing to make a PR if you think it's the way to go :smile:.
