We would like to give synapse support for multiple OIDC identity providers. As a first step:
 * [x] the user would be prompted to choose one from the `/_matrix/client/r0/login/sso/redirect` page
   * [x] give synapse the concept of an "identity provider", and refactor existing CAS, SAML and OIDC impls to match it
   * [x] redirect to an IdP picker when more than one IdP exists
   * [x] serve an IdP picker based on a template
   * [ ] support multiple OIDC providers, each as a separate IdP (#9110)
   * [x] write some tests
 * [x] for UIA, the user would be taken to whichever OIDC provider they had registered with. (#9081)
