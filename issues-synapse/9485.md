With the advent of spaces, it looks like we probably need to rethink how we do room joins/invites. Doing this would probably be fairly tricky, as it'd be hard for a server to discern between legitimate quick-joins (e.g. Spaces' `auto_join` feature), quickly clearing a list of invites with "accept", and spam accounts joining a bunch of rooms to start spamming in them.
