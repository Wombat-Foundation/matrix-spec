### Description

When creating a room via the `/createRoom` endpoint and you try to set an `initial_state` with a non-member event that has the state key of an mxid you get `M_FORBIDDEN`: You are not allowed to set others state.

Example:
```
{
  "invite": ["@alice:matrix.org"],
  "initial_state": [
    {
      "type": "com.example.custom",
      "state_key": "@alice:matrix.org",
      "content": {"blah": "blubb"},
    }
  ]
}
```

### Steps to reproduce

- create a room that contains a default state event with the state key of an mxid


### Version information

- **Homeserver**: matrix.org
