### Description

A few days ago I noticed that Synapse was taking an huge amount of memory on my server, as I started to get “cannot get swap space” messages.

After a restart, it works as expected for a minute or so. Then it becomes unresponsive (Riot says it is disconnected), consuming 100% CPU and growing its memory consumption slowly, minutes after minutes.

At this point, I also see messages like this in my system logs (FreeBSD):

```
May 26 21:08:41 ejpcmac kernel: sonewconn: pcb 0xfffff8000f6d8570: Listen queue overflow: 76 already in queue awaiting acceptance (124 occurrences)
```

I’ve seen #5264 and #5266, which both relates about an issue that seems similar in 0.99.5.1, but it seems to be the case in 0.99.3 too. Maybe it has something to do with some updates in the federation as a whole? My Synapse instance has been operating properly for months (years?).

I’ve run [this](https://github.com/matrix-org/synapse/issues/1760#issuecomment-356270367) to try if it was solving my problem: it is not.

### Steps to reproduce

- start synapse
- see it freezing after a short time
