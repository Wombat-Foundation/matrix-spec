### Description

Background:
The `+discord:t2bot.io` group has 7372 members in it. These members were added using [this](https://github.com/turt2live/matrix-grouper) approach. Members then manually had `is_public` in `group_users` set to false.

The timespan for this event is spread over nearly 12 hours, with only the last 2 hours causing server failure. At the time of writing this, 556,592 requests have failed. This number is only going up.
