### Description

The documentation for how to set up a captcha needs to specify that a V2 key is required, and possibly the type of key (checkbox, android, background thing)

### Steps to reproduce

- Create a v3 captcha key
- New user registration fails horribly with a SITE ERROR in the captcha dialog
- If domain validation is on, SITE ERROR with invalid domain

You must pick a v2 captcha key (possibly with the checkbox, have only specified one with the checkbox setting). You must also turn off domain validation if you wish to use the riot.im web client. Not sure if you can leave it on using your own hosted riot-web.
