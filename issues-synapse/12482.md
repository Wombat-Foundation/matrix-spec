Synapse's response to a `/pushrules` query looks something like:

```json5
[
  "global": {
    "content": { /*... */ },
    "override": { /*... */ },
    "room": { /*... */ },
    "sender": { /*... */ },
    "underride": { /*... */ }
  },
  "device": {}
]
```

This `device` property is not [specced](https://spec.matrix.org/v1.2/client-server-api/#get_matrixclientv3pushrules) and should be removed.
