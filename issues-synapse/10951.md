Defaults to `True`.

https://github.com/matrix-org/synapse/blob/50022cff966a3991fbd8a1e5c98f490d9b335442/tests/rest/client/utils.py#L51

Docstring says:

https://github.com/matrix-org/synapse/blob/50022cff966a3991fbd8a1e5c98f490d9b335442/tests/rest/client/utils.py#L65-L67

But the only use is:

https://github.com/matrix-org/synapse/blob/50022cff966a3991fbd8a1e5c98f490d9b335442/tests/rest/client/utils.py#L80-L81

Moreover, the CS spec [says](https://spec.matrix.org/unstable/client-server-api/#post_matrixclientr0createroom) of `visibility` that

> Rooms default to private visibility if this key is not included.

Suggest:

- Change is_public to `Optional[bool]`, default `None`
- `if is_public is False`, set visibility to private
- `elif is_public is True`, set visibility to public
- else do nothing.

Could alternatively leave it as a bool and fix it to actually set visibility to public when True. That would probably require fixing a bunch of tests to explicitly set `is_public`: False.

Spotted by @AndrewFerr in #10930.
