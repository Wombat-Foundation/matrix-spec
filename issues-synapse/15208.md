**Description:**

I would like to run a server, and be able to advertise our matrix using join links.
However, one concern I have with this is that these links might leak, and trolls might use them to join as well.
Therefore, as an admin I would like to be able to screen users joining using a link, such that we could either approve or deny such join requests.
