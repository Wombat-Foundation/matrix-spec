### Description

If workers are configured according to https://github.com/matrix-org/synapse/blob/develop/docs/workers.md , they emit the following warning in the log:

`WARNING - - Failed to listen on 0.0.0.0, continuing because listening on [::]`

If synctl is used and thus a "worker" for the main process is required, the same warning is issued there, but Synapse is still listening on the configured IPv4 ports on all interfaces. However, there are no listeners on IPv4 ports for the actual workers.

### Steps to reproduce

- Configure workers with the example configuration in https://github.com/matrix-org/synapse/blob/develop/docs/workers.md

### Version information

Synapse 1.22.1 on Debian 10.6

### Solution

Add `bind_addresses: ['127.0.0.1']` or similar for IPv6 to the worker_listeners section of the example configuration.
