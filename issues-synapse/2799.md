### Description

The icons in the riot client for some rooms seemed blurry so I checked the media url and it seems to be returning the wrong size image.

### Steps to reproduce

- Open https://matrix.org/_matrix/media/v1/thumbnail/disroot.org/omImodskspCryApihvRjAtwG?width=48&height=48&method=crop
- See that the requested size is 48x48 but it returns a 32x32 image (the original size is 96x96)

The inverse also happens on this icon:
https://matrix.org/_matrix/media/v1/thumbnail/disroot.org/WaZoGMHggcIsSXmeYWKkgSAz?width=48&height=48&method=crop
that returns an 96x96 image instead.

The issue is on matrix.org
