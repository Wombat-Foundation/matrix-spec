Found another inconsistency between Synapse and the spec while working on ruma-client. Synapse sends events like this:

```json
{
    "content": {
        "currently_active": true,
        "last_active_ago": 66841020,
        "presence": "online"
    },
    "type": "m.presence",
    "sender": "@someuser:matrix.org"
}
```

where the user ID is in the sender field. According to the spec however, this information should be in the `user_id` field inside the events content: https://matrix.org/docs/spec/client_server/r0.2.0.html#m-presence
(both in r0.2.0 and HEAD)
