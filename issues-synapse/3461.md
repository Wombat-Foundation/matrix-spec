This is no bug report, rather a question on which possibilities exist to design and implement a location-based search for users.

My requirement is to be able to have a function with the input (lat,long,radius) returning an array of users with their defined latitude, longitude in order to be able to visualize search results on a gmap.

latitude and longitude may be statically defined already as custom user profile attributes, so I suspect, the heavy lifting part is to do the search by euclidian distance.

So my questions are:
- is this feature already in place (I didn't see it in the spec)?
- are there plans to implement this feature?
- if not, what would be the recommended way to implement this feature?
