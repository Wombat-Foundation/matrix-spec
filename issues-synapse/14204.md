### Description

If we start a password reset via Element and then click on the link in the password reset confirmation email, then a 404 Nginx error is displayed in the browser window.

The link in the email is as follows:
https://chat.slawinski.de/_synapse/client/password_reset/email/submit_token?token=X&client_secret=X&sid=X

The error did not exist in previous Synapse versions.
Since which version the error exists I can not say.

### Steps to reproduce

- Request passwort reset in Element.
- Click on link in reset confirmation email

### Homeserver

chat.slawinski.de

### Synapse Version

1.68

### Installation Method

Debian packages from packages.matrix.org

### Platform

Server: Ubuntu 20.04 LTS
Client: macOS, iOS and Android
