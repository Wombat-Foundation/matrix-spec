### Steps to reproduce

I am not sure how reproducible the following steps are, but here's what I did, in general terms. If you need intense specifics, database queries, etc. ... feel free to ask me. 

- First somehow stop an existing federated server from validating SSL certificates.
- Shutdown this server
- Create a new server in a FreeBSD jail, but hook it to the same postgres database and the same reverse proxy.
- Before you start the server, rsync the media cache from the old area to the new area (I used `rsync -av` to keep it simple)
- Start up the new server.

### Version information

- **Homeserver**: matrix.jetcafe.org

- **Version**: 1.28

- **Install method**:  From FreeBSD ports tree 2021Q1 via poudriere

- **Platform**: FreeBSD 12, using postgres as backend, and nginx as reverse proxy.
