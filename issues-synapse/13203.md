From https://github.com/vector-im/element-web/issues/22728:

> I recently updated my server machine, which changed the postgres server from version 13 to 14. This created a new database which removed my user account. On failing to authenticate, all my element clients logged out. When restoring the postgres v13 database, I had to reauthenticate all my clients. Luckily one was offline for the duration of this disaster, so I could recover the encryption keys without the security key.

I believe changing synapse to use `soft_logout: true` by default in cases where the user doesn't exist would solve this.
