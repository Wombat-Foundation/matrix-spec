# CPU Affinity breaks on FreeBSD

This feature introduced in commit 10d8b701a1fa585c5fc2d5edcea8d4d02ae360a4 does not work on FreeBSD as the python module required only supports Windows and Linux. We will have to patch out this entire feature/commit in order to package/deploy on FreeBSD. Can this somehow be made completely optional or just removed altogether? I feel there are better ways of handling this such as with systemd perhaps and maybe something also exists on Windows? On FreeBSD the easy solution right now would be to run the software in a jail and control the affinity settings of the jail itself.


Thanks for your consideration. Unfortunately all the world is not a Linux.
