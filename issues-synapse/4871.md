### Description

Splitting #4788 into separate issues. ACME certificate request tries to store data in /etc/matrix-synapse/conf.d but the /etc/matrix-synapse/conf.d belongs to root. Everything fails.

### Steps to reproduce


- install matrix-synapse-py3 ver. 0.99.2 on bionic1 with

```
wget -qO - https://matrix.org/packages/debian/repo-key.asc | sudo apt-key add -
sudo add-apt-repository https://matrix.org/packages/debian/
sudo apt install matrix-synapse-py3 -y
```

- add an acme section
