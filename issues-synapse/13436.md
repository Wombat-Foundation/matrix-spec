From the source code, it doesn't look this should be possible in the logic which inserts rows to this table, unless a) Synapse's in-memory caches are out of date, or b) the current state events table has changed beneath us.

However: the recently removed weird corner (#12943) was known to create dodgy state groups and I can't help but wonder if that was the cause.

At the time of writing, stream ID 3117777850 was the last time we saw this on matrix.org.
