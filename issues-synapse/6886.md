**Description:**

[The spec says](https://matrix.org/docs/spec/client_server/r0.6.0#id150) "Users may encounter content which they find inappropriate and should be able to report it to the server administrators **or room moderators for review**." but Synapse doesn't currently expose reported messages to room moderators as far as I know. I would be great if you could report a message and have the room moderators act on it without having to ping individual moderators.

Related to https://github.com/matrix-org/synapse/issues/4007 - event reports get lost in a database table
