The `sent` column is strict BOOL and must be passed a `TRUE` or `FALSE` value, not `1` or `0` as before.

```
    ...x.se', 39, '@user:home-server.se', 'DEVICE-ID', 1, 5125125...
```

Where the `1` should be a `TRUE` (seeing as SQLite3 uses 1 or 0 for BOOLS, these need to be type-converted).
