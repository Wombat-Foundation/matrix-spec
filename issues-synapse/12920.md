### Description

Me and other users on my homeservers are unable to log in on certain clients. This happens on freshly created accounts as well. Existing logins still work, but if I log out, logging in is no longer possible:
- Element desktop 1.10.12: stuck on infinite sync; upon restarting it says "unable to connect to homeserver. retrying"
- Element web 1.10.13 and 1.10.10: same as above
- [Fluffychat 1.4.0 web](https://fluffychat.im/web): "No connection to the server"
- Fluffychat 1.4.0 on Android: able to log in normally
- [Moment](https://mx-moment.xyz) (using matrix-nio): able to log in normally
- Fractal on Ubuntu: able to log in normally
- NeoChat on Ubuntu: able to log in normally

SIMILAR ISSUE: #12882
