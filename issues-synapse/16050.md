### Description

We've had a report of Element iOS crashing when opening rooms that are v11 (https://github.com/vector-im/element-ios/issues/7633). I've tracked this down to the room's `m.room.create` event missing the `creator` string. The [spec](https://spec.matrix.org/v1.7/client-server-api/#mroomcreate) seems to indicate that this is a required property.

### Steps to reproduce

- Open an existing room (not v11) in Element Web.
- Send `/upgrade 11` into to the room to upgrade it.
- Open the devtools and inspect the `m.room.create` event.
- Notice the required `creator` field isn't present.
