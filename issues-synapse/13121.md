### Description

Since a few weeks, it takes from 15s to 30s to send messages on large channels like #nix:nixos.org. Each time a message is sent, the matrix synapse process pikes at 100% CPU for all this time. If file this issue mostly because synapse being cpu-bound instead of postgresql-io-bound looks abnormal to me, especially as I am the only user of this home-server.

Here is a flamegraph with pyspy, but it does not look that revealing.

![flamegraph](https://user-images.githubusercontent.com/12595971/176009345-74ca2304-9bef-405d-a48d-220d4385f4ba.svg)


### Steps to reproduce

- send a message on #nix:nixos.org
- see that the message takes more than 15s to be accepted (single tick in element or nheko)
