Suppose Alice is the only user in a room on her server.

She decides to leave that room, and creates a leave event, which refers to whatever the current backwards extremities are. That event gets sent out over federation.

A recipient server happens not to have one of those backwards extremities, so asks Alice's server for it via `get_missing_events`. However, Alice's server now believes that there are *no* servers in the room, so responds with a 403 [here](https://github.com/matrix-org/synapse/blob/v1.58.0rc2/synapse/handlers/federation.py#L1125).

The recipient server therefore ignores the leave event:
