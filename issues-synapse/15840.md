**Description:**

I'm using [Ky](https://github.com/sindresorhus/ky#retry) to make calls to the Matrix API. Whenever I receive a `rate-limited` error with status code `429` I'm forced to parse the body of the error in order to retrieve the value for `retry_after_ms` before doing the next request.

Ky has a built in retry mechanism and honors the http header [Retry-After](https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/Retry-After) that represents either an absolute date/time or a delay in seconds.

Can you please add the appropriate http header to 429 errors? I'm using Synapse v1.82 in a dockerized setup.

Thanks,
Thomas
