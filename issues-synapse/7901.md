It would be great to have an option that allows synapse admins joining all remote rooms, independent of their complexity.

A non-admin user can ask an admin to join a specific, too complex room. After that the non-admin user can join the room (since it is local now). The admin may leave the room again.

It has the advantage that server admins always have an overview over large rooms.
