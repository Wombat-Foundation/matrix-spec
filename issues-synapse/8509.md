### Description

Users cannot use the "Reset cross-signing and secret storage" feature when using SSO auth.

### Steps to reproduce

- Log in with SSO
- Go to your security & privacy settings
- Click the "Reset cross-signing and secret storage" button
- Go through the process, you'll get an error message

The problem comes from /_matrix/client/unstable/keys/device_signing/upload which returns a 401 (because it lacks SSO information).

### Version information

- **Homeserver**: matrix.asso-pea.ch
- **Version**: 1.20.1
- **Install method**: pip
- **Platform**: Debian Buster
