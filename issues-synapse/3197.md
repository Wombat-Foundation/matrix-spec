As part of the work on [GDPR compliance](https://github.com/vector-im/riot-meta/issues/149), we need support for gathering users' consent before they can use the platform.

Steps here will include:
* [x] Add a column to the `users` table recording consent (done in #3213)
* [x] Add support for serving up a (templated, configurable) consent page. Users will get personalised links so that we know who is giving consent without them having to log in. (done in #3213)
* [x] Wire up the consent page to record consent in the db. (done in #3213)
* [x] Create an AS-like service which opens a DM with new users after they register, and sends them the link to their consent page. This will also be useful for finally fixing https://github.com/matrix-org/synapse/issues/1199 aka SYN-1. (#3236)
* [ ] Scripts to trawl the existing user list and send them their links via:
  * ~~DM via the server bot~~ (done via #3236)
  * [ ] email (if we have their address)
  * [ ] push
* [x] The (configurable) ability to block usage of the server until the user has consented. (#3257) "Usage" includes:
  * [x] Creating rooms
  * [x] Joining rooms
  * [x] Sending events
  

Extensions:
* [ ] i18n support for consent page
* [ ] A front-end page which gathers login creds from a user and directs them to their personalised consent page, so that we can post the link in public.
