At present, the venv for the Debian/Ubuntu matrix-synapse-py3 package does not include the [synapse-s3-storage-provider](https://github.com/matrix-org/synapse-s3-storage-provider) in its site packages. It's possible to just activate the environment and install it manually, but I would like to see it packaged in future builds like some other optional dependencies are.
