### Description

Synapse is run via Docker. There is an existing homeserver.yaml file which is mounted into the container. The path is specified via `SYNAPSE_CONFIG_PATH`. 

Every time i change the homeserver.yaml and re-upload it via ansible and restart the container via ansible, i get an error: `Environment variable SYNAPSE_SERVER_NAME is mandatory`
It doesnt matter if i set `SYNAPSE_SERVER_NAME` explicitly via docker env, it has still the same error. Of course, the homeserver.yaml has a `server_name` setting.

Only solution is to delete the container and recreate it. 

### Steps to reproduce

- Install synapse via Docker, a homeserver.yaml file mounted in the Container, and `SYNAPSE_CONFIG_PATH` set. 
- When everything is running, upload a new homeserver.yaml file to the docker host
- Restart the container so that it picks up the new homeserver.yaml
