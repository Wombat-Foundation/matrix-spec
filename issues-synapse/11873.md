Related: https://github.com/matrix-org/matrix-doc/pull/3688

Synapse will check integer values in JSON by its canonical JSON max, but it won't do the same for powerlevels encoded in strings, these are allowed to become as big as they can (as synapse implicitly parses to bigint when doing `int()`)

I believe the ecosystem impact is minimal enough to add a simply canonical JSON integer check on this when encountering such an event, as the only rooms that would have done this are rooms that deliberately tried to stretch the limits of matrix, and no real user rooms.
