Currently, the default value for the `notif_from` config parameter looks like this (see [emailconfig.py line 114](https://github.com/matrix-org/synapse/blob/master/synapse/config/emailconfig.py#L114)):

       notif_from: "Your Friendly %(app)s Home Server <noreply@example.com>"

I propose to add a comment right above it:

    # %(app)s is replaced with the application's name. To avoid parsing errors, either keep it 
    # in place, or delete it completely. Docs: https://pyformat.info/#named_placeholders

This would prevent people not familiar with such a Python string formatter (like me …) from mistakes that result in failing e-mail notifications and long debugging :-) For example, setting the option to `"Company Name %(app) <contact@example.com>"` caused this in the log, not precisely helpful to find the error:
