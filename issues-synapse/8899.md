I *think* [Using a reverse proxy with Synapse](https://github.com/matrix-org/synapse/blob/master/docs/reverse_proxy.md) uses the deprecated Admin API endpoint, for example for nginx:

`location ~* ^(\/_matrix|\/_synapse\/client) {`

instead of

`location ~* ^(\/_matrix|\/_synapse\/admin) {`

see: https://github.com/matrix-org/synapse/blob/develop/UPGRADE.rst#removal-historical-synapse-admin-api
