Synapse supports exporting data about a user for administration purposes. Part of that exported data are the memberships of a user in various rooms.

Currently, this only covers `join`, `leave`, `ban` and `invite` memberships. `knock` ([MSC2403](https://github.com/matrix-org/matrix-doc/pull/2403)) membership data is not currently supported:

https://github.com/matrix-org/synapse/blob/eb9ddc8c2e807e691fd1820f88f7c0bf43822661/synapse/handlers/admin.py#L85-L94

Note that this was one of the TODO's on the original [knock implementation PR](https://github.com/matrix-org/synapse/pull/6739).
