synapse: v1.21.2

In a scenario where users only use web clients, the E2EE does not fully work.

Decrypting messages in conversations only works if the recipients are online while the sender is sending the encrypted messages. If the receiver is offline while the sender is sending a message, the error below will be displayed:

`logger.js:50 Error in DecryptionError[msg: The sender's device did not send us the keys for this message, session:`

Meaning, the message could not be decrypted.

In the case of the Element Web Client, a user can request the key, but in a scenario where users use only Web clients that do not permanently store the key "locally", this message can never be read. Moreover, the sender does not know that his message could not be read by the recipients.

This is a user experience that is unacceptable to users especially in scenarios where these messages are critical. And you cannot force them to use mobile clients just to get it working. 

Are there any shortterm plans to fix this issue?
