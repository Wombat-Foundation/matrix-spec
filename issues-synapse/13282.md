The latest version of frozendict, 2.3.2, has a memory leak in `__repr__` which gets triggered during `/sync` when opentracing is enabled.

To demonstrate:
```py
d = {"asdsd": "dklfj"}
while True:
    _ = repr(frozendict(d))
```
