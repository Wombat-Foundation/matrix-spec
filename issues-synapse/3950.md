I name here "not federated" room, a room which has been created with the creation_content: {m.federate: false}. This option blocks users on other matrix homeservers from joining this room.

The `publicRooms` API should not return the not-federated rooms when the selected server is not the user's homeserver.  

It should also not return rooms which require an invite.
