- set ```DEFAULT_VERSIONS+= ssl=openssl``` in ```/etc/make.conf```
- install packages

  - openssl

  - py36-virtualenv

run the following commands as root to install synapse:

```
pw groupadd synapse
pw useradd synapse -m -g synapse
```
