Synapse Version: 1.83.0
OS: Debian 11 5.10.0-22-amd64

I just setup the structured log formatting sending logs remotely to Graylog using the "synapse.logging.TerseJsonFormatter" following the config provided in https://matrix-org.github.io/synapse/develop/structured_logging.html
Unfortunately, none of the synapse.access.http logs are in JSON format. 

I think it would be extremely useful to have these HTTP logs put in JSON format to make it easier to parse the logs.

Current Log format:
```
May 17 10:47:28 chat matrix-synapse[147051]: INFO:synapse.access.https.8443:192.168.99.99 - 8443 - {@user:chat.domain.com} Processed request: 0.002sec/0.000sec (0.001sec, 0.000sec) (0.000sec/0.001sec/2) 469B 200 "GET /_matrix/client/r0/devices HTTP/1.0" "Element/1.5.32 (Google Pixel 5; Android 13; TQ2A.230505.002.2023050500; Flavour GooglePlay; MatrixAndroidSdk2 1.5.32)" [0 dbevts]
```

Example JSON format:
```
{"LogLevel":"INFO","Log":"synapse.access.https.8443","ClientIP":"192.168.99.99","Username":"@user","UserDomain":"chat.domain.com","RequestProcessTime1":0.002,"RequestProcessTime2":0.001,"RequestProcessTime2":0.000,"RequestLength":469,"ResponseCode":200,"FullRequest":"GET /_matrix/client/r0/devices HTTP/1.0","UserAgent":"Element/1.5.32 (Google Pixel 5; Android 13; TQ2A.230505.002.2023050500; Flavour GooglePlay; MatrixAndroidSdk2 1.5.32)"}
```
