### Description

<!-- Describe here the problem that you are experiencing -->
In order to disable federation on `server_a` and only allow users from `server_b` , I have set `federation_domain_whitelist` on `server_a` homeserver.yaml to `server_b` like so:
```
federation_domain_whitelist:
 - server_b
```
However when a `@user_a:server_a` invites user `@user_b:server_b` into a room, `@user_b:server_b` gets "Failed to join room. You are not invited to this room", and synapse logs on `server_a` reports `SynapseError: 403 - You are not invited to this room`. 
### Steps to reproduce


- on `homeserver.yaml` for `server_a`, whitelist `server_b` using `federation_domain_whitelist`
- create a room on `server_a` and invite `@user_b:server_b`
- try to join the `!room:server_a` using `@user_b:server_b`
