### Description

After starting synapse, the configured `pid_file` (e.g. `/var/run/matrix-synapse.pid`) is not created.

### Steps to reproduce

1. start synapse: `su -s /bin/bash -c "/usr/bin/python3 -m synapse.app.homeserver --config-path /etc/matrix-synapse/homeserver.yaml --config-path /etc/matrix-synapse/conf.d/" matrix-synapse`
2. look up the location of the configured PID file: `grep -r pid_file /etc/matrix-synapse`
3. verify that the PID file does not exist

The documentation of the `pid_file` indicates, that it should be created, when *matrix-synapse* is started as a daemon. Since there is no specific *daemonize* argument, I assume, that this startup mode is the default.

### Version information

1.24.0

- **Platform**:

Debian (buster-backports)
