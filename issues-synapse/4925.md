### Description
Following [#4919](https://github.com/matrix-org/synapse/issues/4919)
Now the invitation works correctly if the user exists.
There is an exception in Synapse when the user does not exist in Matrix world.
The invitation mail is sent, but the error is shown in Riot: `Unknown server error.`

As I understand, Synapse got a 500 status code, but there is no information in exception code about the source of the error (My ID server? Vector ID server?...)
There is no exception in `mxisd`.

### Steps to reproduce

- Install my own home server
- Configure my own ID server (mxisd)
- Configure and test federation
- Invite a non existing user using his e-mail address into a room or into a private chat.

### Version information

Synapse 0.34.1.1 (last available in ports tree)
Installed on FreeBSD from package (official repository).

Riot 1.0.1
Mxisd 1.3.1

Domain bimp.fr
Server chat.bimp.fr
