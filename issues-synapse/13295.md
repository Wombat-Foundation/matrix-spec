When handling a `/pushers/set` request, Synapse removes any matching pushers belonging to a _different_ user, then calls `PusherPool.add_pusher`:
https://github.com/matrix-org/synapse/blob/fe1daad67237c2154a3d8d8cdf6c603f0d33682e/synapse/rest/client/pusher.py#L106-L125

`PusherPool.add_pusher` eventually creates a new pusher to replace the existing one:
https://github.com/matrix-org/synapse/blob/e24ff8ebe3d4119d377355402245947f7de61c00/synapse/push/pusherpool.py#L354-L359

Critically, it increments the `synapse_pushers` metric, regardless of whether it replaced an existing pusher, so stopped pushers can be included in the count.
