### Description

Login API `https://matrix-client.matrix.org/_matrix/client/v3/login` presents login via `m.login.application_service` also if no [`app_service_config_files`](https://matrix-org.github.io/synapse/latest/usage/configuration/config_documentation.html#app_service_config_files) is configured.

### Steps to reproduce

- setup a new homeserver
- request `/_matrix/client/v3/login`

```json
{
   "flows":[
      {
         "type":"m.login.password"
      },
      {
         "type":"m.login.application_service"
      }
   ]
}
```
