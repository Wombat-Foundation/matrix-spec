### Description

lib libjemalloc2 isn't available through the [matrix-docker-ansible-deploy](https://github.com/spantaleev/matrix-docker-ansible-deploy) playbook, while it should (it's also written [here](https://github.com/matrix-org/synapse/blob/develop/docker/README.md#using-jemalloc) )


### Steps to reproduce

To Reproduce
- start the ansible-playbook and from a shell prompt do the following:

- `# lsof -n |grep jemalloc`

result on my box is a lot of python processes, that look like this:

```
python    277213                      matrix  mem       REG                8,1                33432 /usr/lib/x86_64-linux-gnu/libjemalloc.so.2 (stat: No such file or directory)'
```

you get "no such file or directory".

Expected behavior

- After installing libjemalloc2 on my Debian 11 via apt, I'm getting the following result:

```
python    378640                      matrix  mem       REG                8,1                33432 /usr/lib/x86_64-linux-gnu/libjemalloc.so.2 (path i node=8628)
```

which should be correct; but the "ansible-playbook" maintainer said this is an upstream bug, so I'm posting here.
