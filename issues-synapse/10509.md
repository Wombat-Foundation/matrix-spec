I've been hosting my server on a Raspberry Pi running a 32-bit OS. I've tried to migrate my Postgres Synapse setup to an x86_64 machine, but when I start the Postgres server I get the following:

```
chmod: changing permissions of '/var/run/postgresql': Operation not permitted

PostgreSQL Database directory appears to contain a database; Skipping initialization

2021-08-01 21:12:56.897 UTC [1] FATAL:  database files are incompatible with server
2021-08-01 21:12:56.897 UTC [1] DETAIL:  The database cluster was initialized without USE_FLOAT8_BYVAL but the server was compiled with USE_FLOAT8_BYVAL.
2021-08-01 21:12:56.897 UTC [1] HINT:  It looks like you need to recompile or initdb.
2021-08-01 21:12:56.898 UTC [1] LOG:  database system is shut down
ERROR: 1
```

The internet tells me this means a database initialized on my 32-bit Pi can't be used on my x86_64 cloud machine. This means I'm forever locked into a 32-bit architecture for my homeserver, unless there's some way to migrate the database that I don't know about. Here are some ideas:

- a script like `synapse_port_db` for migrating the database to a new architecture, where instead of `--sqlite-database SQLITE_DATABASE` you have `--source-database POSTGRES_URL`
- a script to dump a postgres DB to sqlite so that I can copy that file over and then run `synapse_port_db` to recreate the postgres DB on the new architecture
