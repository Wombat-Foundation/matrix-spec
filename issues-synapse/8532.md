Note: I already filed this issue in the matrix-js-sdk repo (here: https://github.com/matrix-org/matrix-js-sdk/issues/1505) because the SDK throws an exception and stops working correctly. @jryans suggested to further discuss this issue Synapse related.


Background:

I am trying to bootstrap cross-signing along with a 3pid login using a password provider, see below JS snippet:

```
    const _doBootstrapAuth = async (makeRequest) => {
        await makeRequest({
            type: 'm.login.password',
            identifier: {
                type: 'm.id.thirdparty',
                medium: 'email',
                address: userMail,
            },
            password: userPwd,
        });
    };

    try {
        await Client.get().bootstrapCrossSigning({
            authUploadDeviceSigningKeys: _doBootstrapAuth,
            setupNewCrossSigning: forceReset,
        });
    } catch (e) {
        console.error('Error bootstrapping cross-signing', e);
    }
```

The `authedRequest` looks fine, sending the auth dict with the 3 cross-signing keys. The user is authenticated successfully and the password provider returns the `user_id` upon authentication.

However, the following errors are shown in ...

-1- console
```
POST http://localhost:8008/_matrix/client/unstable/keys/device_signing/upload 400 (Bad Request)
crypt.js:400 Error bootstrapping cross-signing M_MISSING_PARAM: Unknown message
    at parseErrorResponse ...
    at Object.callback ...
    at on_end ...
    at XMLHttpRequest.on_state_change ...
```

-2- homeserver.log
```
2020-10-12 07:46:47,277 - synapse.http.server - 76 - INFO - POST-112 - <XForwardedForRequest at 0x7f5dda580b70 method='POST' uri='/_matrix/client/unstable/keys/device_signing/upload' clientproto='HTTP/1.1' site=8008> SynapseError: 400 -

```


I guess that Synapse returns a different response when the authentication is done through a password provider. In this case Synapse seems to miss merging a parameter into the response of the `authedRequest` that is obviously needed/expected in the matrix-js-sdk.
