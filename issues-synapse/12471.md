### Description

We use the a antispam module to determine if a user is a student or a teacher and decide on this base if the user can invite a another user to a room ( all this to prevent 1:1 messages between students --> its a education environment ) . 
Because a student who wants to chat with another student only gets a message like " we are unable to create your room" i want to send them a message like  (Server Notification) " You have no permissions to invite other students!" I tried it the following way:

With the help of #synapse:matrix.org channel i ended up using the ModuleApi http_client to send the notification, this worked exactly 1 time. In all other cases i get the message `synapse-server   | 2022-04-13 12:17:42,926 - synapse.http.server - 95 - INFO - POST-33 - <XForwardedForRequest at 0x7f95730cdd30 method='POST' uri='/_synapse/admin/v1/send_server_notice' clientproto='HTTP/1.1' site='8008'> SynapseError: 401 - Too many Authorization headers.` with a following `401: Unauthorized`.

If i not submit a header with authorization token i get the exspected "401: Unauthorized" and the message `Too many Authorization headers` is gone.

I think there is something wrong in check from http_client if there are more than once auth headers.
