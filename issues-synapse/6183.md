Dear team,

according to the newest release notes (1.4.0) Matrix Synapse will not use any third party identity server unless you enable it again.
Also the current public identity servers (vector.im & matrix.im) will no longer allow to use them in December.

That's fine but on the other side the FAQ says:

> Yes - the reference implementation issydent and you can run your own ID server cluster that tracks 3rd party to Matrix ID mappings. This won't be very useful right now, though, and we don't recommend it.

So what should we do?
I run my own hosted Matrix Synapse server and currently I know that the 3rd party service I am using won't be supported in the near future but there is also no current solution.
