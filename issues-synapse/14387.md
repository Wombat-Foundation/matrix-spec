The [Make room admin](https://github.com/matrix-org/synapse/blob/develop/docs/admin_api/rooms.md#make-room-admin-api) API allows a server admin to grant another user in the room the highest power level in that room. It seems to do this by high-jacking one of the user with the highest power level in the room, and use them to set the power level.

This will fail if the high-jacked user does not have the permission to change power level (for example in a room with no Admins). If it is somehow possible, it would be preferable to set the power level directly without high-jacking a user.

### Steps to reproduce

- Create a room
- Add a couple users to the room
- Demote yourself from "Admin" to "Standard"
- Call the Make room admin API with a user id.

Private university server
