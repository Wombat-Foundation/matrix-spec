### Description

Hi,
i have a strange issue with Matrix which i am not able to find it's root cause. We run a federating server with ~70 members. The server is up for 3 years now and works basically well. Some issue i registered today, as i saw that 3pids do not work correctly in element deskop or web client, but in element android. Registered mail addresses do not appear because API error is thrown (status 404 unrecognized). I do not get it. 

### Steps to reproduce

I checked 

- homeserver.yaml against the refence configuration documentation
- the nginx reverse proxy settings
- the log files

matrix.fablabchemnitz.de

### Synapse Version

1.78.0

### Installation Method

regular apt repository

### Database

postgresql  12+214ubuntu0.1

### Workers

Single process

### Platform

Ubuntu 18 LTS on a Netcup virtual server

nginx:

```

server {

     location / {
        default_type "application/json";

	root /var/www/vhosts/matrix.fablabchemnitz.de/;
    }
	location ~ ^(/_matrix|/_synapse/client) {
        proxy_pass http://localhost:8008;
        proxy_set_header X-Forwarded-For $remote_addr;

	proxy_http_version 1.1;

    location ^~ /.well-known/matrix/server {

    location ^~ /.well-known/matrix/client {
```
