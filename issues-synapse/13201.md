The [spec](https://spec.matrix.org/v1.3/client-server-api/#post_matrixclientv3account3pidbind) has required an `id_access_token` param for `/account/3pid/bind` ever since it was introduced to the spec in https://github.com/matrix-org/matrix-spec-proposals/pull/2328.

We currently accept requests without an `id_access_token`, and then call `/_matrix/identity/api/v1/3pid/bind`, which was removed from the spec over a year ago ([msc2713](https://github.com/matrix-org/matrix-spec-proposals/pull/2713)).

Instead, we should simply reject any requests that do not pass an `id_access_token`.
