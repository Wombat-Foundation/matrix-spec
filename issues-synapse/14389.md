### Description

We have a presumed issue with federation in Synapse where a few certain (at least five) users, who created an account from a homeserver, in the channel of this homeserver, being unable to see all users from the matrix.org homeserver (no exceptions), and the opposite also happens, where all users from the matrix.org homeservers cannot see the messages of these few users.

This has been tested in multiple environments, Android/iOS/Windows/Mac, etc. by multiple people. Thus this is NOT a client issue.

Most users who created an account from this homeserver can see matrix.org homeserver users just fine.

We have reached out to #synapse:matrix.org and received the following answer from `@travis:t2l.io`, a moderator of the channel.

```
it looks like the events are being flagged as spam for some reason. It's unfortunately something I can't fix, but if you send an email to abuse@matrix.org saying that your server appears to be on the spam rules list then they should be able to help. Feel free to say I pointed you there so the team can track me down for further context.
I'll also mention it to the team internally, but an email from you is much more reliable 🙂 (if they need to ask questions or something)
```

We are sending a weekly reminder to abuse@matrix.org.

This has been months ago and has still not been fixed. I am posting this issue to find if any other homeserver can reproduce the same issue, and whether it is even a spam filter issue.

### Steps to reproduce

- The issue is the following (all rooms here are unencrypted and thus unrelated to E2E except what I wrote about DMs):
- Account A is an account created on matrix.org. Account A can see messages by most, **but somehow not all**, accounts created on the matrix.my-server.com homeserver, in a matrix.my-server.com homeserver room.
- All (every single) accounts created on matrix.org cannot see a certain Account B (we have seen at least 5 of these accounts now) created on the matrix.my-server.com homeserver in all matrix.my-server.com rooms (not yet sure if this still happens outside these rooms).
- Account A can see the "currently typing" tool-tip of Account B, but no messages are visible. Other accounts created on matrix.my-server.com can see Account B fine.
- This consistently happens regardless of room version (6 and 9), and is persistent on multiple Element platforms (Web, Windows, Mac, Android, iOS, etc).
- Therefore, it should be an issue with the homeserver.
- When Account B tries to create a DM room with Account A, Account A cannot join the channel with an error message about "room version mismatch".
- No visible issues occur when Federation Tester is used.
- User verification is also broken across servers - the request comes. but verification acceptance doesn't come back to the requesting user.
