The [nuke-room-from-db.sh](https://github.com/matrix-org/synapse/blob/master/scripts-dev/nuke-room-from-db.sh) script doesn't nuke the room from **communities**
if you added a room into a community on the lefthandside and then nuke that room, it is still in the list of rooms in the community

### Steps to reproduce

- using **postgresql** use the [nuke-room-from-db.sh](https://github.com/matrix-org/synapse/blob/master/scripts-dev/nuke-room-from-db.sh) script on the room

- **Homeserver**: my own homeserver
- **Version**:       0.28.0
- **Install method**: git clone/pip      
- **Platform**:       
  -  Debian squeeze version 9.3
  - Hardware: Intel Core™ i7-6700 Quad-Core (Hetzner EX41S),  running in a XEN vm/container (xen 4.6)
