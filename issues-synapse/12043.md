### Description
Incoming federation works fine. Messages can be received, but outgoing messages don't seem to be working. 

For example imagine 2 users, user1:matrix.org, and user2:matrix.dov.dev

If user one sends a message to user2, it works, but user2 can not ever respond.

Even weirder is that the logs on my home server do not indicate any errors, in fact it helpfully informs me that all of the federation messages sent to matrix.org responded with 200.

```
 synapse.http.matrixfederationclient: [federation_transaction_transmission_loop-11] {PUT-O-17} [matrix.org] Completed request: 200 OK in 0.17 secs, got 60 bytes - PUT matrix://matrix.org/_matrix/federation/v1/send/1645208670770
```

(I can include more logs if you want but they are all just announcing successful requests) this makes me think that somehow my home server is sending malformed messages that matrix.org doesn't validate immediately?
