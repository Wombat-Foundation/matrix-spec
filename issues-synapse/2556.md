### Description

Empty bind address for federation does not bind to all interfaces

### Steps to reproduce

- Server has both IPv4 and IPv6
- Set the `bind` parameter for the federation port in `homeserver.yaml` to the empty string
- Try to connect to the federation port via IPv6, or use the Federation Tester

Although with an empty `bind` one would expect Synapse to bind on all interfaces, it only binds on all IPv4 interfaces.
