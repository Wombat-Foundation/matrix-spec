### Description

Setting an invalid mxc URL as avatar returns a `{"errcode":"M_UNKNOWN","error":"Internal server error"}` instead of some nice error.

This should probably be handled nicely according to spec.
Or it should be possible to set different avatar urls that do not start with `mxc://`

### Steps to reproduce

- type `/myroomavatar example.com` or similar
- press enter

Get `MatrixError: [500] Internal server error (https://my.server/_matrix/client/r0/rooms/!JzIUzeKaqhabcsHQVE%3Amy.server/state/m.room.member/%40test%3Amy.server)`
