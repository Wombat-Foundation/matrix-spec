Seems like queryng room state with `eventType` specified but without `state_key` is broken.
For example for #matrix:matrix.org:
```bash
> curl -X GET --header 'Accept: application/json' 'https://matrix.org/_matrix/client/r0/rooms/&#33;QtykxKocfZaZOUrTwp%3Amatrix.org/state/m.room.aliases?access_token=XXX'
```
always returns
```json
{
  "errcode": "M_NOT_FOUND",
  "error": "Event not found."
}
```
and with stake_key (
GET /_matrix/client/r0/rooms/{roomId}/state/{eventType}/{stateKey} ) all work fine
```bash
> curl -X GET --header 'Accept: application/json' 'https://matrix.org/_matrix/client/r0/rooms/&#33;QtykxKocfZaZOUrTwp%3Amatrix.org/state/m.room.aliases/m.12o.nl?access_token=XXX'
```
returns
```json
{
  "aliases": [
    "#matrix:m.12o.nl"
  ]
}
```

`GET /_matrix/client/r0/rooms/{roomId}/state/` work fine too.

P.S. It is also probably necessary to implement tests.
