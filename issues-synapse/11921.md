### Description

hello, I found an event that is causing issues in Synapse.

The issue is that Synapse will raise an error when trying to decode the query result in `bg_updates.py` line `136`, I lost the stack from my logs but here is the error generated:
`UnicodeDecodeError: 'utf-8' codec can't decode byte 0xf8 in position 21: invalid start byte`

### Steps to reproduce

#### update:

see this comment below: https://github.com/matrix-org/synapse/issues/11921#issuecomment-1031092418

#### or

Making a call to `_get_state_groups_from_groups` that target the room `!CCRKncVOQamqtSzFBm:matrix.org` should make it throw the error.

Compressing the states of the room with https://github.com/matrix-org/rust-synapse-compress-state should make the appropriate call and fail.

Attempting to delete the room will also fail because of this error.

To dig in the problem I did this:
 - call this API and save the result to a file: `https://matrix.homeserver.tld/_synapse/admin/v1/rooms/!CCRKncVOQamqtSzFBm:matrix.org/state?dir=b&from=0&order_by=id`

- run this command to find the culprit characters: `grep --color='auto' -P -n "[^\x00-\x7F]" dump.json`
