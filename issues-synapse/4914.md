A Telegram user joined a public room (!RistbroappQPsmzqnr:matrix.org) and immediately sent a message, however the message never arrived to matrix.org clients. The event appears to have made it to other servers.

The sequence of events is:
* Join: https://matrix.to/#/!RistbroappQPsmzqnr:matrix.org/$1553187330152264cKlPV:t2bot.io?via=matrix.org&via=t2bot.io&via=t2l.io
* Mystery message: https://matrix.to/#/!RistbroappQPsmzqnr:matrix.org/$1553187330152265oPgVN:t2bot.io?via=matrix.org&via=t2bot.io&via=t2l.io
* Message that alerted to the problem: https://matrix.to/#/!RistbroappQPsmzqnr:matrix.org/$1553187429152822fYuhn:t2bot.io?via=matrix.org&via=t2bot.io&via=t2l.io

t2bot.io's DAG appears to support this order of events, and the `prev_events` all reference the expected things. Joining with a server that has never been in the room, the events show up. Even when joining through matrix.org.

Synapse logs from t2bot.io do not reference any of the 3 events as being problematic. 

Not sure how feasible it is to diagnose this, but it sure is strange. This is reportedly not the first time it has happened and is at least the third time.
