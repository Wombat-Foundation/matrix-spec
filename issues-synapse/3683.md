### Description

With HTTP/2 support enabled in Twisted, some HTTP requests never complete, with traceback seen in logs.

### Steps to reproduce

- Install python-h2 and python-priority, that will enable HTTP/2 support in Twisted.
- Attempt to send a message to a room.

The message won’t be sent with an error appearing in Riot (*failed to send the message, retry/cancel*).
