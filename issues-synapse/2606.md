### Description

Synapse will eat all available RAM and Swap if it is unable to write to the log file due to the disk being full.

### Steps to reproduce

- Let your logging partition fill up
- Run Synapse

Expected Behavior: Synapse should not consume all available ram when a log file cannot be written to.

Unable to get logging info since this occurs when the log cannot be written to.
