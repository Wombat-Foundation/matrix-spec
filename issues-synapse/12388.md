We added a table that tracks device list changes in a room in https://github.com/matrix-org/synapse/pull/12321. We can use this in `/sync` (and `/keys/changes`) to more efficiently calculate the device list changes without having to calculate the full set of users who share a room with the requester.

c.f. 

https://github.com/matrix-org/synapse/blob/573cd0f92f78de54cbe5dc9d0bf9f904f9d90011/synapse/handlers/sync.py#L1313-L1329

and

https://github.com/matrix-org/synapse/blob/573cd0f92f78de54cbe5dc9d0bf9f904f9d90011/synapse/handlers/device.py#L139-L143

The tricky thing is that since the table has been added recently we need to a) only use it once our minimum schema is `69` and b) only for device list stream IDs that have happened after a.
