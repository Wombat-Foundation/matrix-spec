The possibility of changing username or transferring the account would be a great convenience to have. For example if someone wants to change the username for some reason, the only possible way would be to create another account, add all rooms and contacts and lose all chats in the process. Simply changing the username would be the best, if it can't be done for technical reasons, then a feature to transfer all contacts, chats and backed up keys would be a good solution too.
