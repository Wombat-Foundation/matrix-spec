Despite having an SRV record pointing to the synapse server, trying to federate with matrix.org doesn't work.
I've been able to confirm it connects to the domain's IPv6 address as-is, ignoring the SRV record.
Synapse should honor the SRV record and connect to the host it points to, even if that host doesn't have an A record but an AAAA one.
