### Description

<!-- Describe here the problem that you are experiencing -->

When running a [load test](https://github.com/hpi-schul-cloud/synapse-load-test) on my [synapse setup with workers](https://github.com/spantaleev/matrix-docker-ansible-deploy/pull/456) the user_dir worker fails to update the user profiles [here](https://github.com/matrix-org/synapse/blob/develop/synapse/storage/databases/main/user_directory.py#L381). 

Maybe additional indexes are needed, similar errors were fixed by adding indexes in https://github.com/matrix-org/synapse/issues/4877

### Steps to reproduce

- setup synapse with workers (at least the `user_dir` worker is needed)
- simulate requests from multiple users e.g. using a [load test](https://github.com/hpi-schul-cloud/synapse-load-test)
- the worker logs an error
