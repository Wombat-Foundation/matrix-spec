### Description

There's a lot of confusion when a user on server B can't view media from server A. Often it's caused by the upload limit of server B being too low. But why does the upload limit even apply? The server could just stream the media from server A or cache it for a short duration. It's even worse that clients don't show any indication of this error, they are just stuck showing a loading indicator.

### Steps to reproduce

- Upload video on server A
- Try to watch video on server B with lower upload limit

fachschaften.org
