### Description

Although `"\^@"` is a perfectly valid JSON string, it seems to fail when storing in the database.

### Steps to reproduce

```
HS_URL=
ROOM_ID=
ACCESS_TOKEN=
curl "https://$HS_URL/_matrix/client/r0/rooms/$ROOM_ID/send/m.room.message" -X POST H 'Content-Type: application/json' -H "Authorization: Bearer $ACCESS_TOKEN" --data-raw '{"msgtype":"m.text","body":"\^@"}'
```
