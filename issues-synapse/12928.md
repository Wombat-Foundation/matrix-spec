From #12732:

> Adds configuration options for automatically removing media if it hasn't been accessed (either locally or remotely) after a certain period of time.

It unfortunately doesn't take into account if the media is [protected](https://matrix-org.github.io/synapse/latest/admin_api/media_admin_api.html#protecting-media-from-being-quarantined), which is usually applied to things like sticker packs (or maybe room avatars and such?). This feature was originally added specifically to avoid quarantining (see #4988 / #9083), but seems equally applicable to media retention feature in #6832.
