### Steps to reproduce

1. Install Synapse through pip in a virtualenv on it's own user in CentOS 7.
2. Set up the Synapse homeserver to use a PostgreSQL database.
3. Run the Synapse homeserver.
4. Create a main admin user for synapse, which will use the identity server of the homeserver.
5. Go to the matrix client of the homeserver at http://matrix.example.com:8448 and log in as the main admin user created.
6. Try to set the main admin user's display name.
  * display name fails to change, 404 No Row Found
7. Invite some matrix.org users and allow them to join.
8. Send a PM to the user or write a message on the homeserver hosted group.
  * Message is not seen, homeserver.log shows 404 No Row Found
9. Allow the matrix.org users to chat among themselves.
  * The matrix.example.org users can see these chats fine, but still cannot send messages.
10. Create a new nonadmin homeserver user, and have it join a matrix channel on the homeserver.
  * The user joins the matrix channel, but does not show up on the user log and while it can read all messages from matrix.org users, it cannot send any.
  * Surprisingly, _this non admin user can change their display name._

### Version information

* Homeserver: Personal hosted homeserver.
* Version: < Server: Synapse/0.22.1 (b=matrix-org-hotfixes,88185fe)
* Install Method: installed through python2 pip
* Platform: CentOS 7

The firewall has port 8448 open, and nginx proxy passing 8008 to port 443.
