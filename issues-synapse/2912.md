A bug introduced in 0.25.0 by ffc574a6 meant that synapse would fail to start if you had the following config in your homeserver.yaml:

```
ldap_config:
    enabled: true
```

The error was:

```
File "/usr/lib/python2.7/dist-packages/synapse/config/password_auth_providers.py", line 34, in read_config
TypeError: 'builtin_function_or_method' object has no attribute '__getitem__'
```
