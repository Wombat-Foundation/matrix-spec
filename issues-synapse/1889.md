I'm trying out Synapse as a possible solution for chat within an application and i'm having trouble sending messages to a room.

Via the http api i've:

1. created a new user
2. logged the user in
3. created a room
4. joined the user to the room

checking the database i can see the user exists, is a member of the room etc.

all is well so far - however, whatever i send in the body of the PUT request to 

`/_matrix/client/r0/rooms/{roomId}/send/{eventType}/{txnId}`

I receive a 400 response with the message

`{"errcode":"M_UNKNOWN","error":"'body' not in content"}`

The room id is definately correct, eventType is m.room.message and the transactionId is randomly generated for each request so it doesn't clash.

i've tried variations on 

```
{
  "content": {
    "body": "a simple message",
    "msgtype": "m.text"
  }
}
```

to no avail... no matter WHAT content the body of the request contains i ALWAYS receive the 400 with the same message. 

I'm assuming i'm doing something dumb here, but can't work out what. Can anyone shed any light on this?

I'm running Synapse on an Ubuntu Trusty install via Vagrant/VirtualBox from 

`pip install https://github.com/matrix-org/synapse/tarball/master `

as per the setup instructions
