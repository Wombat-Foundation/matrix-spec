https://github.com/matrix-org/synapse/pull/14464 added `icu` as a new, optional native dependency to improve user directory search for non-English languages. If the python module is installed, then the new user search code is used, otherwise it will fall back to the old code.

It would be nice to include this in our docker images by default as it allows for enhanced functionality. Really all this means is:

1. Install `libicu-dev`
2. Ensure `pyicu` is installed via `poetry`
