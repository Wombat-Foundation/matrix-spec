Hello,

I m using synapse v1.68.0 on debian bullseye with keycloak as oidc provider and access it with last version of Element.
I would like to do extra specific things in a custom module when people log to my homeserver so I created a module and try to use the register_password_auth_provider_callbacks with auth_checkers : 


```python
import json
from typing import Union, Awaitable, Callable, Optional, Tuple, Literal
import synapse
import logging
from synapse.module_api import ModuleApi

logger = logging.getLogger(__name__)

class Guard:
    def __init__(self, config: dict, api: ModuleApi):
        self.api = api

        api.register_password_auth_provider_callbacks(
            auth_checkers={
                ("m.login.sso", ()): self.check_auth, # DO NOTHING
                ("m.login.password", ()): self.check_auth, # WORK
                ("m.login.token", ()): self.check_auth, # DO NOTHING
            },
        )

    async def check_auth(
        self,
        user: str,
        login_type: str,
        login_dict: "synapse.module_api.JsonDict",
    ) -> Optional[
        Tuple[
            str,
            Optional[Callable[["synapse.module_api.LoginResponse"], Awaitable[None]]],
        ]
    ]:
        logger.warning("GUARD - I CAN DO THINGS HERE !!!!")
        return None
```

When I login with my admin account with classic login / password the type (m.login.password) it's working great I got my log warning.
**When  I login with the oidc I got nothing...why am I missing something ??**
