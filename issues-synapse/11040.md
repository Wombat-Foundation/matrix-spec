### Description

Synapse doesn't create a matrix user for the registered appservice which leads to users not being able to DM it but synapse does recognize the access token of the AS when trying to access endpoints.

The exact same `appservice.yaml` file works just fine when used with dendrite and the user is created.

### Steps to reproduce

- Install synapse and generate a config file (Doesn't matter whether the database used is postgres or sqlite)
- Create an `appservice.yaml` file: https://0x0.st/-E4f.txt

- Append the following to `homeserver.yaml`:

```
app_service_config_files:
  - /path/to/appservice.yaml
```
