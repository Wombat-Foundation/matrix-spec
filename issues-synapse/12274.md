Version: 1.46 to 1.54

 1. Server configured with `jwt_config.enabled=true`
 1. Login a test user  with `type=org.matrix.login.jwt` and token
 1. With admin user, deactivate the test user `/_synapse/admin/v1/deactivate/{userid}`
 1. Relogin the test user  with `type=org.matrix.login.jwt` and token 
    - -> here the login is success
    - => should be refused with `403` `M_USER_DEACTIVATED`
