### Description

I upgraded from 1.24 to 1.27, and then to 1.28. After the upgrade from 1.24, synapse federation broke for me and has not since recovered.

I believe but am not certain that the relevant log lines are:

```
2021-03-10 20:06:05,486 - synapse.federation.sender.per_destination_queue - 417 - WARNING - federation_transaction_transmission_loop-14- TX [matrix.org] Failed to send transaction: Failed to send request: RequestTransmissionFailed: [<twisted.python.failure.Failure OpenSSL.SSL.Error: [('SSL routines', 'ST_CONNECT', 'tlsv1 alert unknown ca'), ('SSL routines', '(UNKNOWN)SSL_internal', 'certificate verify failed')]>]
2021-03-10 20:06:05,487 - synapse.logging.context - 70 - WARNING - federation_transaction_transmission_loop-14- Re-starting finished log context federation_transaction_transmission_loop-14

2021-03-11 13:46:56,989 - synapse.crypto.keyring - 623 - WARNING - PUT-2532- Key lookup failed from 'matrix.org': Not retrying server matrix.org.
```

The first log line there is the first log I found with `[matrix.org]` in it after the upgrade. There are more than hundreds of that last log line. 

### Steps to reproduce

- Upgrade server from 1.24 to 1.27
- Restart the server

matrix.jetcafe.org
