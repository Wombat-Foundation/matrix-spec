**Description:**
Add `TLSA` record validation for outgoing federation connections. If `SRV` or `.well-known` points us to `synapse.example.com:8448` we would like to:

1. Check if  `TLSA` record for `_8448._tcp.synapse.example.com` exists in the DNS
2. Validate the `TLSA` record against the TLS certificate chain presented by the federation server

Details of the latter depend on semantics of the `TLSA` record. [swede](https://github.com/pieterlexis/swede/blob/master/swede) can be used as a reference Python implementation.

* [RFC6698](https://tools.ietf.org/html/rfc6698)
* [RFC7671](https://tools.ietf.org/html/rfc7671)
* [RFC7218](https://tools.ietf.org/html/rfc7218)
