### Description

I'm trying to use matrix as a messaging bus for a decentralized RFQ (request for quote system).

My requirement is that all homeservers share the same rooms, where each room will be used as a topic for sending and receiving quotes.

The requirement is that users should be able to join the room even if the main homeserver is offline, because otherwise, the main homeserver is a centralized point of failure.

I can join rooms using `viaServer` (js SDK) and `server_name` (API request), but, only if the main homeserver is online.

I'm getting the following error message when trying to join when the main homeserver that owns the room is offline: `No create event in state`

Is it possible to sync room state from another homeserver, so I can join the room even if the main homeserver is offline?

### Steps to reproduce

- Create 3 homeservers
- Create a public room in homeserver1
- User from homeserver 2 joins homeserver 1
- Homeserver 1 goes offline
- User from homeserver 3 attempts to join room in homeserver 1 via homeserver 2
- Receive error message: `No create event in state`
