**Description:**

`psycopg2-binary` distributes far more wheels than `psycopg2`, it's both maintained by the same people, and has the same source tarball contents (except top-level package name changes in `PKG-INFO`, `setup.py`, and `.egg-info` files).

Allowing `pip` to access a far richer range of wheels to choose from when installing will make installing synapse from source more accessible to more platforms (because build errors or `python*-dev` dependencies will not be present).
