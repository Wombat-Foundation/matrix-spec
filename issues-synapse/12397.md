### Description

Very occasionally, multiple users will have multiple devices signed out and will need to sign back in and re-verify. It may be some devices, for some users, or it may be all—this last time it affected every user except for a specific Element web client for one user (but the rest of his devices were affected).

Logs do not show anything interesting.

Only other report I can find of this is https://github.com/matrix-org/synapse/issues/10401. This also [causes the Android version to crash](https://github.com/vector-im/element-android/issues/5701).

### Steps to reproduce

No idea. It has happened 3 or so times over the course of months, there is no obvious commonality between the events.
