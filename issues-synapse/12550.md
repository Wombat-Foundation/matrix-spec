[MSC3771](https://github.com/matrix-org/matrix-spec-proposals/pull/3771) and [MSC3773](https://github.com/matrix-org/matrix-spec-proposals/pull/3773) make changes to the receipt and notifications architecture for handling threads.

* [x] Develop proof of concept for MSC3771 and MSC3773 together
* [x] MSC3773: Notifications for threads
	* [x] Update the notifications schema to handle a `thread` field.
	* [x] Update the push rule handling code to attach thread to notifications.
	* [x] Update the notification rotation code to handle unique `thread`s.
	* [x] Update the sync code to return notifications separately for each thread.
* [x] MSC3771: Read receipts for threads
	* [x] Update the `/receipt` servlet handling for `thread`.
	* [x] Update the receipt schema to handle `thread` (and properly handle it when not provided).
	* [x] Update the fetching of receipts to handle unique `thread`s.
	* [x] Update the sync code to return the `thread` of each receipt.
