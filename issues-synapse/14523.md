The spec has deprecated the `keyId` parameter on [`GET /_matrix/key/v2/server`](https://spec.matrix.org/v1.5/server-server-api/#get_matrixkeyv2serverkeyid) since [forever](https://github.com/matrix-org/matrix-doc/pull/1423).

(The reason given for that deprecation was that it is *ignored* on the server side.)
