### Description

I'm building Synapse on a Debian 11 machine with an armv7 architecture by using the [matrix-docker-ansible-deploy](https://github.com/spantaleev/matrix-docker-ansible-deploy) project.

The build process fails with the error "AttributeError: cython_sources".

I'm not aware of the details, but it [is a known bug](https://github.com/yaml/pyyaml/issues/601) in the build process of PyYAML versions greater than 5.3.1 up to 6.0.0 (inclusive) while compiling against recent versions of Cython. Fortunately [a new version of PyYAML](https://github.com/yaml/pyyaml/commit/c42fa3bff1eabdb64763bb1526d9ea1ccb708479) that [works around the issue](https://github.com/yaml/pyyaml/pull/702) has been recently released (6.0.1).

### Steps to reproduce

I used the [matrix-docker-ansible-deploy](https://github.com/spantaleev/matrix-docker-ansible-deploy) instructions.

- First I did [this](https://github.com/spantaleev/matrix-docker-ansible-deploy/blob/master/docs/configuring-playbook.md)
- Then [this](https://github.com/spantaleev/matrix-docker-ansible-deploy/blob/master/docs/installing.md) up to the point of actually running ansible-playbook.

I run the Ansible recipe with `ansible-playbook -i inventory/hosts setup.yml --tags=install-all,ensure-matrix-users-created,start`.
