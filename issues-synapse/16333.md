### Description

With the version 1.92.2 which also contains the Debian update, I suspect that some python libs has changed. 
It seems to affect the logging.
Config wise I use the logging sample config you can find [here](https://matrix-org.github.io/synapse/v1.41/usage/configuration/logging_sample_config.html).


### Steps to reproduce

Steps to reproduce:
- pull synapse version v1.92.2 or (currently) latest via Docker
- recreate and start
- Exception appears, synapse doesn't run

Steps to unreproduce:
- pull synapse version v1.92.1 via Docker
- recreate and start
- synapse runs
