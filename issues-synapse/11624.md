### Description

When we send a room invite event to a specific user, the user doesn't receive any invite notification (tested in Element Web) and cannot see or access the room. Also when directly calling the `/sync` endpoint no events concerning the room are received. However other users can see that the user has been invited.

This seems similar to https://github.com/matrix-org/synapse/issues/10022 but we already checked that no entries are set in the `ignored_users` and `rejections` tables.

Also we cleared the cache in Element Web and did a full reload, still the invite doesn't get received.
